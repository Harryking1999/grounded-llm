# Grounded LLM with Cognitive Maps

Integrating cognitive maps with language models for improved state representation and planning in long-horizon tasks.

## Project Overview

This project explores whether adding a small state network (cognitive map) to LLMs can enable:
- Better state perception and reasoning
- Generalization to unseen scenarios
- Efficient training with minimal computational overhead

Inspired by [GCML paper](../2025.05.14.654027v3.full.pdf) on cognitive maps in biological navigation.
