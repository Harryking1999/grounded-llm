# 积木地图：当前读取接口的基础

**地图把完整棋盘编码成向量 Q，使有向距离反映从当前棋盘到目标棋盘的移除难度。** 当前 LLM 实验冻结这个编码器，通过 cross-attention 读取 current、goal 和各合法后继的向量。

## 当前采用什么

| 项目 | 当前设置 |
|---|---|
| 环境 | 10×10 二值棋盘、八种规定形状；仅移除，目标可以非空 |
| 编码器 | 多棋盘共享 Q，输入完整棋盘，输出 128 维状态向量；目标不进入编码器 |
| 后继 | 由环境执行合法动作获得，再编码为 Q(T(current, action)) |
| 距离 | `directed_sum`：累加坐标的正向差并按维度归一化 |
| 权重 | `tree_1000_132f5a1/best.pt`；地图训练源码提交 `132f5a1` |

当前没有训练积木动作向量 V。早期“先做单棋盘 Q、再训练 V”的顺序是探索计划，不能当作本轮 LLM 接口的实际设置。

## 地图监督与判断

离线裁判给出状态对的精确最短步数或已证明不可达；未知不当作不可达。训练用距离误差与排序监督塑造 Q，再用留出关系和逐步贪心执行检验地图能否支持动作选择。

积木只有移除，反向添加不可行，因此距离需要有方向。死局也是相对目标而言：无法清空的棋盘，仍可能到达某个非空目标。数据应同时包含合法坏动作、非空目标，以及面积相同但可达性不同的后继。

地图贪心成绩检验地图加选择器；LLM 成绩还包含读取、表达与自身轨迹分布的影响。两者应在相同任务上比较，一步准确率也不能直接换算为整条轨迹成功率。
