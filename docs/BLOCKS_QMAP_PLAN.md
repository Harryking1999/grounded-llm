# 积木 Q-map：共享状态地图与目标相对关系

要检验的是：**只由当前棋盘计算的 Q，能否在未见过的初始棋盘上，支持不同起点到不同目标的动作选择？** 一个合法移除动作可能通向清空目标，也可能破坏必须保留的非空目标；好坏应由“当前状态到这个目标能否到达、还有几步”决定。

当前只训练 Q，动作模型 V 和 LLM 尚未进入积木实验。执行入口与正式配置见[实验 README](../experiments/blocks_distance_map/README.md)，已得到的分层成绩见[结果报告](../experiments/blocks_distance_map/results/report.md)，下一步见[项目状态页](PROJECT_STATUS_AND_TODO.md)。

## 规则与表示

使用原论文的 10×10 棋盘、四种三格拐角及横竖二格／三格条，共八种形状。每步合法移除一块，不会重新添加格子。目标可以是空棋盘，也可以是指定的非空残余棋盘。动作由规则程序枚举，Q 不负责预测动作后果。

共享编码器 `Q(棋盘)` 读取 100 个占用位，输出 128 维状态坐标；目标不输入编码器。当前有向距离为

$D(Q(s),Q(t))=\sum_i\max(Q_i(s)-Q_i(t),0)/\sqrt{128}.$

移除不可逆，所以 `s→t` 与 `t→s` 应允许不同距离。Q 的坐标不要求每一维有独立语义；关键是候选后继到当前目标的相对顺序能否指导动作。

## 标签与数据覆盖

一个状态对的标签是**真实最短合法移除步数**或**已证明不可达**。离线精确求解器先检查目标格是否都仍存在，再检查差集能否被允许形状完整覆盖。计算预算耗尽是未知，不能记为不可达。合法坏分支也是当前状态的一步正关系；它只在相对某些目标无解时是负关系。

数据先覆盖多张棋盘、多种非空地标和目标切换，再把同父状态的所有合法后继与后代目标联起来。后续补全清空前的分叉和较长目标距离。新增关系与原有关系一起参与训练；当前比例是一个工作点，尚未经过固定其他条件的配比消融。具体采样和优化参数只在[正式配置](../experiments/blocks_distance_map/configs/)中维护。

按**完整初始棋盘**划分训练、开发、封存测试。开发题池同时变动残余起点、清空／普通非空／含孤立格目标和真实路径长度，用于从已保存 checkpoint 中选权重。另一批未见棋盘上的同类题只用于最终报告。同一棋盘可产生多道相关任务，不能把任务数当作独立棋盘数。模型决策时只收到 Q 分数和规则给出的合法真实后继；精确标签只在训练或评测端使用。

## 每个指标回答一个问题

| 指标 | 问题 |
| --- | --- |
| 首步后仍可达 | 第一次选择有没有切断到目标的所有路径？ |
| 首步进入最短路 | 这一步是否保留最短步数？ |
| 分步数完整到达 | 连续多步选择最终能否到达目标？ |
| 按目标类型完整到达 | 清空收益是否掩盖了普通与孤立格非空目标的损失？ |
| 可达距离误差 | Q 的步数刻度平均偏差多少？ |
| 困难不可达召回 | 目标格仍在但差集无解时，能否识别？ |

最短路首步比“仍可达”严格；完整到达又会累积后续动作错误，三者不能混作同一个 ACC。完整到达不要求最短。不同长度段要互不重叠，报告每段的成功数和分母。清空目标、一般非空目标与含孤立格目标分别列出。

## 当前结论与下一步

封存新棋盘上的总体完整到达已达到 90.2%，首步仍可达 95.7%；清空目标约 99.0%，普通非空约 89.6%，含孤立格目标约 81.6%。这说明树关系监督和补全后的共享 Q 已能处理许多未见棋盘的目标选择，同时也定位了尚未解决的关系类型。距离刻度与困难不可达识别仍有明显误差，不能仅凭总到达率宣布地图已经完整。

下一项研究问题是**怎样调整清空、长程、普通非空和含孤立格目标的训练关系比例**，使最弱目标类型改善而不牺牲已获得的清空能力。先按固定开发题池定位失败，再设计匹配的最小比例对照；高成本续训需要单独确定合同。之后若固定 Q 训练 V，必须另测 V 预测后继坐标对候选排序造成的损失。
