# 积木认知地图：先把状态的远近训练出来

我们要让每张棋盘对应一个向量 Q，让两个向量之间的距离反映：**从前一张棋盘出发，最少需要多少次合法移除才能得到后一张棋盘。** 一步能到的近，多步才能到的更远，怎么也到不了的最远。

训练分成两件事。先只训练地图 Q；地图固定后，再训练动作模型 V，预测一个动作会使向量移动多少。当前试验只做第一件事，不训练 V 或 LLM。

## 这次用什么积木

使用原论文的 10×10 棋盘，以及四种三格拐角、横竖二格条、横竖三格条，共八种形状。每步移除一块，形状覆盖的格子必须全部仍被占据。形状可以重复使用，没有重力和库存限制，目标是空棋盘。

首轮固定使用原论文 notebook 演示的那张八块构造棋盘。先检验一张地图能否学好，再讨论新棋盘的泛化。原来的八步参考解只证明它可解，不代表八步最短。

## 监督告诉模型什么

一个训练样本是“起点棋盘、终点棋盘、最短步数”。例如一步、两步、五步，或者已经确认的不可达。一个棋盘可以与许多其他棋盘组成样本。

标签由离线精确求解器生成，不靠人工猜测。要从 s 变成 t，t 的格子必须都保留在 s 中；再检查多出来的格子能否用允许形状完整分解，最少需要几块，就需要几步。

没有找到路径不等于不可达。只有完整求解证明确实无解，才能给不可达标签；如果计算预算耗尽，就保留为未知。本次程序遇到标注预算耗尽会停止，避免把未知当负样本。

采样覆盖一步、短程、中长程和不可达关系。不可达又分为两类：一类是目标需要重新长出已移除的格子；另一类是目标确实包含在当前棋盘里，但剩余差集无法分解。第二类更能检验模型有没有学到积木结构。首轮训练后发现，随机取状态对几乎采不到“非空目标”的第二类负样本；因此追加一个诊断条件：用单块积木组成的非空棋盘作参照，监督其他状态到这些参照棋盘的距离。留出的“后继到空棋盘”标签仍不进入训练。这增加了间接目标信息，评测解释须明确这一点。

特别要保留“坏动作”的合法转移。如下图，每个字符代表一格，其他位置为空：

```text
当前：111111
后继：000111   再移除三格条即可清空
后继：100011   还能移除右侧二格条，但会剩下孤立单格，无法清空
```

两个后继距离当前状态都是一步，因此都应当近；但是第二个后继距离空棋盘应当最远。**死局不是对所有状态都为负样本，“不可达”始终描述起点到终点的关系。** 两个后继的格子数相同，也能防止模型仅凭剩余面积判断。

## 距离为什么需要有方向

积木可以移除，却不能重新添加。从 s 一步得到 t，不代表从 t 能返回 s。普通欧氏距离左右对称，无论增加多少维度，也无法同时表达这两个不同答案。

因此比较两种模型：一组使用普通欧氏距离；另一组使用简单的有向距离：

\[
D(Q(s),Q(t))=\max_i\max(Q_i(s)-Q_i(t),0).
\]

可以把它理解为：逐个比较向量坐标，取最大的正向差。交换起点和终点，结果可以不同。距离公式没有额外可训练网络，两个版本都只训练 Q。Q 本身仍只由棋盘决定，不把当前目标输入 Q。

## 怎样训练，loss 是什么

首轮给每个已采到的棋盘分配一个可学习的 128 维向量。训练只调整这些向量的位置；它检验已有状态能否组成地图，还不能证明模型能编码未见棋盘。

不可达不能直接用无穷大参与计算。用 C 表示一个超过本张棋盘所有有限路径长度的数，作为不可达的最远等级。有限距离仍使用真实最短步数。

**第一项 loss 校准距离：预测几步，就应当接近真实几步。**

\[
L_{距离}=\operatorname{Huber}(预测距离-标签距离).
\]

Huber 可以理解为一个平滑的误差罚分：误差越大罚得越多，但特别大的误差不会无限放大梯度。不可达样本的标签距离使用 C。

**第二项 loss 校准顺序：真正近的，应当比真正远的更近。**

\[
L_{排序}=\max(0,\;0.5+预测近距离-预测远距离).
\]

预测近距离至少比预测远距离小 0.5 时，这一对不再受罚。同样步数的样本不强迫分先后。既比较“同一起点到不同终点”，也比较“不同起点到同一目标”。

总 loss 是这两项相加。可达与不可达各占一半训练权重，再在各自内部平衡距离等级或负样本类型，避免模型被大量容易的不可达样本主导。欧氏版和有向版使用同一批标签、同一划分和匹配训练预算。

## 怎么判断学到了没有

训练 loss 下降只是拟合过程，以下评测分别回答不同问题。

| 指标 | 用直白的话解释 | 为什么需要 |
| --- | --- | --- |
| 有限距离平均绝对误差（MAE） | 平均把真实步数估错多少步 | 检查距离刻度是否准确 |
| 距离排序准确率 | 在已知谁近谁远的比较中，排对了多少 | 直接对应地图的近远目标 |
| 不可达识别 | 无解状态是否被排到最远，可解状态是否被误伤 | 不能只看正样本 |
| 困难死局排序 | 还有合法动作的无解状态，是否比可解状态远 | 排除“没有动作就是死局”的捷径 |
| 相同格子数的好坏后继排序 | 面积相同，能否辨别哪个后继还可解 | 排除仅仅数格子的解释 |
| 可解动作选择率 | 在存在可解后继时，按地图挑动作，有多少仍保留解 | 判断地图是否支持决策 |
| 最优动作选择率 | 选中的动作是否属于最少步数解的一步 | 区分能完成与走得最短 |

动作评分相同的时候，按随机打破平局的期望成功率计分，不利用真实答案挑对的那个动作。

对照包括训练前的随机 Q、剩余格子数、欧氏 Q 和有向 Q。精确最短距离只作为评测上限。旧的转移监督试验用了不同形状，保留作历史背景，不混成同规则的直接对照。

## 如何防止“把答案背下来”被当成泛化

先划分状态对，再生成排序比较；一个状态对的两个方向进入同一个集合。初始棋盘与其他状态的关系保留用于训练，让每个向量都有学习依据；其他关系再划分。验证集选择训练轮数，测试集只报告结果。

还会选一批决策状态，把它们所有后继到空棋盘的直接距离标签留在测试集。这些关系不进入训练 loss，检验模型能否从其他关系补出目标方向。后继状态本身仍可以出现在其他训练关系中，所以这是**已见状态的关系补全**，不是未见状态泛化。

当前动作评测使用环境给出的合法动作和真实后继 Q，专门检查地图质量。它不包含 V 的预测误差，也不能称为无工具规划或 LLM 的规划成绩。若地图通过，再冻结 Q 训练 V，然后单独检查 V 是否保住了地图的排序。

地图查表有效后，才把 Q 换成读取完整棋盘的小网络，用从未参与训练的残余棋盘测试泛化；跨初始棋盘共享模型更晚进行。

## 什么结果值得继续，什么结果意味着要停下来分析

建议首先检查：困难好坏后继排序是否达到 95%，在存在可解动作时选择可解动作的比例是否达到 95%。这是决定是否进入 V 阶段的暂定工程标准，不是已取得的成绩，也不是认知地图的理论定义。

如果训练和测试距离都差，先检查表示容量或优化问题；如果训练好、测试差，说明关系补全不足；如果距离好、动作选择仍差，就定位真正影响选择的候选排序。不能只凭某一个总体相关系数宣布成功。

这轮允许求解器提供训练监督，因此检验的是“规划关系能否学成有用的状态地图”，不是“只看一步转移就自行发现了全部规划关系”。
