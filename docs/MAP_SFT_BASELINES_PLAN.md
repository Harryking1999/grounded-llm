# 积木：统一增强数据的地图与 SFT 多基线方案

**主线按用户构思：所有组共用增强后的任务和动作轨迹；无地图输出 R＋A，有地图输出 R＋排序＋A；比较只训接口与全参＋接口。编号重复全部取消，用不同物理轨迹填充数据。**

本文件是下一轮设计，不改变当前 SFT 续训。覆盖审计已完成，增强数据和新训练尚未启动。**用户已确定所有地图组统一使用更好的续训版 Q；有地图必须输出排序，无地图不输出排序，不设置例外组。** 原始证据见[策略分析](../experiments/llm_task_sft/results/policy_comparison.md)。

## 1. 先明确要解释什么

当前总成绩接近，但数据、动作教师、输出格式和可训练参数同时不同。下一轮检验四个具体解释：

| 可能原因 | 机制假设 | 对应比较 |
|---|---|---|
| 旧地图数据反复练同一路线 | 编号变化增加表达练习，但没有增加物理决策状态 | B1/B5、B2/B6、B0/B7 |
| 冻结主干限制了任务适应 | 接口能改变输入，主干却不能直接调整已有动作规律 | B2/B1 |
| 新增接口本身就能帮助适配 | 同样全参训练，新增模块而非地图也可能带来提升 | B4/B0 |
| 地图方案能否提供额外收益 | 真地图及其排序监督可能帮助任务决策 | B1/B3、B2/B4；分别匹配冻结/全参范围及接口结构 |

“示范更短”也可能有贡献。本轮所有新组都使用地图贪心成功且最短的示范，将它作为共同条件；本轮不能单独测出从非最短改成最短的收益。

按照用户的输出约定，地图和排序监督一起变化，因此 B1/B3、B2/B4 测量的是“地图输入＋排序监督”的整体作用。不能将差值单独归因于地图向量。另用同模型、同格式的地图内容干预检查是否实际使用地图，但这种干预也不替代训练对照。

## 2. 现有数据怎么来的，覆盖差在哪里

1. 从官方数据随机选取 1,000 张不同的来源棋盘。
2. 每张棋盘取官方清空路线，再采 32 条随机合法移除路线；随机路线可以走死。
3. 将每条路线中的前后状态组合成起点—目标，去重并计算真实最短距离。
4. 保留最短距离至少 6 步的任务，优先检查距离长的任务；地图贪心成功才接收，每张棋盘取 8 个，共 8,000 个任务。原始记录有 3,282 次因地图贪心失败而拒收。
5. 每题保存一条地图路线，再做六份编号变体，得到 48,000 条普通样本；另加 1,000 条初始即目标、1,000 条仅监督结尾的失败历史，总计 50,000 条。

**按棋盘数量均衡，并不等于按决策情境均衡。** 8,000 题只有 2,400 个不同起点，208 张来源棋盘的八题共用一个起点；97.35% 的题长为 7–8 步，91.55% 的目标只剩 0–4 格。短状态在完整路线后半段仍会出现，不能说模型完全没见过短题。

| 普通动作监督覆盖（忽略编号和历史文本差异） | 旧地图 | 当前多路线 SFT |
|---|---:|---:|
| 不同形状＋坐标动作 | 664/664 | 664/664 |
| 不同当前状态—目标 | 62,230 | 292,758 |
| 不同当前状态—目标—监督动作 | 62,230 | 337,299 |
| 同一状态—目标有多个监督动作 | 0 | 16,932 |

旧地图普通路线本身有 64,155 个决策，六次编号重复后是 384,930 次动作监督；SFT 是 360,336 次。因此差别不是旧组动作标签出现次数少，而是它们更重复。旧地图仍在输入中看过全部合法候选，并接受过候选排序监督，上表不代表所有输入信息的覆盖。

随机抽取同一批 128 个训练任务，起点共有 3,216 个“仍属于最短解”的可选动作。旧地图标签覆盖其中 117 个（3.64%），SFT 覆盖 693 个（21.55%）。这是该样本中的动作分支覆盖率，不是模型准确率，也不是完整状态空间覆盖率。一个确定策略不必展示所有正确动作才能学会任务。

SFT 不是只交换移除顺序：7,764/8,000 题的多路线包含不止一套积木移除组合，平均每题 4.85 套。两组二格块的动作占比分别为 63.22% 和 41.76%；这也反映教师和最短性差异，不能仅凭频率不同就强行均衡八种形状。

## 3. 统一增强数据：扩大地图最优示范的覆盖

### 3.1 什么算合格轨迹

统一使用 **`tree_continue_986cb4d/checkpoints/step_015000.pt`**，在原 Q 基础上补充清空与长程关系、续训 15,000 步的版本。平台文件已确认存在，绝对路径见[开发机手册](../DEVELOPMENT_MACHINES.md)。同题纯地图贪心已有结果为 397/510（77.8%），原版为 345/510（67.6%）；这不是新 LLM 组的预期成绩或保证。

用该版冻结 Q，逐步选择真实地图距离最小的合法候选，直到精确到达目标；再由精确求解器认证整条路线最短。所有组使用这条路线的同一套动作标签。

- 每一步合法、保留目标且仍可解；真实最短距离减少 1。
- 每一步动作也必须属于该状态的地图最优候选。
- 不添加人为距离容差，不按编号改排名，不把非第一名解释成第一名。
- 推理时全部合法候选照常呈现，求解器只用于离线标签和裁判。
- 数据筛选、缓存 Q、排序标签、训练输入和推理输入全部来自同一新版权重。旧版的成功路线不能直接当成新版的地图最优路线，必须重新验证。

**已查到旧版地图数据 64,155 个决策全部只有一个地图最优候选。** 固定 Q、起点和目标后，严格贪心路线在这些任务上唯一。因此不能假定“同题换六个随机种子”会产生六条路线。增强的主要单位改为不同起终任务及其物理轨迹；新版地图的并列情况在试产时重新统计，真实并列出现时才允许不同贪心路线。

### 3.2 生成和选择

| 环节 | 执行规则 |
|---|---|
| 小规模试产 | 先用固定种子 20261013 随机选 32 张训练来源棋盘，检查产量与耗时；不按旧模型成绩挑棋盘 |
| 扩大候选池 | 每张用官方路线＋128 条随机合法路线，生成不同起终配对；不足时增加到 512 条，不重复采同一确定性贪心路线 |
| 最短性筛选 | 首轮普通任务保持真实长度 6–9 步；检查贪心成功且路线长度等于精确最短距离。求解超预算记为未知，不当成无解 |
| 增加新情境 | 同一来源棋盘内，优先能带来新状态—目标组合、不同起点、不同目标大小的路线；不再简单按最长优先取满 |
| 数量 | 首选每张来源棋盘 49 条不同普通轨迹＋1 条初始即目标，共 50,000 条/epoch；没有重复补足 |
| 分层选择 | 在每张来源棋盘的合格池中轮流取不同起点；每个起点内轮流取 `(真实题长, 目标格数档)`，目标档为 0、1–2、3–4、至少 5 格。该层内优先选新增状态—目标最多的路线，同分用固定随机种子；空层跳过并记录缺口。另记录合法候选数和最优/次优地图距离差，不把微小差距强行视为并列 |
| 限制重复 | 对起点—目标—动作序列整体去重；额外统计忽略顺序后的移除集合，识别只改动作次序的路线 |
| 编号 | 全部组采用同一 `(shape_id,row,col)` 顺序编号；不制作重编号副本。候选编号不携带地图排名 |

32 张试产后冻结各层配额、单题求解预算及候选池上限，并写入正式数据配置；只根据训练候选池产量作决定。若部分棋盘无法提供 49 条，先报告缺口，不暗中集中到易生成棋盘、不用重复样本冒充覆盖。正式生成前须确定可满足的配额。

### 3.3 覆盖验收与边界

以现有 SFT 的 **292,758 个不同状态—目标组合**作为主要覆盖目标，同时报告实际决策数、不同动作三元组、来源棋盘分布和长度分布。50,000 是完整多轮样本数，覆盖数按去掉编号和历史文本后的物理状态统计。

严格地图贪心是确定策略，所以同一状态—目标通常只有一个动作标签；它不能复制 SFT 的多最优动作分支分布。对齐的是情境覆盖规模，不是宣称两批旧数据逐状态、逐动作分布相同。真正的组间一致由所有新组共用同一个增强数据文件保证。

若 50,000 条仍达不到覆盖目标，先在相同训练棋盘上扩大候选起终池、减少重合；仍不足就报告实际规模并调整方案，不能在实验后宣称已对齐。

仅从已指定的训练来源棋盘取数据；先锁定共同参考路线，将既有留出任务的初始状态—目标及共同参考决策对排除出新训练决策，新初始棋盘评测保持来源隔离。现有 510 题继续作为固定监测集，不根据失败个例造题，也不删掉其中地图做不好的题。所有组共享最终动作标签、配额、编号及终止样本。

这批数据经过地图成功且最短筛选，适合检验“地图已经能提供正确最优指引时，怎样接入更有效”。不能由此证明地图在所有可解状态上都可靠。评测按地图独立贪心成功/失败、题长和来源分组，观察是否只在地图擅长的区域改善。

新版 Q 的补充关系与监测题的曝光重合尚未审计；制作新数据时一并记录地图训练、接口训练的曝光边界。未排除前不称为独立泛化证据，也不能将换图后与历史模型的差值全部归因于本轮数据增强。

### 3.4 还能增加什么

- **优先：同一棋盘上的新起点、新目标。** 最直接增加当前缺少的任务情境。
- **其次：旋转、翻转、平移。** 只用训练来源，同步变换动作并重新生成 Q、排序与贪心路线，再认证最短；地图未必具备几何不变性，不能照搬原排名。第一批不混入，以免同时改变来源分布。
- **后续：训练棋盘上的困难可解状态。** 可以增加目标容易被误删、错误动作容易留下孤立格的任务；困难分层使用离线裁判，模型仍看到全部合法候选。已经走死的状态不能伪造“能恢复”的正确动作。

这些增强均须向所有组提供同一批数据，不能只补地图组。

## 4. 八条基线：三条主线，五条诊断

R 为现有 SFT 的事实短依据，A 为动作/停止标记，S 为真实地图的 Top-10＋current 排序。
有排序时严格按用户提出的 **R→S→A**；停止回答统一为 R＋`<done/>`，不输出排序或另加长总结。

普通回答按以下模板机械生成；花括号由真实动作、裁判和该版 Q 填写，不交给教师自由编写。

```text
Reason: Clearing {cells} is legal, preserves all goal cells, and leaves a solvable board with one fewer removal needed.
Map-distance ranking to the goal, closest to farthest: {ranking}.
<action>{candidate_id}</action>
```

无地图组只去掉中间排序行，保留完全相同的 R 和 A。一步到达时沿用 SFT 的 `leaves exactly the goal board` 句式；初始即目标用同一达标短句与 `<done/>`。

| 编号 | 用途 | 输入与架构 | 可训练参数 | 输出 | 数据 |
|---|---|---|---|---|---|
| **B0** | **无地图主基线** | 文字状态、无接口 | LLM 全参 | R＋A | 增强全集 |
| **B1** | **原地图架构主线** | 真地图＋接口 | 仅接口，LLM 冻结 | R＋S＋A | 同一增强全集 |
| **B2** | **地图全参主线** | 真地图＋接口 | LLM 全参＋接口 | R＋S＋A | 同一增强全集 |
| B3 | 匹配冻结主干的接口对照 | 无地图＋同一接口 | 仅接口，LLM 冻结 | R＋A | 同一增强全集 |
| B4 | 匹配全参的接口容量对照 | 无地图＋同一接口 | LLM 全参＋接口 | R＋A | 同一增强全集 |
| B5 | 地图接口的数据覆盖对照 | 真地图＋接口 | 仅接口 | R＋S＋A | 全集中的小覆盖子集，重复到相同样本预算 |
| B6 | 地图全参的数据覆盖对照 | 真地图＋接口 | LLM 全参＋接口 | R＋S＋A | 与 B5 同一子集、同一重复规则 |
| B7 | 无地图的数据覆盖对照 | 文字状态、无接口 | LLM 全参 | R＋A | 与 B5 同一子集、同一重复规则 |

**“全参＋接口”不包括训练地图 Q。** 所有组从原始 Qwen2.5-1.5B-Instruct 开始；接口使用相同随机初始化，不加载旧 adapter 或已训练 SFT 权重。纯冻结 LLM 且不加任何可训练模块不属于训练基线，不占一个正式名额。

B3/B4 是“无地图但保留可训练接口”：保留相同接口结构、候选地址、角色、槽位和 mask，状态内容使用固定、各槽位不同的非零伪向量，独立于棋盘和目标；从头训练，不输出排序。候选数量仍保留，因为各组文字中本就提供全部合法候选。不能直接禁用整个接口或把它变成无效分支，那样控制不住新增模块；也不能以推理时临时拔图替代这些训练对照。

B5/B6/B7 每张来源棋盘从全集中选 8 条代表性普通任务，共 8,000 条；保留同一 1,000 条初始即目标。每条普通路线重复六次，每张棋盘再为其中一条增加一次，共 49,000＋1,000 条。没有编号增强，完整序列重复是有意设置的低覆盖对照。记录子集与全集的长度、目标和候选数分布，尽量匹配；它检验新增任务情境与覆盖的整体收益，不宣称是同题多路径的单独贡献。此子集同样由新版地图生成，不能拿旧地图训练集直接替代。

## 5. 一致的训练与评测

以下为新一轮拟定配方，不修改当前运行。正式运行前写入各组机器可读配置。

| 项目 | 统一规则 |
|---|---|
| 第一阶段预算 | 每组 5 epoch、global batch 4、共 62,500 次更新；每半 epoch 同题评测 |
| 优化 | AdamW，峰值学习率 2e-5、weight decay 0.01、clip 1；5% warmup 后 cosine 到 2e-6，按本轮总步数统一计算 |
| 数值与内存 | BF16、gradient checkpointing；完整对话训练，不截断动作或停止标签；先做最长样本 smoke |
| 损失 | 各样本 R＋A token 平均损失；有 S 时另加 S token 平均损失，固定系数 1。排序 token 不进入 R＋A 分母；分别记录 R、S、A loss |
| 数据权重 | 每张来源棋盘同权，普通/初始即目标总权重固定 98:2；B5/B6/B7 的六/七次重复按配额校正，防止同时改变任务权重与终止权重 |
| 随机性 | 第一阶段统一种子与可匹配数据顺序；关键比较再补两个种子，不对某组单独挑最好种子 |
| 输出预算 | 全组先统一 256 token/轮；制作数据时检查最长答案是否容纳，若不够统一调高并在训练前锁定；记录生成截断率 |
| 环境 | 同样的状态、合法候选、历史、最大 32 次动作、停止解析；禁止用裁判预先过滤动作 |
| 同状态单步评测 | 共用这 510 题现有求解器最短参考路线上的 3,690 个非终止状态及候选编号。每个状态独立发起一次回答，提供同样的题面、当前棋盘和真实已执行动作，不拼接任何一组的 assistant 示范历史；避免在地图组历史里强塞与排名不一致的求解器动作 |
| 自主评测 | 同一 510 起终任务，保留自身完整对话并执行实际动作；中途走死不会用求解器纠正 |
| 主结果 | 固定第 5 epoch 的到达且正确停止率，同时报告完整曲线；监测峰值只作描述，不按各组最佳点判胜 |

分段损失意味着地图组额外接受排序目标，比较反映地图方案的整体作用，不把效果解释为“证明模型在思考”。B5/B6/B7 的普通任务校正权重可用 `49000/(8000×该任务重复次数)`，初始即目标权重为 1；这样期望的任务权重和 98:2 类别权重固定。

新的同状态单步评测是独立诊断口径，不与旧版带 assistant 参考历史的 reference 百分比直接拼接。完整任务能力仍由保留模型自身历史的 rollout 判断。

主要诊断只保留能改变判断的指标：

1. **完成任务：**到达、到达且正确停止；配对列出救回/退步题数，并给出按来源棋盘聚类的差值区间。
2. **动作判断：**相同参考状态上的可达动作率、最短动作率，以及首轮指标；不把两条不同参考路线的均值当配对结果。
3. **错误位置：**第一次致命动作的轮数，区分误删目标格、剩余无解、提前停止和控制错误；不只看最后一次报错。
4. **路线效率：**双方共同成功题上的额外步数；同时报告全部成功题分布，说明条件筛选范围。
5. **地图读取：**排序质量、选择自己排序首项的比例、R 的事实正确率；对 B1/B2 在固定 32 题的配对状态做正常 Q/候选后继 Q 反序干预，仍输出 R＋S＋A。保持模型、文字、历史、地址和预算一致，分别检查排序和物理动作变化。这是地图使用诊断，不是新的整题成功率。
6. **训练成本：**R/S/A 分段 loss、动作 token 数、步时和总 GPU 小时；同 epoch 不自动等于同计算成本。

固定 510 已参与前期选择，是监测集。最终泛化主张需要预先封存的新评测；本轮不恢复旧 1,000 题评测，也不自动新增外部评测任务。

## 6. 运行顺序与如何解释结果

1. **先验收数据。** 32 张棋盘试产，确认能否满足最短且地图最优、49 条/棋盘和覆盖目标，再形成完整固定数据；未通过不启动八组训练。
2. **先跑 B0、B1、B2。** 这是用户原构思，回答共同增强数据下的系统表现与主干解冻收益。
3. **接着跑 B3、B4。** 区分主干解冻、接口容量及地图方案的整体作用；排序始终跟随有无地图，不单独消融。B1 对 B0 同时改变地图、训练范围与输出，不能独立归因。
4. **再跑 B5、B6、B7。** 判断新增覆盖是否同时帮助各条线，以及是否缩小差距。
5. **关键差值补种子。** 固定训练预算和评测口径后复验，不通过逐组续训或改配方追求地图获胜。

| 观察到的结果 | 能支持的判断 |
|---|---|
| B2 优于 B1 | 此共同配方下，解冻主干有益 |
| B4 优于 B0 | 无地图时，增加可训练接口本身有益 |
| B1 优于 B3，或 B2 优于 B4 | 对应训练范围下，地图＋排序监督的整体作用有益；不能拆出纯地图内容收益 |
| B2 优于 B0，但与 B4 接近 | 收益可能主要来自新增接口，地图方案额外收益未确立 |
| 正常地图比反序更好且改变实际动作 | 模型实际使用地图内容；不等于地图方案必然优于无地图训练 |
| B1/B5、B2/B6、B0/B7 有正向差值 | 新增任务情境有益；比较三种增益可判断谁更受覆盖限制 |
| 增强后的各组仍接近 | 接受该任务与预算下收益有限，不把历史差距全部解释成采样问题 |

**完成标准：得到一组共用数据、范围明确、允许负结果的比较。** 数据更广、示范更短和 loss 更低都不是地图方案更好的替代指标。
