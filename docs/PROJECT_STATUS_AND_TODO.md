## 3. 已确定的比较原则

- 现有基线使用共同增强数据、相同任务输入与标准 assistant token 平均 CE；有地图输出排序、依据和动作，无地图输出依据和动作。会议提出的简化监督仍属后续候选，不覆盖既有运行。
- 地图版本统一且冻结；比较主干训练范围与接口条件。地图输入和排序监督一起变化，差值解释为整体方案收益。
- 监测题固定。现有平台期规则仍只作标记；常规收尾不另开会，异常情况再沟通。不因低 loss 或部分评测峰值宣称任务收敛。
- 历史实验与新实验分别记录。当前状态、动作后继由环境提供，现阶段不据此声称模型学会自主状态维护或内部搜索。

## 4. 有序 TODO

1. **收尾 B4 与改进 B1。**确认收敛后的完整评测结果和实际训练长度；运行细节只更新对应实验报告，常规进展无需专门会议。
2. **验证数据缩减是否保留 B2 收益。**采用会议确定的小数据规模，检查完整集能否仍达九十多；不把降低数据量、放宽示范筛选和改变输出格式混作一个可归因结论。
3. **补 7B 全参 CoT 强基线。**数据、设备与 batch 的会议规格见讨论稿；执行前形成已提交配置。模型规模、监督长度与地图条件的影响分开解释。
4. **验证新任务可行性。**已有寻路、积木，先加汉诺塔；八数码、2×2 魔方及搬运等候选的取舍见调研建议。先验证真实地图，再验证全参 SFT，任务选择尚未全部确定。
5. **形成多任务联合训练与留出协议。**区分已训练任务 OOD 和未参与任务 SFT 的新任务；分别记录地图与 LLM 的曝光，明确匹配基线和 SOTA 比较范围后再执行。

FLAN 定向调研已写入讨论稿；地图机制的更细拆分、额外编号诊断与补种子后移，按具体失败需要安排。本次只更新决策与研究依据，未启动新运行或修改正式训练配置。
