## 当前主线

研究显式状态地图能否帮助 LLM 学习状态关系，并迁移到新目标、新任务。各任务独立训练 Qmap，同一个 LLM 通过 cross-attention 读取地图。环境提供真实状态与合法后继，现阶段检验关系读取、动作选择和完整任务完成，见[研究简述](RESEARCH_BRIEF.md)。

目前主体是积木、二阶魔方、8-Puzzle、寻路的四任务联合 SFT。下一阶段按约8–9类任务组织，并在大类中包含不同目标或子任务。扩充以规则可表达、地图可验证、类别有差异为依据，简单任务也可加入；过桥、24点纳入候选。最终名单、每类数据分配、训练类别与留出类别尚待确定。

任务类别回答“学过哪种规则”，类内子任务回答“学过哪些目标要求”，具体题目才是起点、目标与实例。增加同类题量、增加目标变化、增加任务类别分别改变不同的覆盖范围。下一轮围绕这三个层次组织数据，现有四任务实验保持原条件。

## 训练与评测状态

以下运行状态最近核实于2026-10-24晚；它们是观测快照，实时状态由对应runtime提供。

- 原四任务三组训练已提前停止。1.5B和3B原目录保留恢复文件；7B仅查到150K推理权重，原停止点无完整恢复文件。节点、保留范围与核对时间见[SFT报告](../experiments/map_sft_baselines/results/report.md#原训练停止与恢复条件)。

- 150K重评测中，地图1.5B和文字3B已完成，7B尚有未完成题集。完整分项与未完成项在报告中区分。
- 推箱子固定混合分布的检查已完成既定预算：训练拟合继续改善，连续执行仍弱，未见布局没有共同收益；见[推箱子报告](../experiments/new_tasks_qmap/results/sokoban/report.md#固定混合分布的收敛检查)。
