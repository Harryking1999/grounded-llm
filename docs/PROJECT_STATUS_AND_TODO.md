## 当前目标

研究“有语义的模型加上状态认知，是否比只有语义的模型更好”。当前阶段首先扩大积木与路径的独立样本覆盖，对每题进行多次直接 API 采样，寻找闭源模型稳定失败、结果易核验的反例，为后续研究建立动机。一次性输出完整计划是本阶段的正式初测协议；状态网络、闭环交互和机制消融在后续推进。死局陷阱用于离线诊断与 case study，不以陷阱评分筛选主要 API 样本。

长期目标是让一个共享状态模型帮助模型构建对世界的认识，增强空间与状态认知：从观测和交互历史形成内部状态、预测动作影响，在推理时先进行虚拟演算，实际行动后再利用真实反馈校准认知。通过多任务训练检验迁移能力，交互中的持续参数学习仍是后续目标。研究定义、参考机制和证伪标准见 [研究简述](RESEARCH_BRIEF.md)。

## 已确定的研究决策

- **训练范围**：冻结 LLM 原有参数，仅训练状态网络及其与 LLM 之间的转换接口。具体架构、损失、训练顺序和预算尚未确定；参考工作的 `Q/V` 与直接误差更新仍只是候选机制。
- **推理与实际交互**：接收真实观测并更新内部状态认知，在推理中先想象候选动作及后续状态，再选择实际动作。实际执行后可以获得真实反馈／新观测，校准认知并进入下一轮。可以只执行计划中的一步或一段；不要求一次性规划完全部任务。推理中尚未执行的虚拟动作由内部模型演算后果，与实际动作后的真实反馈分开记录。
- **路径选择与范围**：整体推理方案包含多路径采样和外部奖励工具筛选；采样与评分工具的优化不属于核心研究贡献，并非禁止使用。会议明确以相同采样次数比较基线和新模型。路径奖励与“可以执行”的判据尚未定义；具体对照设计见下方初测原则及研究简述中的建议。
- **近期顺序**：积木是必测项，与 32 节点路径任务优先开展初测。直接用 GPT 等顶级闭源模型 API 做英文纯语言基线，初测不以小模型替代；再依据失败定位深入训练。复杂候选任务暂缓，棋类不作为近期主攻方向。
- **时间安排**：初期不设硬截止日期。每周五前汇总进展并向导师反馈属于沟通节奏，不作为必须取得正结果的实验期限。

本轮全部完成：64 个实例各八个完整答案，共 512 个，已全部重放。原始 8 块积木成功 99/128、pass@8=15/16；生成 12 块成功 72/128、pass@8=15/16。两组分别有 86、71 个合法成功答案超过生成块数，均正常计入。原图最短路成功 116/128、pass@8=16/16；一个开关成功 60/64、pass@8=8/8；两个开关成功 40/64、合法到达 55/64、pass@8=7/8。逐题结果与实际 token 用量见研究 [`results/summary.json`](../experiments/gcml_counterexamples/results/summary.json)。连接／服务失败单独保留，补齐时未重采已完成的模型失败。

三个八次全失败的实例是原始积木 row18465、12 块 generated025、双开关 layout0 的初始 `[0,0]`。后者在配对初始 `[1,0]` 下八次全部到达、七次最短；`[0,0]` 的最短解仅七步，八个失败答案的合法前缀开关报告全部正确，却随后穿过关门边。积木中共有 30 个答案、16 个不同棋盘出现合法动作造成死局；所有首次死局都已有无法被任何形状覆盖的格子。本轮有明确的状态与动作一致性、即时后果和子目标协调诊断点，尚不能声称这些死局必须深层搜索才能发现。完整反事实后缀与图示见研究分析产物。

当前判断：暂不增加 16 块。先用相同棋盘的等价坐标表示、状态更新与动作前提检查，以及死局前状态的继续规划，区分观测编码、转移／合法性和规划中的改进空间。8 块与 12 块来自不同生成分布，其成功率差异不能只归因于块数。当前证据足以支撑本项目继续做状态增强研究；方法增益与共享迁移仍待后续验证。

## 初测与后续对照原则

- 从现有代码抽取少量可核验的实例，先明确输入、合法动作和成功条件。环境负责执行真实动作并返回约定的新观测，参考答案与解题器供裁判使用；推理中查询未执行动作的精确结果应单独记录。
- 兼顾任务挑战性与状态表示的简洁性，优先选择能清楚定义状态与动作、便于后续状态网络建模的任务。
- 当前前期测试使用英文规则、完整观测和一次性完整计划，按正式配置匹配每题采样次数与推理设置。它用于寻找可复现的任务失败；后续状态增强方法的交互对照再让双方按同一规则获得真实动作后的反馈，并分别记录内部想象与实际执行。
- 优先寻找需要空间想象与持续状态更新的任务。信息不全时，明确缺失信息能否从历史推断或通过动作获取；若不能确定答案，应评估不确定性处理，不能把猜错直接解释为状态认知缺陷。
- 同时记录成功与失败、格式错误与非法动作，检查状态维护、单步转移和目标判断；按需用等价表述或显式状态记录定位失败，避免只靠题目难度推断机制。
- “寻找做不好的任务”是任务筛选策略。后续比较需使用独立实例，保留初测中模型做好的结果，避免把筛选后的失败率推广为普遍能力结论。
