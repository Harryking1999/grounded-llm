## 当前主线

研究显式状态地图能否帮助 LLM 学习状态关系，并迁移到新目标、新任务。各任务独立训练 Qmap，同一个 LLM 通过 cross-attention 读取地图。环境提供真实状态与合法后继，现阶段检验关系读取、动作选择和完整任务完成，不把环境能力算成模型能力。见[研究简述](RESEARCH_BRIEF.md)。

目前主体是积木、二阶魔方、8-Puzzle、寻路的四任务联合 SFT。下一阶段考虑扩到约8–9类任务，并在类内设置不同目标或子任务；名单、训练分配和留出类别尚未定案。扩充以规则可表达、地图可验证、类别有差异为依据，不再把“强文字模型做不出”作为所有任务的准入条件。过桥、24点可以纳入候选；首轮结果不等于已有可采用地图。

## 训练与评测状态

- 原四任务三组训练已提前停止，不能写成“已收敛”。1.5B和3B原目录保留恢复文件；7B仅查到150K推理权重，原停止点无完整恢复文件。节点、保留范围与核对时间见[SFT报告](../experiments/map_sft_baselines/results/report.md#原训练停止与恢复条件)。
- 三组稀疏 cross-attention 是正在运行的独立对照，检验减少接入层后的学习表现；参数见[配置](../experiments/map_sft_baselines/configs/flan_four_50k_sparse_crossatt.json)，运行与结果从[实验入口](../experiments/map_sft_baselines/README.md#flan-15b-稀疏-cross-attention)读取。尚不能宣称比原方案更好。
- 150K重评测中，地图1.5B和文字3B已完成，7B尚有未完成题集。完整分项与未完成项在报告中区分，不将部分成绩或原验证／小OOD混合总分用于判胜。
- 推箱子固定混合分布的检查已完成既定预算：训练拟合继续改善，连续执行仍弱，未见布局没有共同收益；不足以判断充分收敛。见[推箱子报告](../experiments/new_tasks_qmap/results/sokoban/report.md#固定混合分布的收敛检查)，不自动延长或换方案。

## 接下来的顺序

1. **收齐已有比较。** 完成已安排的150K分项评测，观察稀疏注意力既定节点；分别比较原任务、换目标、到达与正确停止。判断收敛须看匹配条件下连续多个完整评测点，缺失的200K评测不补造。
2. **明确扩任务方案。** 从已有十个任务入口中选择约8–9类的候选组合，先明确每类状态、动作、目标与地图可用范围；简单任务也可贡献类别多样性。单列训练类别、类内留出目标与未训练类别，不能用固定目标复原替代任意目标学习。24点仅支持探索运算状态空间，不直接外推一般数学推理。
3. **再决定后续训练。** 稀疏实验获得可比较结果后，若无更优先安排，再评估补训7B；首先查找完整恢复副本。若只能从推理权重开始，须作为重建优化状态的新阶段提出，不能冒充无损续训。本页不授权启动新任务训练、扩预算或抢占现有资源。

地图改进服务于上述问题。推箱子的更多局部诊断不自动成为项目主线；是否继续投入，依据它能否提供本轮需要的任务类别和可验证地图决定。已有负结果、旧积木数据量对照、魔方近目标对照保留在各自报告，不在这里逐次展开。
