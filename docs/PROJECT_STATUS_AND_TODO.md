## 当前目标与已确定决策

检验显式状态认知能否改善 LLM 的状态估计、动作后果预测和规划。已完成多组纯语言完整计划基线；尚未训练状态网络，也未验证状态增强或跨任务迁移的因果增益。研究定义与证伪标准见 [RESEARCH_BRIEF.md](RESEARCH_BRIEF.md)。

- 冻结 LLM 原参数，只训练状态网络及转换接口。近期积木讨论提出状态／关系报告适配后直接测规划，图任务提出先验证地图方向性再接 LLM；均尚未形成新的正式训练合同。
- 长期交互方案是观测后更新内部状态、行动前想象候选后果、真实行动后用反馈校准。一次性完整计划是当前基线协议，不是后续方法的唯一交互形式。
- 状态估计、转移预测、目标判断、规划和动作表达分别评估。自报状态正确不保证动作合法，任务失败不能直接证明缺少世界模型。
- 多路径采样与奖励筛选可作整体方案，但需匹配采样、预算和工具信息；候选中有正确答案与筛选成功分别报告。
- 用户已授权官方 Qwen3-4B/8B/32B thinking 基线，更新了早期先测闭源模型的阶段安排。本次验收范围为最终双向 path256 与 blocks 16k，其他预算条件不混报。

## 最新讨论及其边界

- **积木**：用完整二值状态和固定动作规则更新状态，主要研究冻结 LLM 如何使用状态接口，不主张学会了积木动力学。优先短、结构化的动作输出是工程候选，不是“线性状态不能配推理模型”的理论限制。
- **抽象图**：从探索轨迹学习表示；先检验目标条件下的动作排序和到达能力，再接 LLM。近期方案首先测同图未见起终点的合法到达；最短性作效率指标，与旧 path256 最短路合同有区别。
- **架构**：输入层 state tokens、外部 memory/cross-attention 是主要候选；飞书新增动态连续提示／LoRA 讨论。转移拟合、向量距离和规划能力不能等同。共享跨任务模型仍是后续目标。

Blocks 实际触顶 511/768（66.54%），其中 92 条已在最终答案前缀确认非法，优先归为非法。加上完整答案，至少 343 条非法；另有 6 条合法未清空、419 条截断原因未决。Path 有 4 条触顶输出在截断前已确定不可能最短。触顶作为资源标签另报，不覆盖已确认错误。

可见思考和最终动作分别暴露坐标读取、约束利用、重复移除、状态报告与计划收尾问题。人工思考检查是定向案例审阅，非全量逐句标注；未决截断不能解释为纯预算不足。监控已由前序任务停止，本次没有新增推理或训练。

## 有序 TODO

以下是结合新讨论的建议顺序，不代表已授权启动训练。

1. **明确积木最小对照**：复用现有裁判，固定形状集合、动作边界、目标和反馈协议；比较准确文字状态闭环与状态接口，匹配信息和预算。一次性完整计划保留为独立协议。
2. **定位状态使用问题**：分别测解析、状态报告、单步转移、合法性和目标判断；状态正确仍违规的案例不能归为单纯遗忘。保持预算触顶标签与失败归因分开。
3. **验证最小接口**：建议先做输入层 state tokens，按讨论只训练状态／关系报告，再测未见状态和规划；检查打乱当前状态、替换目标是否改变动作。若报告改善却规划不变，如实保留这一分离，再决定是否需要 cross-attention。
4. **独立检验图地图**：先确认探索覆盖、转移预测及目标条件下的动作排序；用非 LLM 选择器检验地图能否到达目标，再比较 LLM 读取地图的增益。不能用 Q/V 一致性损失替代方向性证据。
5. **有机制证据后扩展**：再考虑跨图、共享跨任务模型与在线参数学习。持续调研围绕实际瓶颈展开，不以输入模态排除相关工作。

翻花绳、华容道、鲁班锁与棋类暂缓；进入前先明确状态、观测和动作定义。路线图仅保留[候选设计](../PROJECT_ROADMAP.md)，不维护第二份进度或时间承诺。
