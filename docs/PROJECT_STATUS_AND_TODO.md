## 当前主线

研究显式状态地图能否帮助 LLM 学习状态关系，并迁移到新目标、新任务。各任务独立训练 Qmap，同一个 LLM 通过 cross-attention 读取地图。环境提供真实状态与合法后继，现阶段检验关系读取、动作选择和完整任务完成，见[研究简述](RESEARCH_BRIEF.md)。

目前主体是积木、二阶魔方、8-Puzzle、寻路的四任务联合 SFT。下一阶段确定为九类任务：保留上述四类，加入推箱子、移车出库、棋子交换、过桥和24点。各大类包含不同目标、起始阶段或结构的小类；过桥和24点采用正常难度。汉诺塔保留为已有能力与后续扩展项。每类数据分配与训练／留出小类在准备阶段落实。

任务类别按规则组织，小类覆盖目标、地图结构和规模变化，具体题目给定起终点与实例。寻路、棋子交换以新图及对应新Qmap检验迁移；推箱子按固定墙体独立训练地图、检验墙体内新关系与目标；移车出库以同一任务Qmap的输入编码检验新棋盘；过桥、24点加入中间目标及新人数／操作数规模地图。共享Qmap通过多起终点、动作边、完整分支和可达关系形成更广的状态结构，训练设计见[Qmap方法与任务扩展](../tasks/QMAP_METHOD.md#任务扩展与训练安排)。

## 训练与评测状态

以下运行状态最近核实于2026-10-25；它们是观测快照，实时状态由对应runtime提供。

- 原四任务三组训练已提前停止。1.5B和3B原目录保留恢复文件；7B仅查到150K推理权重，原停止点无完整恢复文件。节点、保留范围与核对时间见[SFT报告](../experiments/map_sft_baselines/results/report.md#原训练停止与恢复条件)。
- 三组稀疏 cross-attention 已停止训练和后续评测。同为100K时，每2层略高于每层，每4层总体接近；最后3层只有早期评测，不能判断后期能力。结果见[SFT报告](../experiments/map_sft_baselines/results/report.md#8-稀疏cross-attention的同预算比较)。
- 文字3B从完整停止断点续训；7B从150K权重开始动量近似初始化的新优化阶段，按原预算补齐。7B的学习率接原时程，不能视为原优化器的完整恢复，参数见[配置](../experiments/map_sft_baselines/configs/flan_four_50k_7b_adam_calibration.json)。
- 150K重评测中，地图1.5B和文字3B已完成，7B尚有未完成题集。完整分项与未完成项在报告中区分。
- 推箱子固定混合分布的检查已完成既定预算：训练拟合继续改善，连续执行仍弱，未见布局没有共同收益；见[推箱子报告](../experiments/new_tasks_qmap/results/sokoban/report.md#固定混合分布的收敛检查)。
- 五类新任务已接通普通完整目标与多目标精确标签。五人和六人过桥分别通过独立完成及成本验收；移车几何编码消除了已测命名依赖，但跨布局没有改善，训练覆盖已扩至1,000个独立车辆配置组并保留原整布局留出；推箱子动作边仍未解决原始起点执行。24点改为明确的查询目标关系留出后，原起点有所改善，固定24仍弱。棋子交换在原端点保护条件下使用完整循环分支及L1读出，已通过扩大冻结完成率验收并采用原树地图，残余循环和成本缺口单列；另一棵树独立地图也通过冻结完成率验收，原LLM读取新图仍待验证。均未新增LLM评测。证据与限制见[分任务报告](../experiments/new_tasks_qmap/results/report.md#按任务阅读)，原多目标运行见忽略的 `runs/new_tasks_qmap/multigoal_runtime_40048.json`，扩量与分支拟合运行见 `runs/new_tasks_qmap/followup_runtime_40048.json`。
