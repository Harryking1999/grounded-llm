## 当前目标与已确定决策

检验显式状态认知能否改善 LLM 的状态估计、动作后果预测和规划。已完成多组纯语言完整计划基线及独立 Q/V 图地图学习；尚未训练 LLM 状态接口，也未验证状态增强或跨任务迁移的因果增益。研究定义与证伪标准见 [RESEARCH_BRIEF.md](RESEARCH_BRIEF.md)。

- 冻结 LLM 原参数，只训练状态网络及转换接口。近期积木讨论提出状态／关系报告适配后直接测规划，图任务先验证地图远近结构再接 LLM；积木已有具体试点提案，尚未实现或启动训练。
- 长期交互方案是观测后更新内部状态、行动前想象候选后果、真实行动后用反馈校准。一次性完整计划是当前基线协议，不是后续方法的唯一交互形式。
- 状态估计、转移预测、目标判断、规划和动作表达分别评估。自报状态正确不保证动作合法，任务失败不能直接证明缺少世界模型。
- 多路径采样与奖励筛选可作整体方案，但需匹配采样、预算和工具信息；候选中有正确答案与筛选成功分别报告。
- 用户已授权官方 Qwen3-4B/8B/32B thinking 基线，更新了早期先测闭源模型的阶段安排。本次验收范围为最终双向 path256 与 blocks 16k，其他预算条件不混报。

- **架构**：输入层 state tokens、外部 memory/cross-attention 是主要候选；飞书新增动态连续提示／LoRA 讨论。转移拟合、向量距离和规划能力不能等同。共享跨任务模型仍是后续目标。

**重跑补充已完成：四个条件共 64 张地图，全部后继节点识别均为 100%。** 512 节点图上，局部更新 128／1000／2048 维的距离相关均值为 0.559／0.585／0.590，完整梯度 1000 维为 0.541；详细转移误差见[更新后的报告](../experiments/cml_map_scaling/results/report.md)。探索判断仅限本次 Step 1。已准备 [Step 2 接口调研与讨论稿](../experiments/cml_map_scaling/STEP2_DISCUSSION.md)，尚未启动适配训练。下面保留首轮基线概况。

| 随机图节点数 | 距离秩相关（图间均值） |
| --- | ---: |

全部规模、全部重复均较随机初始化获得距离相关提升。全部节点和有向动作均被探索，最终转移 MSE 低于 3×10⁻¹⁰，训练合计约 105 秒 CPU。已保存的地图和规模基线支持推进下一步地图／状态适配。

简单余弦选择器作为补充参考：原图到达 990/992 对起终点，随机图随规模从 100% 变化至 51.36%。复杂图的逐步路径选择对读出方式提出额外要求，该指标不作为本阶段地图学习的成败判据。完整结果与实现口径见研究报告。
