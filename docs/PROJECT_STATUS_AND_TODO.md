## 后续研究

- 任务内OOD与多任务训练分别核对地图和接口的训练信息范围；跨任务迁移只在对应规则、地图和未见题集准备后评测。
- **三个新任务均未通过地图验收。** 推箱子在扩展的100张未见布局上完成37.89%，21步及以上仍失败；移车出库未见布局54.59%，固定10顶点树的棋子交换主要组约68%–69%。每题均指定完整目标，各必需组至少80%、目标90%以上；暂不接入LLM。规则见[任务入口](../tasks/README.md#三个新任务)，结果与证据见[三任务报告](../experiments/new_tasks_qmap/results/report.md)。
- **持续改进推箱子，目标为各必需组到达率超过90%。** 64张与1,000张训练棋盘同题对照已完成，未见布局从29.88%提高到37.89%，长期规划仍未解决。先完成同目标相邻状态成组监督的对照，再根据训练轨迹中的循环、错误分支与死锁补数据，兼顾近目标、长距离和棋盘覆盖；每轮先查失败原因，再做有限预算的可比验证。验证与测试关系及其候选闭包不加入训练；测试不用于逐轮选方案，已反复查看的题只作回归，最终泛化需独立留出验收。配置见[实验入口](../experiments/new_tasks_qmap/README.md#推箱子覆盖量对照)。移车出库与棋子交换暂不追加；移车出库未完成的编码对照仍无最终成绩。具体运行记录由对应runtime维护。
- 过桥与24点保留已有调查和首轮结果，暂不扩展；其他候选见[任务调查](../tasks/README.md#新任务候选难度与地图关系)。
