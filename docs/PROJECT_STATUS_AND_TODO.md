# 项目状态与有序 TODO

更新于 2026-09-29。本页只记录当前结论与下一步；研究定义见[研究简述](RESEARCH_BRIEF.md)，正式参数见各实验的 `configs/`。

## 当前结论

**积木共享 Q-map 已完成跨棋盘封存评测。**在原论文八种简单形状下，用 1,000 张棋盘训练共享 Q、200 张开发棋盘选权重，再在另一批 200 张新棋盘测试。4,355 道不同起点和目标的题中，完整到达 3,928 道（90.2%）；第一步后仍可达 4,167 道（95.7%），第一步在最短路上 3,812 道（87.5%）。清空目标为 99.0%，普通非空目标为 89.6%，含孤立格的非空目标为 81.6%。当前 Q 能指导许多未见棋盘上的选择，但非空目标和长程关系仍是短板。本轮由规则提供合法后继，只训练 Q；V 和 LLM 尚未参与积木决策。数值、图和案例见[结果报告](../experiments/blocks_distance_map/results/report.md)。

**寻路逐节点地图插入五图测试正在运行。**已完成的旧五图逐步协议共 5,760 条，Instruct 无地图／有地图最短路 pass@1 为 26.98%／33.49%；它要求整条最短路，却每步重新生成一次答案，结果见[旧五图报告](../experiments/external_map_interface/results/path256_five_graphs.md)。当前[新合同](../experiments/external_map_interface/configs/path256_continuous_five_graphs.json)改为整题累计预算：两个无地图组一次生成完整路径，两个地图组在提交节点后由控制器插入真实状态和候选 learned-map 距离。五图 120 题，每题 16 次、四组共计划 7,680 条；重启恢复前保存的 2,188 条已全部通过独立重放，队列从已有记录续跑。

前三次重复均已覆盖全部 120 题，四组各 360 条。这个**阶段性**对照如下；“最短路”以全部 360 条为分母。

| 条件 | 合法到达 | 最短路 | 16k 截断 |
| --- | ---: | ---: | ---: |
| Instruct 无地图 | 271/360 | 146/360 | 40 |
| Instruct＋地图 | 247/360 | 116/360 | 59 |
| Instruct＋地图，优先最小距离 | 354/360 | 139/360 | 2 |
| Thinking 无地图 | 226/360 | 158/360 | 133 |

普通地图组在提交首步前生成的 token 中位数为 5,564，优先最小距离组为 9；普通地图组 59 次截断中有 58 次尚未提交任何动作。明确的局部选步规则显著改变了输出行为，但高到达率并未对应更高的最短路率。地图组有逐节点反馈，优先组还多一条选最小距离的指令，当前不能把组间差异单独解释为地图质量。完整结果须等 7,680 条全部完成并重放后再定稿。

## 有序 TODO

1. **完成寻路正式运行并全量重放。**按冻结合同汇总合法到达、最短路、绕路、失败类型和 token 成本，更新五图报告；保留所有失败样本。
2. **定位地图信息与提示词规则各自的作用。**在同一逐节点协议下，比较“立即提交动作但不规定选最小距离”与“优先最小距离”，再用距离扰动检查成绩是否依赖正确地图。先固定小样本与评测合同，再决定是否扩大运行。
3. **分析积木 Q 的非空目标错误。**使用既有开发题定位清空、长程、普通非空及孤立格关系的取舍，再决定是否调整训练配比；封存题不用于重新选权重。
4. **固定 Q 后再单独检验 V。**验证预测后继坐标是否保住 Q 已有的候选排序，然后才评估 LLM 读取积木地图的收益。
