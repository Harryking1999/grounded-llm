训练覆盖核对：256 条训练题共 3436 个动作轮，其中三候选仅 256 个，全部为首轮；首轮最近候选编号为 86/85/85，未见标签编号失衡。最终权重在全部 256 条训练题首步上逐对远近仅 783/1536、完整排序 19/256、最近候选 93/256，说明训练内关系本身尚未拟合。当前不能把问题简化为“多训练几轮”或“只缺数据”：中期 checkpoint 231 在同 20 道保留首题上选对 8 道，最终权重仅 1 道。[关系 token 加权的整题 SFT 消融](../experiments/flamingo_map_reader/configs/pilot_path256_relation_weighted.json)使用同一 256/64 条记录完成独立 512 次更新，运行目录为 `runs/path10_relation_weighted_20261002`。验证首步合法排序 55/64、逐对 150/384、最近候选 12/64，低于原配置的 64/64、183/384、18/64；不再扩大该消融的正式评测。20 条保留题的 Q 交换诊断只有 12 条交换前后都有合法动作，其中 4 条动作改变；不能把格式失败计为地图敏感。目标 token 对齐和一条 11,519 token 长题的完整前后向 smoke 已验证，显存峰值约 55.5 GiB。

原权重 28 层 gate 的平均 `|tanh(g)|` 为 0.006507；加权消融后为 0.006423。零 gate 初始使地图投影和 cross-attention 首步得不到任务梯度，但单看 gate 数值不能证明最终地图残差很小。固定 `tanh(g)=0.1` 对照保持同题、同普通损失和其他超参数，从首步放开地图分支梯度；固定幅度是机制试验，不预设 0.1 为最优值。

固定 gate 对照已完成 512 步，运行目录 `runs/path10_fixed_gate_20261002`。验证首步逐对远近 187/384、最近候选 23/64，原配置为 183/384、18/64；训练首步 839/1536、101/256，仍未拟合。20 道保留题的 Q 交换使动作改变 4 次；原配置为 1 次，但 3 道原本选对最近候选的题在交换后均未转向新的最近候选。原模型 4 个验证首步的地图残差／hidden 层中位数约 0.83%，第一层约 25%；固定 gate 后层中位数约 1.7%，第一层约 78%。因此 gate 数值不是地图通道完全关闭的证据，固定放大也未建立可靠读出。

投影 P 在原／固定 gate 验证首步上分别保留 318/384、322/384 个逐对关系，最近候选为 52/64、54/64；经过仅状态的组合线性变换仍为 310/384、316/384 和 51/64、50/64。把角色与编号也计入融合向量的欧氏距离后，两组均降至 192/384 和 22/64。这只说明整体向量的**欧氏几何**受到标签偏移干扰，不证明 cross-attention 无法恢复状态关系。下一步按用户决断分别为两题测试地址 key 与状态 value 分离，固定文字交换 Q 和同步重编号用于检验是否真正读图。
