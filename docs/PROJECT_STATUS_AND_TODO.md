## 当前主线

研究显式状态地图能否帮助 LLM 学习状态关系，并迁移到新目标、新任务。各任务独立训练 Qmap，同一个 LLM 通过 cross-attention 读取地图。环境提供真实状态与合法后继，现阶段检验关系读取、动作选择和完整任务完成，见[研究简述](RESEARCH_BRIEF.md)。

当前主线是八类任务池的FLAN式泛化比较：地图1.5B的4／5／6类三组已完成训练与每组2000题终点自主执行验收，历史检查点与部分TF仍在补评。训练类别、50,000条轨迹的分配及25个小类只维护于[正式配置](../experiments/map_sft_baselines/configs/flan_generalization_50k.json)。本轮没有同条件文字3B／7B与DeepSeek结果。三组整类留出均未正确完成任务；6类在六人过桥有改善，但魔方训练内表现较弱，增加类别的收益不一致。后继架构实验固定5类50k预算，采用最新地图重建认证轨迹，先实现并启动4层共同／配对编码、K/V来源与全参／冻结8组；2层仅作备用。设计与配置见[地图编码实验](../experiments/map_encoder_sft/README.md)。

积木异或、魔方目标相对编码与逆对称、华容道目标规范化的地图结果已核对，后继采用对应selection条件。新地图SFT已完成全部向量槽位的目标变换，并重建认证50k轨迹，任务、小类与精确成本分布匹配；起终点保留及路径覆盖变化见[制备结果](../experiments/map_encoder_sft/results/data_preparation.json)。移车跨布局、推箱子能力保持与目标迁移继续列为待办。过桥、棋子交换、寻路和算术沿用已采用条件。新旧比较见[任务入口](../tasks/README.md#本轮flan旧地图与后继新条件)。

## 训练与评测状态

Flan与新地图结果核对于2026-10-29。平台持久结果可读，但本次连接的开发节点身份已不同于历史runtime，未见原训练进程；推箱子最新持久进度并非终点验收，不能沿用历史“training”字段推断仍在运行。

- 原四任务三组训练已提前停止。1.5B和3B原目录保留恢复文件；7B仅查到150K推理权重，原停止点无完整恢复文件。节点、保留范围与核对时间见[SFT报告](../experiments/map_sft_baselines/results/report.md#原训练停止与恢复条件)。
- 三组稀疏 cross-attention 已停止训练和后续评测。同为100K时，每2层略高于每层，每4层总体接近；最后3层只有早期评测。结果见[SFT报告](../experiments/map_sft_baselines/results/report.md#8-稀疏cross-attention的同预算比较)。
- 原文字3B及7B补训均已完成250K、20轮。3B为完整恢复续训；7B是150K权重后的动量校准阶段。按用户授权删除旧已评和待评中间张量，终点、完整恢复文件及已有答卷保留；终点评测未完成部分仍单列。
- 150K重评测中，地图1.5B和文字3B已完成，7B尚有未完成题集。完整分项与未完成项在报告中区分。
- 移车80K接续完成，按原验证标准选择54K，跨布局仍未通过；推箱子36K完整逐题结果已核对，后续训练尚无终点结果。采用条件仍由selection维护，见[各任务报告](../experiments/new_tasks_qmap/results/report.md)。
- 028和4090的旧Flan评测已停止，为新encoder实验释放资源；4／5／6类仅保留各自完整ID最优与终点推理权重，以及最新完整恢复状态。终点RO与已完成ID曲线的逐题计数已收齐；未完成节点不参与“已评最佳”选择。

## 推进安排

| 工作 | 顺序与目的 | 需要得到的结果 |
|---|---|---|
| Flan历史结果 | 保留已有答卷与完整节点结论；旧中间权重已清理，不继续补评这些节点 | 不用局部节点或OOD选模，不重复训练 |
| 地图encoder架构 | 固定5类50k，先4层共同／配对编码×K/V来源×全参／冻结8组，首批三个全参组合 | [设计与实现](../experiments/map_encoder_sft/README.md)；2层不自动启动 |
| 新地图SFT接入 | 魔方／华容道目标坐标覆盖全部槽位；各组共用最新已采用地图与重新认证的50k轨迹，匹配原起终点分布和覆盖 | 向量、动作编号、排序和停止监督一致；旧Flan结果保持原条件 |
| 剩余地图缺口 | 积木清空门槛、移车跨布局、推箱子能力保持与目标迁移继续单列 | 先核实开发节点及持久断点；不以历史运行状态重启 |
| 同条件强基线 | 旧3B／7B补训已完成且终点恢复文件在；本轮文字3B／7B及zero-shot强模型尚无匹配结果 | 另经确认开展比较，不使用旧题集成绩冒充本轮结果 |
