## 当前目标

研究“有语义的模型加上状态认知，是否比只有语义的模型更好”。近期先使用参考 GCML 论文中的二维积木轮廓分解与 32 节点图路径任务，完成纯语言英文基线，寻找可复现的失败，并判断失败是否与状态维护、转移预测或规划有关，再决定状态网络的具体实现。

长期目标是让一个共享状态模型帮助模型构建对世界的认识，增强空间与状态认知：从观测和交互历史形成内部状态、预测动作影响，在推理时先进行虚拟演算，实际行动后再利用真实反馈校准认知。通过多任务训练检验迁移能力，交互中的持续参数学习仍是后续目标。研究定义、参考机制和证伪标准见 [研究简述](RESEARCH_BRIEF.md)。

## 已确定的研究决策

- **训练范围**：冻结 LLM 原有参数，仅训练状态网络及其与 LLM 之间的转换接口。具体架构、损失、训练顺序和预算尚未确定；参考工作的 `Q/V` 与直接误差更新仍只是候选机制。
- **推理与实际交互**：接收真实观测并更新内部状态认知，在推理中先想象候选动作及后续状态，再选择实际动作。实际执行后可以获得真实反馈／新观测，校准认知并进入下一轮。可以只执行计划中的一步或一段；不要求一次性规划完全部任务。推理中尚未执行的虚拟动作由内部模型演算后果，与实际动作后的真实反馈分开记录。
- **路径选择与范围**：整体推理方案包含多路径采样和外部奖励工具筛选；采样与评分工具的优化不属于核心研究贡献，并非禁止使用。会议明确以相同采样次数比较基线和新模型。路径奖励与“可以执行”的判据尚未定义；具体对照设计见下方初测原则及研究简述中的建议。
- **近期顺序**：积木是必测项，与 32 节点路径任务优先开展初测。直接用 GPT 等顶级闭源模型 API 做英文纯语言基线，初测不以小模型替代；再依据失败定位深入训练。复杂候选任务暂缓，棋类不作为近期主攻方向。
- **时间安排**：初期不设硬截止日期。每周五前汇总进展并向导师反馈属于沟通节奏，不作为必须取得正结果的实验期限。

会议认可翻花绳的图抽象可行性，并提出三维坐标直线表征；这是待实现、待验证的建模方案。“冷门任务未被模型预训练过”“人类空间想象优于模型”“方法可泛化到多模态与具身任务”“多模态方法不构成竞争”等仍是会议判断或研究假设，尚无本项目实验支持。英文测试用于统一实验语言，不能据此认定语言偏差已消除。

## 初测原则（整理建议，具体运行设置待确定）

- 从现有代码抽取少量可核验的实例，先明确输入、合法动作和成功条件。环境负责执行真实动作并返回约定的新观测，参考答案与解题器供裁判使用；推理中查询未执行动作的精确结果应单独记录。
- 兼顾任务挑战性与状态表示的简洁性，优先选择能清楚定义状态与动作、便于后续状态网络建模的任务。
- 使用英文规则、观测、目标和回答格式，在相同信息与预算下测试纯语言模型；基础模型与状态增强模型按同一规则获得实际动作后的真实反馈。观察每轮推理中的状态认知、想象与动作选择；一次性完整解可作补充诊断，不替代正常反馈交互或作为唯一要求。
- 优先寻找需要空间想象与持续状态更新的任务。信息不全时，明确缺失信息能否从历史推断或通过动作获取；若不能确定答案，应评估不确定性处理，不能把猜错直接解释为状态认知缺陷。
- 同时记录成功与失败、格式错误与非法动作，检查状态维护、单步转移和目标判断；按需用等价表述或显式状态记录定位失败，避免只靠题目难度推断机制。
- “寻找做不好的任务”是任务筛选策略。后续比较需使用独立实例，保留初测中模型做好的结果，避免把筛选后的失败率推广为普遍能力结论。
