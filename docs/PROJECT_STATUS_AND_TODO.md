## 当前主线

研究显式状态地图能否帮助 LLM 学习状态关系，并迁移到新目标、新任务。各任务独立训练 Qmap，同一个 LLM 通过 cross-attention 读取地图。环境提供真实状态与合法后继，现阶段检验关系读取、动作选择和完整任务完成，见[研究简述](RESEARCH_BRIEF.md)。

目前主体是积木、二阶魔方、8-Puzzle、寻路的四任务联合 SFT。下一阶段确定为九类任务：保留上述四类，加入推箱子、移车出库、棋子交换、过桥和24点。各大类包含不同目标、起始阶段或结构的小类；过桥和24点采用正常难度。汉诺塔保留为已有能力与后续扩展项。每类数据分配与训练／留出小类在准备阶段落实。

任务类别按规则组织，小类覆盖目标、地图结构和规模变化，具体题目给定起终点与实例。寻路、棋子交换以新图及对应新Qmap检验迁移；推箱子、移车出库以同一任务Qmap的输入编码检验新棋盘；过桥、24点加入中间目标及新人数／操作数规模地图。共享Qmap通过多起终点、动作边、完整分支和可达关系形成更广的状态结构，训练设计见[Qmap方法与任务扩展](../tasks/QMAP_METHOD.md#任务扩展与训练安排)。
