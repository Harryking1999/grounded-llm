## 当前主线

研究显式状态地图能否帮助 LLM 学习状态关系，并迁移到新目标、新任务。各任务独立训练 Qmap，同一个 LLM 通过 cross-attention 读取地图。环境提供真实状态与合法后继，现阶段检验关系读取、动作选择和完整任务完成，见[研究简述](RESEARCH_BRIEF.md)。

当前主线是八类任务池的FLAN式泛化比较：4类训练积木、二阶魔方、寻路、过桥；5类加8-Puzzle；6类再加棋子交换。当前仅运行地图1.5B的4／5／6类三个版本，分别从基座训练、同时各用两卡；文字3B／7B暂不运行。每版本50,000条轨迹、按大类均分，版本间从同一候选池取不同子集。各训练大类留一个小OOD，其他大类作整类OOD；移车和21／24点始终整类留出。参数和25个小类只维护于[正式配置](../experiments/map_sft_baselines/configs/flan_generalization_50k.json)。

推箱子继续搁置，反向放积木推迟；积木8块非空目标纳入训练、12块非空目标留出。原Qmap优化不恢复，过桥与棋子交换使用已采用的分人数／分树地图；为寻路留出图按原纯Q合同独立准备地图。地图能力、LLM读取和目标停止分开解释，动机与证伪标准见[研究简述](RESEARCH_BRIEF.md)。

## 训练与评测状态

新任务运行最近核实于2026-10-26，其余运行的核对日期见各结果报告；它们是观测快照，实时状态由对应runtime提供。

- 原四任务三组训练已提前停止。1.5B和3B原目录保留恢复文件；7B仅查到150K推理权重，原停止点无完整恢复文件。节点、保留范围与核对时间见[SFT报告](../experiments/map_sft_baselines/results/report.md#原训练停止与恢复条件)。
- 三组稀疏 cross-attention 已停止训练和后续评测。同为100K时，每2层略高于每层，每4层总体接近；最后3层只有早期评测。结果见[SFT报告](../experiments/map_sft_baselines/results/report.md#8-稀疏cross-attention的同预算比较)。
- 原文字3B及7B补训均已完成250K、20轮。3B为完整恢复续训；7B是150K权重后的动量校准阶段。按用户授权删除旧已评和待评中间张量，终点、完整恢复文件及已有答卷保留；终点评测未完成部分仍单列。
- 150K重评测中，地图1.5B和文字3B已完成，7B尚有未完成题集。完整分项与未完成项在报告中区分。
- 五类新任务Qmap优化已按用户要求暂停，推箱子搁置；没有遗留该轮训练进程。已有完整恢复断点与已选地图保留，未完成对照不增加采用范围。当前结果及关键负结果由[各任务报告](../experiments/new_tasks_qmap/results/report.md)维护；恢复来源与停止记录保存在忽略的runtime及原运行目录。
- 移车和21／24点分别采用已验证的限定范围。两棵树的棋子交换保留完成可用地图，追加最优效率验收仍未通过；过桥两个人数地图分别保留完成与成本结论。五类均尚无新增LLM读取结果。

| 最终比较 | 固定终点模型与题集，评冻结地图及zero-shot文字基线 | 同题报告成功、正确停止、最优成本和信息条件差异 |
