# 积木 Q-map：树关系补全后的跨棋盘结果

**总结果：**用 1,000 张棋盘训练同一个 Q 编码器，并补充树上的清空目标和较长距离关系后，选定续训 **15,000 步**权重。在完全未参与训练和选权重的 **200 张新棋盘**上，按起点、目标和真实最短步数分层的 **4,355 道任务，完整到达 3,928 道（90.2%）**。首步选完后目标仍可达的比例为 **4,167/4,355（95.7%）**。清空很强，但非空目标，尤其含孤立格的目标，仍是主要短板。

这是一份**本轮结果报告**。下文所有成绩都来自上述同一权重；旧的单棋盘实验结果、图和分母不并入本报告。

## 一眼看懂：先看总结果，再看步数

| 指标 | 正确／总数 | ACC |
| --- | ---: | ---: |
| 全部分层题完整到达 | 3,928/4,355 | **90.2%** |
| **第一步后仍可达** | 4,167/4,355 | **95.7%** |
| 第一步走在最短路上 | 3,812/4,355 | **87.5%** |
| 真实最短距离为 1 步：完整到达 | 600/600 | **100.0%** |
| 真实最短距离为 **2–4 步**：完整到达 | 1,656/1,800 | **92.0%** |
| 真实最短距离为 **5–6 步**：完整到达 | 1,024/1,200 | **85.3%** |
| 真实最短距离为 **7–8 步**：完整到达 | 648/755 | **85.8%** |

**总到达率**把同一批题的完整轨迹作为分母，是本报告的主结果；它不要求路径最短。**首步仍可达**只检验第一次选择，因此高于完整到达率是合理的：之后的动作仍可能出错。**首步最短路**更严格，说明模型有时会保留解但绕路。

**一步任务**全部到达，但这只涵盖真实距离为 1 的题。**2–4 步**仍有 92.0% 到达；**5–6 步**降到 85.3%；**7–8 步**为 85.8%。最后两组的目标类型和可采到的题数不同，不能把 85.8% 略高于 85.3% 解释成长程反而更容易。步数段互不重叠，4 步归 2–4，6 步归 5–6，8 步归 7–8。

## 同一封存题池：换目标会怎样

| 目标类型 | 完整到达／总数 | ACC |
| --- | ---: | ---: |
| 清空目标 | 1,515/1,530 | **99.0%** |
| 普通非空目标 | 1,213/1,354 | **89.6%** |
| 含孤立格的非空目标 | 1,200/1,471 | **81.6%** |

这些三类题加起来正好是上表的 4,355 道。清空目标的高分不能替代非空目标成绩；含孤立格的目标虽可能从某些起点到达，却不能被“把棋盘尽量清空”这条规则正确处理。

同一批 **200 张封存棋盘**还做了两项固定任务，便于直观看不同起点和目标：

| 固定任务 | 完整到达／总数 | ACC |
| --- | ---: | ---: |
| 每张棋盘 5 个未见非空目标 | 860/1,000 | **86.0%** |
| 从每张完整初始棋盘清空 | 193/200 | **96.5%** |
| 只按剩余面积选动作，同一 1,000 题 | 17/1,000 | **1.7%** |

固定非空目标任务按真实距离取 2、3、4、5 步，含普通目标 600 道、孤立格目标 400 道；其普通目标到达 534/600（89.0%），孤立格目标到达 326/400（81.5%）。完整初始棋盘清空达到 193/200，而只靠剩余面积的同题非空目标基线仅到达 17/1,000；Q 的表现不能用“只数格子”解释。广度题池另外覆盖到 8 步。这些任务使用**同一批封存棋盘**，不能把表中的分母相加当作独立棋盘数。

## 续训带来了什么，权重怎么选

原模型已经在 1,000 张训练棋盘上学习大量树分支、祖先和目标切换关系。本轮沿用它的 65,000 步权重，新增 **600,293** 条训练状态对，总训练关系达到 **2,776,757** 条。新增关系重点覆盖原树中薄弱的清空目标、清空前分叉和较长距离的非空目标。新增关系约占最终训练状态对的 **21.6%**；这是本轮使用的配比，**尚未做严格的配比消融，不能称为最优比例**。

用训练棋盘以外的 **200 张开发棋盘、4,385 道分层题**选择权重。下面是同一批题、同一评测规则的对照；“父权重”指续训前的 65,000 步权重。

| 开发集指标 | 父权重 | 续训 10,000 步 | **续训 15,000 步** |
| --- | ---: | ---: | ---: |
| 全部题完整到达 | 3,747/4,385（85.5%） | 3,973/4,385（90.6%） | **3,972/4,385（90.6%）** |
| 清空目标完整到达 | 1,361/1,543（88.2%） | 1,529/1,543（99.1%） | **1,530/1,543（99.2%）** |
| 普通非空目标完整到达 | 1,166/1,369（85.2%） | 1,240/1,369（90.6%） | **1,229/1,369（89.8%）** |
| 孤立格非空目标完整到达 | 1,220/1,473（82.8%） | 1,204/1,473（81.7%） | **1,213/1,473（82.3%）** |
| 真实距离 7–8 步完整到达 | 527/785（67.1%） | 672/785（85.6%） | **689/785（87.8%）** |

**选择结论：**虽然 10,000 步多到达 1 道题，15,000 步在清空、孤立格目标和 7–8 步任务上更均衡，因此在封存测试前选它。原训练日志按旧验证损失选出的“最佳”是续训 2,500 步，训练在 22,500 步早停；本报告的最终权重是随后按上述**宽覆盖开发题**重排已保存权重的结果。封存 200 张棋盘没有参与这一选择。

父权重与续训权重的差异同时包含**新增关系和更多参数更新**，这张表不能单独证明增量来自哪一部分。

用户先前观察到的“清空目标变好，一般非空目标暂时受损”，在开发集上需要限定比较对象：相对 **10,000 步**，15,000 步的普通非空目标确实下降 11/1,369；但相对**续训前父权重**，普通非空目标反而增加 63/1,369。孤立格目标相对父权重下降 7/1,473。不能把所有非空目标概括成同方向的损失。

## 模型学到的距离关系与剩余错误

![封存新棋盘上真实最短步数与 Q 预测距离的关系](tree_qmap_distance_relation.png)

*图 1：同一 15,000 步权重，在封存新棋盘状态对上按真实最短距离分组；点表示组内 Q 预测距离的平均值，误差条按棋盘重采样给出 95% 区间。横轴的“8+”合并至少 8 步的可达对。“不可达”须由离线精确求解器确认。组均值不能当成单题精确预测。*

这批封存关系的可达距离平均绝对误差为 **2.17 步**；“目标格子仍在、但无法按规则移到该目标”的困难不可达关系，在固定阈值下只识别 **32.3%**。因此完整到达率高，并不表示每一对状态的距离或无解判断都准确。图中不可达关系的平均预测距离明显更大，但这个平均数也不能掩盖困难负例的漏判。

在固定 1,000 道非空目标任务里，140 道失败中有 **76** 道在某一步移除了目标必须保留的格子，**61** 道因局部余量不能再正确覆盖目标，另有 **3** 道在判卷时成为全局不可达。首个错误发生在第 1 步的有 82 道。这些是模型候选排序的错误定位，不是动作合法性错误：每一步的合法动作和真实后继都由规则程序提供。

## 评测边界与结果身份

- 棋盘为原论文规则的 10×10、八种简单形状；每步只能合法移除。Q 是读取当前棋盘的共享编码器，目标不进入编码器；决策时比较各真实后继的 Q 与目标 Q 的有向距离。
- 训练 1,000 张、开发 200 张、封存测试 200 张**按完整初始棋盘分开**。已核对三者棋盘行号没有交集。开发题覆盖不同残余起点、清空／普通非空／孤立格目标以及真实距离 1–8 步；封存题按同样维度抽样。题目间共享棋盘，不能把 4,355 道题当作 4,355 张独立棋盘。
- 目标到达由规则和精确求解器判卷。推理阶段只用 Q 对规则给出的**合法真实后继**评分，没有训练 V、没有让 LLM 生成动作，也没有把精确距离交给 Q 选择。结论限定为这一环境接口及当前形状分布下的跨棋盘 Q 决策泛化。
