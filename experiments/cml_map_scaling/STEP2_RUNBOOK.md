# 图地图到连续状态 token：已执行的接口设计

将冻结Q/V地图的当前、目标向量投影到冻结LLM的输入embedding，只训练共享adapter。实验分别评价节点报告、一步动作选择和表示距离；结果见[验收报告](results/step2_acceptance.md)，原研究批注保留在[讨论稿](STEP2_DISCUSSION.md)。

## 架构

| 模块 | 实际设置 |
|---|---|
| 地图 | 固定图独立训练的Q/V；接口读取节点Q |
| 输入 | 当前与目标各一个连续token，与任务文字和完整邻接表共同输入 |
| Linear | D→H仿射映射 |
| MLP | D→1024→H，GELU，带偏置 |
| 输入尺度 | 全部Q除以一个冻结的全局RMS标量 |
| 语言模型 | Qwen3-4B-Instruct-2507，BF16，参数冻结；梯度经过主干回传adapter |
| 参数共享 | 当前／目标、所有节点共用同一个adapter |
| 监督 | 生成节点编号及结束标记，按答案token计算CE，支持多token编号 |

首轮用原32节点图、1000维Q；后续按同类协议扩至64／128／256节点。正式参数及精确提示只维护在[配置](configs/step2.json)和对应诊断配置中。

## 数据与评测

首轮496个无序节点对按396／50／50划分；一对的两个方向保持同组，每个方向生成“报告当前”“报告目标”两类训练样本。全部节点在训练中出现，测试保留新的节点组合。固定模板与换措辞模板分别评测。

| 检查 | 评价内容 |
|---|---|
| 节点报告 | 当前和目标各自完全正确率 |
| 一步选择 | 输出编号有效、连边合法、精确剩余距离下降，分别统计 |
| Q干预 | 正确／错配Q、图编号重命名和候选强制选择 |
| 几何 | 原始Q、训练前adapter、训练后adapter距离与图距离的秩相关 |
| 直接几何读出 | 外部程序从真实邻居中选距目标Q最近者，独立于LLM成绩 |

Linear和MLP使用相同节点对、顺序与预算；按报告验证集选点。原始训练入口及后续诊断代码保留供复现，当前项目安排维护在[状态页](../../docs/PROJECT_STATUS_AND_TODO.md)。
