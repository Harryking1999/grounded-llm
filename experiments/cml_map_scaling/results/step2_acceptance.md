# Step 2 结果验收

## 结论

Step 1 学到的 Q 含有可用的图上远近关系。Step 2 的接口能在固定编号下读出节点，但当前训练没有让 LLM 稳定利用这份关系来选路。重编号实验进一步暴露了节点向量与文字图编号的绑定难题：新接口连训练中见过的排列都没有拟合。

## 已完成的比较

| 实验 | 主要结果 |
| --- | --- |
| 固定编号报告 | 64、128、256 节点的 Linear 和 MLP 均在原测试题上把当前、目标两项读对 100/100。 |
| 完整文字上增加 Q | 32 节点一步成功率：文字 83/100，＋Linear 95/100，＋MLP 90/100；64／128／256 节点没有持续出现增益。 |
| 少量动作续训 | 相对等预算报告续训，32／64／128／256 节点分别变化 −1／＋7／0／＋3 题。 |
| 正确与错配 Q | 强制从合法邻居中选一步后，64／128／256 节点都能完成作答；正确 Q 相对错配 Q 没有稳定优势。远近关系题接近机会水平，并出现明显的固定选项偏好。 |
| 反复重编号报告 | 原接口在原编号两项均为 100/100，换名后几乎全错；新接口在训练中见过的排列上为 0/32，训练损失也较早停滞。 |
| Q 的直接几何读出 | 已知真实邻居时，选目标 Q 最近的邻居，64／128 节点成功 85/100、82/100；随机初始 Q 均为 46/100。 |

这些结果对应不同输入和评测协议。直接几何读出由外部程序使用真实邻居集合选点，衡量 Q 中的局部关系；LLM 未参与该项选路。

## 对当前问题的判断

现在给 LLM 的是当前点和目标点的两个向量，全图关系仍由文字邻接表提供。固定编号报告可以通过记住“向量对应哪个编号”完成。反复换名则要求模型从两个向量出发，在重新编号的整张文字图中找到对应节点；现有报告损失没有教会这项对齐。动作续训在原训练提示下能拟合部分动作，到了完整文字题仍缺少稳定迁移。

下一步应先分开测两个环节：**向量所指的点能否在当前图中定位；定位后，模型能否使用点之间的关系。** 可考虑给少量向量与文字节点的对应示例，再比较 learned Q 与每点唯一、但没有图几何的 random Q。若两者都能在完整对应表下作答，而少量示例时只有 learned Q 有优势，才能更清楚地把收益指向关系结构。这个对照目前只是设计建议，尚无实验结果。
