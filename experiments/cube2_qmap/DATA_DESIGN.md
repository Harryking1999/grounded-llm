# 从决策结构构造魔方监督

这次检验：在 Q 编码器、对称距离、Huber 与完整软排序不变时，补齐相对决策的广度及同目标上下文的深度，能否改善连续到达。数据足够覆盖所定义的结构，不等于固定维度的 Q 一定能够表达它。

## 第一性原理：究竟要学会区分什么

对任意目标 g，真实距离 d(s,g) 在每个非终点必须满足 `d(s,g)=1+min_a d(s*a,g)`。相邻状态的距离只能相差 -1、0、1。因此求解需要区分同一个目标下的一步优势，距离为九和十的候选即使都被预测成“很远”，也必须排对次序。全局相关性或平均距离误差不能代替这一决策条件。

当前有九个动作；每一面的三种非恒等转动与原状态形成四点完全连通子图。动作存在逆、同层边、回路和多条最短路。单独记录一棵解树会遗漏其他正确后继及可返回的分支；这里对每个训练父状态标注全部九个真实候选，保留所有平局和最短动作。

定义目标中心相对状态 `r=g^-1*s`。同目标后继是 `r*a`，精确距离就是完整 BFS 表中的 `depth(r)`；共同左乘只改变绝对呈现，不改变 r。由此需要分别覆盖：相对任务类型、不同绝对上下文、同目标的连续路径、分叉后继和近距离边。它们不能靠增加同一类随机状态对互相替代。

深度也不是难度的充分代理。完整图中，深度十一的节点有很多下降动作，而经过深度八、九层时通常只有少数下降动作。必须评估逐层候选选择及完整路径，不能只测最深起点的一步动作。

## 第二性原理：已有结果提供了哪些线索

[可复现审计](results/coverage_audit.json)由旧纯 Q 数据、完整 oracle 和冻结模型直接计算，入口为 `src/audit.py`：

- 数据增强前后都只有 64,623 种相对距离类型，决策类型都只有 11,327 种。共同左乘增加绝对呈现，没有拓宽相对任务类型。
- 深度九包含 1,887,748 种相对状态，旧决策覆盖仅约 0.08%。深度七至十一分别抽取的最短路径中，没有一条的全部决策类型都在旧决策监督内。这只是精确类型覆盖审计，不说明网络不能通过相似类型泛化。
- 冻结模型抽样训练一步正确率约 54%，测试为 51.9%；训练距离 MAE 也较大。因此不能把问题只解释为过拟合或缺少测试状态，表示能力与优化仍是候选解释。
- 旧距离预测在最深层压缩并倒序。低全局误差不保证一单位动作优势被保留，也不保证连续走完。

这些是诊断线索，不是“加数据必然成功”的证明。新实验保留原 Q 结构，先消除已观察到的覆盖缺口。

## 新数据：广度、深度与边界条件

1. **相对广度完整。**每个非恒等相对状态都产生一个完整九候选决策，共覆盖 3,674,159 种类型。为整组共同选择合法左乘 k，生成不同目标中心下的绝对状态。数据不是只取 solved 目标，也不把 Q 改成目标条件网络。
2. **同目标深路径。**从各深度层选择起点，随机选择真实最短后继直到目标；整条路径及每步全部候选使用同一个目标和同一个左乘。每个中间状态继续作为父状态受监督，不只保存轨迹端点。
3. **闭合局部分叉。**一个父状态及全部九个后继，都作为同目标下的父状态；进一步标注它们的全部候选。由此包含兄弟间比较、回退边、同层边和局部汇合。
4. **多上下文近距离。**额外生成大量不同绝对呈现中的短距离关系，避免极少的近距离类型只在极少目标框架中出现。精确距离来自 BFS，不使用打乱动作数。

具体数量和训练参数只维护在 [breadth_depth.json](configs/breadth_depth.json)。生成物在 Git 外，摘要报告实际数量；没有将求解器交给 Q 的推理选择器。

## 覆盖与留出的兼容

随机屏蔽整整一部分状态空间，会使“深路径及每步全部候选均可训练”的联合约束迅速收紧。新划分显式保护旧验证／测试的实际端点，以及新生成、未用于本轮设计的验证／测试端点；所有训练父状态、目标、候选和路径节点都排除这些状态。新鲜评测状态与旧参考评测状态也分开生成。它不同于旧的整桶状态留出，报告必须注明。

完整相对覆盖意味着测试的相对关系类型可以已经在其他绝对框架中训练过；测试检验**未参与损失的绝对状态**上的关系迁移，不声称未见相对类型泛化。旧测试已经参与过问题诊断，只作为固定对照，新测试单列。

## 训练必须真的用到这些数据

只把大数据集写出来、再随机训练很少步，不足以证明覆盖。采样器混合：无放回遍历相对广度、按真实距离均衡采样、重复同目标路径／分叉上下文。近距离和稀有深度不会被深度八至十的大层淹没。最佳 checkpoint 必须实际遍历完规定的广度后才可选择；保存该 checkpoint 当时的覆盖轮次。

仍只有两项损失，未增加辅助头、策略、Bellman 损失或额外对称约束。比较距离分桶、每层动作选择、完整到达和训练侧拟合。如果广度和深度已覆盖且实际训练过，但 Q 仍不能稳定排序或出现循环，应将解释转向表示／优化限制，不能继续把失败笼统称为数据不足。

## 一个精确距离拟合的可证伪限制

当前距离是固定缩放的 L1。任意五个向量 A/B/C/D/E 的 L1 距离，都必须满足：

`d(A,B)+d(A,C)+d(B,C)+d(D,E) <= d(A,D)+d(A,E)+d(B,D)+d(B,E)+d(C,D)+d(C,E)`。

这可以直接由一维坐标推导：每个绝对坐标差是非负加权的二元阈值切分距离；五点只有 32 种二元切分，逐一检查上式均成立，因此求和后仍成立。测试对全部切分核验了符号，不依赖模型训练结果。

精确 oracle 给出的魔方状态编号 `[2051818,1077874,905101,2319678,2932767]` 使左边为 16、右边为 15。三盘汉诺塔的 `[1,3,9,23,17]` 也产生 21 对 20 的违例。完整矩阵和重算入口保存在审计文件与 `metric_witness` 中。由此即使无限增加数据和维数，当前 L1 距离也不能**精确**表示所有最短步数；这十个关系中至少一个误差不小于 0.1。

该下界很局部，不能解释整体 MAE 的大小，也没有证明正确动作排序不可能。汉诺塔存在同类违例却能高成功率求解，正说明“精确距离可表示性”和“足够正确的决策几何”必须分开。本轮仍不改变距离或编码器，只将该限制作为解释负结果时的明确边界。
