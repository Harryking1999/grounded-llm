# 从决策结构构造魔方监督

这次检验：在 Q 编码器、对称距离、Huber 与完整软排序不变时，补齐相对决策的广度及同目标上下文的深度，能否改善连续到达。数据足够覆盖所定义的结构，不等于固定维度的 Q 一定能够表达它。

## 第一性原理：究竟要学会区分什么

对任意目标 g，真实距离 d(s,g) 在每个非终点必须满足 `d(s,g)=1+min_a d(s*a,g)`。相邻状态的距离只能相差 -1、0、1。因此求解需要区分同一个目标下的一步优势，距离为九和十的候选即使都被预测成“很远”，也必须排对次序。全局相关性或平均距离误差不能代替这一决策条件。

当前有九个动作；每一面的三种非恒等转动与原状态形成四点完全连通子图。动作存在逆、同层边、回路和多条最短路。单独记录一棵解树会遗漏其他正确后继及可返回的分支；这里对每个训练父状态标注全部九个真实候选，保留所有平局和最短动作。

定义目标中心相对状态 `r=g^-1*s`。同目标后继是 `r*a`，精确距离就是完整 BFS 表中的 `depth(r)`；共同左乘只改变绝对呈现，不改变 r。由此需要分别覆盖：相对任务类型、不同绝对上下文、同目标的连续路径、分叉后继和近距离边。它们不能靠增加同一类随机状态对互相替代。

深度也不是难度的充分代理。完整图中，深度十一的节点有很多下降动作，而经过深度八、九层时通常只有少数下降动作。必须评估逐层候选选择及完整路径，不能只测最深起点的一步动作。

## 第二性原理：已有结果提供了哪些线索

[可复现审计](results/coverage_audit.json)由旧纯 Q 数据、完整 oracle 和冻结模型直接计算，入口为 `src/audit.py`：

- 数据增强前后都只有 64,623 种相对距离类型，决策类型都只有 11,327 种。共同左乘增加绝对呈现，没有拓宽相对任务类型。
- 深度九包含 1,887,748 种相对状态，旧决策覆盖仅约 0.08%。深度七至十一分别抽取的最短路径中，没有一条的全部决策类型都在旧决策监督内。这只是精确类型覆盖审计，不说明网络不能通过相似类型泛化。
- 冻结模型抽样训练一步正确率约 54%，测试为 51.9%；训练距离 MAE 也较大。因此不能把问题只解释为过拟合或缺少测试状态，表示能力与优化仍是候选解释。
- 旧距离预测在最深层压缩并倒序。低全局误差不保证一单位动作优势被保留，也不保证连续走完。

这些是诊断线索，不是“加数据必然成功”的证明。新实验保留原 Q 结构，先消除已观察到的覆盖缺口。

## 新数据：广度、深度与边界条件

1. **相对广度完整。**每个非恒等相对状态都产生一个完整九候选决策，共覆盖 3,674,159 种类型。为整组共同选择合法左乘 k，生成不同目标中心下的绝对状态。数据不是只取 solved 目标，也不把 Q 改成目标条件网络。
2. **同目标深路径。**从各深度层选择起点，随机选择真实最短后继直到目标；整条路径及每步全部候选使用同一个目标和同一个左乘。每个中间状态继续作为父状态受监督，不只保存轨迹端点。
3. **闭合局部分叉。**一个父状态及全部九个后继，都作为同目标下的父状态；进一步标注它们的全部候选。由此包含兄弟间比较、回退边、同层边和局部汇合。
4. **多上下文近距离。**额外生成大量不同绝对呈现中的短距离关系，避免极少的近距离类型只在极少目标框架中出现。精确距离来自 BFS，不使用打乱动作数。

具体数量和训练参数只维护在 [breadth_depth.json](configs/breadth_depth.json)。生成物在 Git 外，摘要报告实际数量；没有将求解器交给 Q 的推理选择器。

## 覆盖与留出的兼容

随机屏蔽整整一部分状态空间，会使“深路径及每步全部候选均可训练”的联合约束迅速收紧。新划分显式保护旧验证／测试的实际端点，以及新生成、未用于本轮设计的验证／测试端点；所有训练父状态、目标、候选和路径节点都排除这些状态。新鲜评测状态与旧参考评测状态也分开生成。它不同于旧的整桶状态留出，报告必须注明。

完整相对覆盖意味着测试的相对关系类型可以已经在其他绝对框架中训练过；测试检验**未参与损失的绝对状态**上的关系迁移，不声称未见相对类型泛化。旧测试已经参与过问题诊断，只作为固定对照，新测试单列。

## 训练必须真的用到这些数据

只把大数据集写出来、再随机训练很少步，不足以证明覆盖。采样器混合：无放回遍历相对广度、按真实距离均衡采样、重复同目标路径／分叉上下文。均衡流让近距离和稀有深度获得重复采样，但混合后的整体分布仍受大层影响，需要审计实际层权重。最佳 checkpoint 必须实际遍历完规定的广度后才可选择；保存该 checkpoint 当时的覆盖轮次。

仍只有两项损失，未增加辅助头、策略、Bellman 损失或额外对称约束。比较距离分桶、每层动作选择、完整到达和训练侧拟合。相对类型被遍历过，不等于其各种绝对呈现已充分覆盖，更不等于模型已收敛。若 Q 仍不能稳定排序或出现循环，应分别检查训练充分性、实际采样权重、对称迁移和表示限制，不能只用数据总量或单次负结果归因。当前冻结审计与有序验证建议见[结果报告](results/report.md#收敛与失败机制审计)。

用户随后选定的 [balanced_epochs.json](configs/balanced_epochs.json) 直接对全部训练行按真实距离层均衡，不再混合广度／上下文比例或使用损失重要性权重。每层乱序无放回遍历，批配额的余数轮换；排序组按父状态真距离分层，组内完整软目标不变。覆盖要求作用于完整追加预算；起始和早期模型仍可按验证目标获选，最佳与末步的实际覆盖分别记录。该方案沿用相同冻结数据，因此小层会高频重复同一批绝对呈现，不能将轮次增加解释为更多不同上下文；结果报告单列了这一限制。

## 一个精确距离拟合的可证伪限制

当前距离是固定缩放的 L1。任意五个向量 A/B/C/D/E 的 L1 距离，都必须满足：

`d(A,B)+d(A,C)+d(B,C)+d(D,E) <= d(A,D)+d(A,E)+d(B,D)+d(B,E)+d(C,D)+d(C,E)`。

这可以直接由一维坐标推导：每个绝对坐标差是非负加权的二元阈值切分距离；五点只有 32 种二元切分，逐一检查上式均成立，因此求和后仍成立。测试对全部切分核验了符号，不依赖模型训练结果。

精确 oracle 给出的魔方状态编号 `[2051818,1077874,905101,2319678,2932767]` 使左边为 16、右边为 15。三盘汉诺塔的 `[1,3,9,23,17]` 也产生 21 对 20 的违例。完整矩阵和重算入口保存在审计文件与 `metric_witness` 中。由此即使无限增加数据和维数，当前 L1 距离也不能**精确**表示所有最短步数；这十个关系中至少一个误差不小于 0.1。

该下界很局部，不能解释整体 MAE 的大小，也没有证明正确动作排序不可能。汉诺塔存在同类违例却能高成功率求解，正说明“精确距离可表示性”和“足够正确的决策几何”必须分开。本轮仍不改变距离或编码器，只将该限制作为解释负结果时的明确边界。

## 六动作局部图与在线呈现

用户确认后的候选实现采用 [quarter_turn_local.json](configs/quarter_turn_local.json)。这是纯 Q 的新对照，不覆盖九动作结果。只保留每面顺、逆 90 度，180 度成为两步；完整 BFS 的最大距离为 14。每个 90 度动作翻转角块排列奇偶性，因此任意目标下每条边的距离差只能为 -1 或 +1，没有同层边。该性质简化决策标签，不保证神经网络更容易拟合或长轨迹更容易完成。

每个相对根 r 生成两步局部图：起点、六个直接后继以及 36 条两步序列，按终点去重后为 34 个节点。起点与六个直接后继是七个父节点，各自保留全部六候选。父节点恰好等于目标时不构造排序任务，其余任务保留所有最优动作及 `delta=child_distance-parent_distance` 的精确标签。逆动作、同面两次 90 度的汇合、跨面组合均由同一真实图表达；不把相同终点当负例，不把序列长度当距离，也不添加一个对确定性编码器恒成立的闭环损失。

在线流按根到目标的真距离分层，层内乱序无放回遍历后重排。每次抽取共同左乘整个图及目标，拒绝任意节点落入保护端点的呈现，不退回固定旧呈现。小层重复的是相对任务，绝对呈现持续变化。局部展开会改变距离和决策父层的实际分布，所以另外记录两种监督的累计直方图，覆盖轮次仅指相对根。距离对混合图中节点到共享目标的长程标定与局部节点之间的短程关系；两者均用完整 oracle 标注，局部节点间最短路可能经过图外，不能仅在截断图内标最短距离。正式比例只在配置维护。

同批图节点只需一次共享编码，再索引出距离对和全部候选。模型仍只学习 `network.*`，目标不进入编码器；原 Huber 与完整软排序 CE 不变，动作差分只是标签和诊断依据，不是新增损失。GPU one-hot 构造使用固定角块排列／朝向表，与环境的 192 维联合编码相同，不是可学习转移模型。

旧运行的验证／测试及早期参考队列的实际父状态、目标全部受保护；所有新训练图节点（含候选和局部距离端点）均不能落入这些状态。另建新验证／测试端点并保护；评测候选本身不额外全体留出，不能声称整条评测轨迹或所有候选均未见。相对任务全集仍进入训练，所以不声称未见相对关系泛化。

同端点比较包括新六动作最佳／末步、旧九动作最佳，以及旧权重在六动作规则下的冻结诊断。参考 rollout 精确复用旧运行分层抽取的起终状态；另报新测试队列，所有条件使用相同固定步数上限。各模型距离误差及 loss 使用各自动作计步标签，不能把不同 metric 的 MAE 或 CE 数值直接比较为优劣。动作空间、数据和优化过程共同改变，这轮不能单独归因于去掉 180 度；旧权重直接换动作的条件只提供局部诊断。冻结选择器不接收 oracle，不禁逆动作或使用额外搜索以掩盖循环。

## 针对循环的动作距离差监督

首轮六动作的长程负结果及实际 A→B→A 循环表明：相邻状态到同一目标的距离排序仍会颠倒。对任意目标定义 `h(s)=D(Q(s),Q(g))`，每个真实动作边的监督为 `Huber(h(sa)-h(s), d(sa,g)-d(s,g))`，真差为 -1 或 +1。原完整软排序保留。候选方案替换原绝对距离 Huber，不额外添加学习头，也不将该方案写成原先未改动的两损失基线。

这项监督消去同目标下共同的距离偏移，直接惩罚将退步误评为前进、或将正确前进评为退步。所有边的精确差若能成立，沿真实最短路径可以望远镜求和，结合结构上 `h(g)=0` 恢复距离；同时所有最优／非最优后继间距为二，与原软排序目标兼容。有限网络、固定 L1 和有限监督不能保证所有边同时成立，因此这只是针对已定位机制的可证伪干预，不承诺消灭循环。

正式匹配合同只维护在 [quarter_turn_progress.json](configs/quarter_turn_progress.json)：两组共同恢复同一 Q 及 Adam、同一在线随机流、学习率计划、更新预算、评测端点与验证选择。保留原绝对监督作为追加训练对照。验证选择统一使用最短动作率，首次达到最大值的 checkpoint 获选；两组都允许初始权重获选。原测试已用于失败诊断，新阶段结果应作为复用诊断队列，不能称全新独立检验。另报绝对 Huber、边差 Huber、完整软排序 CE、逐层单步最优率、连续成功与循环；没有在求解器内禁逆动作或加搜索。
