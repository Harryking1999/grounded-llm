# 魔方 Qmap

**目标：让网络通过距离和动作关系，自行形成有远近关系的空间。**保留与目标无关的共享编码器 Q(s)，由固定向量距离直接表达状态之间的远近，而不是另加一个接收起点和目标的关系网络。

文字、数据和当前选定权重见[任务工作区](../../tasks/cube2/README.md)。魔方独立维护 [训练](src/run.py)、[关系数据](src/relation_data.py)、[模型／对称适配](src/model.py)和[评测](src/evaluate.py)，当前采用模型的续训仍由 `cycle_repair.py` 实现；不调用汉诺塔训练器。公共 MLP、距离与排序基础见[统一方法](../../tasks/QMAP_METHOD.md)。

## 魔方给这个空间提出了什么要求

当前只考虑 U、U′、R、R′、F、F′ 六种动作，即三个面的顺、逆时针 90°。180° 由两个动作组成，不作为一步。每次四分之一转计一步。

- **逆动作抵消：**同面顺转后逆转回到原态，即 aa⁻¹=e。
- **动作成环：**同面四次顺转回到原态，a⁴=e；三次顺转与一次逆转的结果相同，a³=a⁻¹。这不表示三步路径与一步路径一样短。
- **动作有顺序：**不同面的动作通常不交换，先 U 后 R 与先 R 后 U 可以到达不同状态。
- **关系有对称性：**在本实现的群运算约定下，对起点和目标共同左乘同一个合法状态，真实距离不变，动作边也被保持。这不是任意换颜色或转动观察视角；变换定义见[结构说明](results/structure_notes.md)。

因此，空间既要容纳局部闭环，又要让同一个状态面对不同目标时具有一致的远近关系。只学会相邻或回环，不能自动得到通向远目标的方向。

状态使用固定 DBL 角块的参考系，共 3,674,160 个状态，最远相距十四步。输入编码角块身份与朝向，状态编号不作为网络特征；不包含图像识别。规则由 [environment.py](src/environment.py) 定义。

## 为什么要考量距离规则

距离规则决定哪些关系能够同时成立，不只是调整输出数值。

| 规则 | 含义 | 当前认识 |
|---|---|---|
| L1 | 所有坐标绝对差相加，可整体缩放 | 魔方存在它无法同时精确表示的距离关系；增加维数不能消除该反例 |
| L∞ | 取最大的坐标绝对差 | 有有限度量的构造依据，但固定 128 维不保证精确表示整个魔方，也不保证网络能学到合适坐标 |
| L2 | 欧氏距离 | 对魔方四转环也有精确表示限制；仍可检验近似距离和动作排序 |

L∞、L2 的现有尝试都尚未带来可靠的长程求解进展。精确表示不可能与近似地图不可用是两个不同结论；当前目标是可用的远近与动作方向，不要求全空间零误差。数学依据集中在[结构说明](results/structure_notes.md)，这里不展开逐次实验。

## 怎么让网络自己形成空间

精确最短步数来自完整状态图，而不是打乱序列长度。网络用距离拟合与完整候选排序两类监督，自行决定坐标含义；同一组 Q 必须同时解释多个目标和动作邻域。环境提供所有合法后继，推理只按向量距离贪心选动作，不搜索，也不用裁判纠正。

全状态联合训练按以下原则实施：遍历全部状态和动作边；持续抽取不同距离与目标，连接跨集合关系；固定重放以检查旧关系退化；主要验收已见状态之间未直接训练的关系，以及真实完整到达。留出题的父节点和全部候选到目标的标签都排除于训练。完整轨迹可以进入其他已训练关系。

正式参数与划分以 [full_state_joint.json](configs/full_state_joint.json) 为准，实现见 [full_state_joint.py](src/full_state_joint.py)。当前进度只维护在[项目状态页](../../docs/PROJECT_STATUS_AND_TODO.md)。

另设[固定复原条件](configs/fixed_goal.json)：保留共享 Q 与固定距离，监督各状态到复原态的距离、每步候选排序，以及同一条最短复原路径内中间状态彼此的距离；验收完整复原，不将它当作任意目标地图的成功证据。

[合并续训](configs/mixed_goal.json)将复原与多目标关系放进同一训练批次，保留路径中间距离、分层覆盖和原有复原能力监测。先按复原验证集选择已有断点，再续训同一个 Q；不合并两套网络权重，也不改写原来的运行。新增任意目标验收使用原固定复原条件中受保护的目标状态，所有损失继续排除这些状态的标签。

[循环与对称小对照](configs/cycle_symmetry.json)分别检验两项改动：

- **对称结构：**保持复原态 e 的合法换面／换色呈现，共用 MLP，按坐标置换对齐后平均。仍输出 128 维 Q、用 L∞ 读出；对称状态的 Q 保持区别，共同变换前后的距离相同。旧权重先做不改变原距离的坐标重排，再单独验收投影后的初始表现。
- **循环监督：**联立循环两端、完整候选、正确出口和连续路径，同时监督跨分支、多目标关系。

代价和参数见合同。留出状态按对称轨道保护；历史题用于检查保留能力，不声称从未监督过。详细训练结果留在运行目录。

[当前策略循环修复对照](configs/cycle_repair.json)从保留的对称 Q 开始，定期重新挖掘当前死局，将复原出口与跨分支、多目标关系分别计权。对比普通续训、循环修复及带更新保护的修复；保护只使用训练区内已正确的完整动作邻域，检查并缩小 Adam 实际提出的参数变化，拒绝时恢复参数和优化器状态。[方向修正对照](configs/cycle_projection.json)进一步按受损出口的梯度调整提议，再经过相同的实际检查。验收关系误差、全状态复原、循环净变化与旧路线损伤；抽样保护不代表全空间保证。推理仍只用原有 Q 距离贪心。

## 复原附近目标的续训

[近目标续训配置](configs/near_goal_continuation.json)从当前采用的对称Q及其Adam状态开始，针对距复原态1–3步的绝对目标补完整候选关系，同时重放复原任务。复用`full_state_joint.fixed_batch`、Huber及既有soft-rank，保持共享编码器、L∞和六动作不变。固定更新预算后停止，最终断点单列；降低学习率及改变采样属于新的续训阶段，不能称为原历史采样流的精确恢复。

原FLAN魔方500题复原与500题小OOD保留作配对回归；另采独立验证与测试关系。所有回归、验证、测试的父节点及六个候选到目标的关系均双向排除，并关闭其六种轴对称等价关系；同时保留原固定复原留出状态的对称闭包。新监测关系只保证不进入本次续训，不能追溯宣称原预训练未见。训练面向各层近目标及任意合法起点，不从原500题失败中挑训练题。

验证用于报告进展，原小OOD与新测试只在续训前后评测，不据测试选断点或自动追加。原固定复原能力既检查同题500题，也在前后用相同动作预算核对全状态贪心；不得只报新目标改善。各目标深度分别报告。新的地图未经明确采用，不替换任务selection，也不替换正在进行的FLAN重评测中的冻结图。

```bash
python -m experiments.cube2_qmap.src.near_goal_continuation --contract experiments/cube2_qmap/configs/near_goal_continuation.json --checkpoint SELECTED_Q --oracle EXISTING_QTM_ORACLE --evaluation-data PAIRED_CUBE_EVAL_DATA --out NEW_RUN --source-commit COMMIT --device cuda
```

原均匀父节点续训的近目标验证先升后降，最终复原退化；比较与边界见[结果报告](results/report.md#复原附近目标的续训)。后续[从1000步改进的配置](configs/near_goal_refinement.json)保留同一编码器和目标，混合远处父节点与距近目标1–6步的入口邻域，降低学习率，并复用`cycle_repair.ExitGuard`检查Adam实际更新对训练区正确复原决策的影响。拒绝更新会恢复模型与Adam；有限保护集合不保证全空间保持。

该阶段保存每个评测点，以近目标验证成绩选择候选，约束原复原回归不低于起始1000步，并把初始断点纳入候选。旧小OOD与已查看测试均作为回归；新增最终监测题仅保证本阶段不监督，其早期曝光未审计。选定后再报告全部回归、新监测与全状态复原，不自动采用或追加。

[方向修正配置](configs/near_goal_projected.json)保留上述数据、预算与保护集合，另启用已有`ExitGuard.project`，先修正损伤复原边界的Adam位移，再用相同尺度回退检查。报告实际接受更新数，不能把大量被拒绝的尝试视为有效训练。

[无位移硬保护的局部重放对照](configs/near_goal_local_replay.json)保留同一初始化、Adam、数据与低学习率，仅去掉逐更新硬保护，以区分数据改动无效与保护导致停滞；仍保留阶段选择和原复原回归门槛。该门槛是监测集上的候选筛选，不保证全状态复原保持。

[低学习率原采样对照](configs/near_goal_low_lr.json)恢复1000步的Adam及采样RNG，保留原均匀父节点，采用更小更新；[近目标距离校准权重对照](configs/near_goal_rank_refinement.json)只再降低近目标Huber权重，保留原soft-rank及复原损失。两者匹配采样流与预算，继续用验证和复原约束选阶段候选，所有已查看题集均按回归解释。
