# 魔方 Qmap 的当前结论

**尚未取得可靠的全局长程求解结果。**L1、L∞、L2 的既有尝试没有解决这一目标；不根据训练 loss 下降宣称成功。

已确认的有限结果是：共享编码器能够仅靠距离和动作关系学会小地图；多个集合交错联合训练能够保持这些已训练关系。但组内成功尚不能稳定推广到未训练的跨目标关系，也不能当作全局地图成功。

按已授权的[全状态联合训练合同](../configs/full_state_joint.json)完成了首轮训练，旧集合关系得到保持，但未训练关系的完整到达仍不足以支持全局成功。后续仍以真实完整到达验收。

历史数值保存在已有结构化结果与 Git 历史中，原始运行日志和模型产物留在 Git 外。本页保留会改变判断的比较、负结果与限制。研究依据见[魔方说明](../README.md)与[结构说明](structure_notes.md)；工作进度只维护在[项目状态页](../../../docs/PROJECT_STATUS_AND_TODO.md)。

目标距复原态1、2、3步的小OOD分别为43/167→76/167、16/167→24/167、3/166→8/166。全状态距离MAE从0.8182降至0.7713，最短动作率从75.15%升至75.78%，但整题复原下降，说明距离拟合或单步指标不能替代完整任务保持。已曝光128万近目标完整候选任务与64万复原完整候选任务，覆盖全部153个近目标，不代表穷尽状态—目标关系。

### 从1000步继续的比较

按预先的近目标验证优先、原复原回归至少383/500、平分时优先更多复原成功及更早断点的规则，当前候选为[低学习率原采样](../configs/near_goal_low_lr.json)的2000步点。它恢复1000步Q、Adam与原训练随机流，保留既有损失和均匀父节点，只降低学习率；每个评测点均保留权重。比较详情见[结构化结果](near_goal_refinement_summary.json)。

改善很小，不能称为可靠突破。小OOD新增成功9题、损失7题，净增2题；反复用于阶段与条件选择的验证也不是独立确认。新增阶段监测只保证不进入该阶段监督，更早曝光未审计。通过原CPU冻结`MapReader`加载起点和候选，分别复现复原383→386、小OOD181→183，说明候选可用原推理接口加载；这不证明微小增益具有统计稳定性。

完整路线条件在2097152个候选内未凑齐分层3072条合法训练路线，数据构造阶段停止，优化器更新为零，不能报告训练成败。连续片段条件则从30720个候选中得到3598个合法窗口，固定保留3072段，覆盖153个目标，长度为5–10个父节点；监督每个父节点的全部候选。其新增验证仍低于起点。该条件同时改变采样范围、重复曝光和实际关系数，不是仅改变分组的因果对照；片段终点也不一定已到达目标。
