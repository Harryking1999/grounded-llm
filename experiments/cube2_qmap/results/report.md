# 魔方 Qmap：复原与目标泛化

原复原Qmap在已知的目标相对坐标下可以处理非复原目标；分别编码绝对状态的共享Q仍是薄弱项。采用权重身份见[selection](../../../tasks/cube2/Qmap/selection.json)。

| 条件，六动作贪心，最多32步 | 标准复原 | 编号1–999非复原目标 |
|---|---:|---:|
| 原权重，绝对状态编码 | 全状态77.47%；回归385/500 | 原固定500题0/500；新验证0/500 |
| 绝对状态编码续训，验证选择的第26,000步 | 全状态76.07%；回归385/500 | 验证3/500；留出4/500 |
| 原权重，目标相对坐标 | 回归385/500 | 原固定500题371/500；验证381/500；留出394/500 |

## 目标坐标与关系表示

环境已有的群运算将状态对 `(s,g)` 变为 `(g⁻¹s,0)`。左乘保持六个动作及其后继对应关系，因此可以直接调用原复原Qmap。查询为 `d_Q(Q(g⁻¹s),Q(0))`；收益来自任务规则给出的坐标变换。它是依赖目标的关系读取条件，需与分别编码绝对状态的共享地图分开比较。

由这一双射和逐步动作对应可推得：对任一固定合法目标，均匀全状态起点下的成功率等于原复原策略的77.47%。具体题集的起点分布仍影响实际成绩。

优化目标为复原及各换目标小类分别达到90%以上。[相对坐标训练配置](../configs/relative_goal.json)从复原权重和完整Adam接续，沿用Huber与完整六候选排序；每轮遍历状态，补充按深度均衡的关系。针对性重放在原配额内混合当前错误分叉与候选距离差较小的正确分叉，分别改善失败和保持已有动作次序。错误循环的出口按其影响起点数增加曝光，每五轮更新失败池。四卡共享一次优化更新，状态特征和转移表常驻各卡，减少CPU准备与传输。周期性全状态评测用于核对复原及换目标的共同能力，固定各题集分别报告。

仅广域重放100轮后全状态复原78.50%；加入错误分叉重放100轮后达到84.48%。随后降低学习率接续500轮，全状态完成3,191,283/3,674,160（86.86%）；原固定500题、换目标小OOD、验证与留出组分别完成427、432、431、445题。与当前FLAN完全相同的250题中，复原完成114/125（91.2%），非复原目标完成115/125（92.0%）。这些结果对应目标相对读取；当前FLAN训练仍使用已冻结的旧权重与绝对读取。

剩余错误主要在9–11步候选次序与循环出口。训练区仍有486,828个错误分叉；按深度选择得到26,753个脆弱正确分叉。单批梯度检查显示，单独加强错误分叉可能同时缩小正确分叉的候选距离差，因此接续在原补训配额内加入正确分叉保持，同时继续完整遍历和按深度均衡重放。完整断点、逐轮曲线与逐题结果见对应runtime，关键计数见[目标覆盖结果](goal_coverage_summary.json)的`goal_relative_refinement`。

重放覆盖核对显示，约45.82%的针对性样本来自最终仍能完成的非最优分叉，循环出口占15.91%。可直接补训的35,380个循环出口影响404,889个失败起点，占475,208个失败起点的85.20%。接续方案在原补训配额内，将循环出口、失败路径的其他错误分叉、脆弱正确分叉分别分配50%、25%、25%；广域遍历、深度均衡、损失、模型与总轮数保持原条件。计数和采样验证见目标覆盖结果的`failure_targeting_diagnosis`。

[现有读取器](../../../grounded_llm/tasks/cube2/model.py)通过 `MapReader(env, checkpoint, coordinate_frame="goal_relative")` 启用这一条件。`scores` 和 `choose`使用该变换；`encode`仍返回原权重的状态向量。标准复原目标为0时，两种条件相同。

## 逆状态的距离对称性

正式结构对称在编码器内部使用 `Qsym(r)=(Qaxis(r)+Qaxis(r⁻¹))/2`。原角块特征的逆变换仅交换位置／块身份并翻转扭转方向，已有轴对称与逆变换相容。结构保证正反相对状态得到完全相同的128维向量，读取继续使用单个向量到复原态的L∞距离。第464轮同一参数投影后，全状态完成率由90.41%升至92.65%，四组固定500题分别完成457、459、467、461题；新增参数为零。编码器内部处理两种对称呈现，读取器保留一次距离读取。

原单次读取训练在第470轮达到既定门槛后停止。结构接续保留完整权重、Adam与采样随机状态，在原500轮上限内完成20轮，于第490轮达到停止条件。按预定验证标准选出的第486轮，全状态完成3,486,784/3,674,160（94.90%），四组固定500题分别完成466、467、476、472题；FLAN同题复原117/125、非复原目标119/125。12、13、14步层分别完成716,573/782,536、80,788/90,280、238/276，深层仍有缺口。条件权重登记于selection的`goal_relative_inverse`；当前FLAN继续使用原冻结条件。证据见覆盖结果的`forced_inverse_vector_projection`。

六动作均可逆，精确复原距离满足 `d(r,0)=d(r⁻¹,0)`。对状态对 `(s,g)`，分别读取 `g⁻¹s` 与 `s⁻¹g` 的复原距离并取均值，可使读出距离对称。第257轮固定权重、32步贪心的比较如下；完整状态和六个合法后继均由原规则提供，输入与128维Q保持原条件。

| 题组 | 单次目标相对读取 | 正反相对距离均值 |
|---|---:|---:|
| 全状态复原 | 89.74% | 92.16% |
| 原固定500题 | 455/500 | 457/500 |
| 换目标小OOD | 445/500 | 466/500 |
| 验证组 | 448/500 | 462/500 |
| 留出组 | 445/500 | 464/500 |
| FLAN同题：复原 | 115/125 | 113/125 |
| FLAN同题：非复原目标 | 112/125 | 115/125 |

均值读取在全状态中多完成88,563题，存在286,750题新增完成和198,187题原成功丢失。12–14步层仍是难点，完成率分别约87.31%、83.17%、79.71%。它是每候选两次Q查询的额外读取条件；现有单次读取训练继续执行原预算，当前FLAN维持旧冻结条件。

现有读取器通过 `MapReader(env, checkpoint, coordinate_frame="goal_relative", inverse_average=True)` 启用，`encode`继续提供原状态向量。250道实际查询的全部合法候选分数与缓存策略完全一致，16道直接读取器执行结果也一致。快照、分层结果及读取条件见[覆盖结果](goal_coverage_summary.json)的`goal_relative_inverse_average`。

## 绝对状态编码的优化缺口

实际目标族按编号1–999均匀抽样，涵盖距复原态6–13步；广域起点、目标附近入口、训练失败与原复原路径关系共同训练40,000步。固定实际训练批次中，非复原目标首步最优率由第1,000步53.61%升至第40,000步60.64%，末段排序KL约0.448；留出完整求解仍弱。原关系距离拟合改善同时伴随复原完整轨迹下降，后续应以连续动作的正确性检验表示与监督之间的冲突。

当前评测保护具体查询及完整候选关系，相同状态参与其他关系学习。早期输入级保护导致路线截断，现行关系级保护已解决这一采样限制。配置、覆盖、训练曲线和各条件分项见[目标泛化配置](../configs/goal_generalization.json)与[覆盖和拟合结果](goal_coverage_summary.json)。
