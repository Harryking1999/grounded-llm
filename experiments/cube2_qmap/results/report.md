# 魔方 Qmap 的当前结论

**尚未取得可靠的全局长程求解结果。**L1、L∞、L2 的既有尝试没有解决这一目标；不根据训练 loss 下降宣称成功。

已确认的有限结果是：共享编码器能够仅靠距离和动作关系学会小地图；多个集合交错联合训练能够保持这些已训练关系。但组内成功尚不能稳定推广到未训练的跨目标关系，也不能当作全局地图成功。

按已授权的[全状态联合训练合同](../configs/full_state_joint.json)完成了首轮训练，旧集合关系得到保持，但未训练关系的完整到达仍不足以支持全局成功。后续仍以真实完整到达验收。

历史数值保存在已有结构化结果与 Git 历史中，原始运行日志和模型产物留在 Git 外。本页保留会改变判断的比较、负结果与限制。研究依据见[魔方说明](../README.md)与[结构说明](structure_notes.md)；工作进度只维护在[项目状态页](../../../docs/PROJECT_STATUS_AND_TODO.md)。

### 目标不敏感的核验与真实路径诊断

目标不敏感的判断使用真实距离和最优动作集合筛选。对4096个合法训练起点，3483个面对六个一步目标时真实距离不同，1933个起点不存在一个同时适用于全部目标的最优动作。进一步固定512个真实距离不同、最优动作集合也不同的起点，其中208个含有两两不相交的最优动作集合。

这些起点共有3516组真实距离不同的目标配对；初始化和距离层最终点均未区分其中任何一组预测距离（阈值1e-5）。初始化的870个错误候选决策全部由0-based坐标126主导，该坐标在轴置换下不变。距离层最终点的859个错误仍全部由同一坐标主导。目标向量本身不同，但其差异没有进入这些错误距离的L∞最大值。因此证据不依赖“预测接近就算塌缩”的假设。

微型训练的8个共享起点也有66组真实距离不同的目标配对；训练后仍全部未被源—目标预测距离区分。这是训练内仍未满足的关系，不只是未见状态泛化失败。现象支持检查主导坐标与有效梯度／拟合瓶颈，尚不能区分模型参数化能力限制和当前优化路径限制。

固定216条真实最短路径，起始距离为4、8、12，共1728条真实路径边。训练期间只检查不触及保护关系的部分：1366条可评测边，且只有6条路径的所有决策均完整可监督，不能以未观察到错误宣称整条路径正确。模型选择冻结后，再对整条路径作最终评测，保护的中间关系仅用于测试，未进入训练或困难挖掘。

这些条件的合格选择均保留176/500、386/500的初始化。加边缓和了持续训练的退化，但未超过初始化；交叉覆盖未产生稳定收益。失败辅助池的32768个新决策中，24376个来自训练区真实贪心轨迹，其余8392个来自训练池错误或小间隔排序。不能把微型或困难池的重复曝光写成不同关系增长。针对主导坐标缺口的近复原深度距离对对照也未通过复原门槛，结果完整保留，未据测试追加。

### 隔离、复现与结论边界

- 全部六个一步目标进入训练；二、三步目标按完整轴对称轨道留出。留出目标作为任何监督端点也被排除。所有完整排序都包含六个合法候选，不以遮掉候选后继续排序的方式凑覆盖。
- 新关系验证／测试避开已重建的两个续训阶段的监督关系及轴对称闭包。继承的1000／2000步模型曾见过全部近目标，且未重建更早复原预训练的全部标签；阶段留出目标不等于从未预训练过的目标。
- 微型开发起点星与微型训练星隔离；主试验保证关系留出，不能宣称所有评测物理状态此前从未被编码或监督。完整路径的保护关系仅在最终选择冻结后用于评测。
- 真值距离32步贪心在各500题评测上均为500/500；本报告的Q贪心成绩是地图参照，不是LLM成绩。模型的失败不由32步预算不足解释。
- 数据、各组best及最终完整恢复状态在4090的`runs/cube_coverage_4fecef0/`、`runs/cube_coverage_factorial_ed2827e/`、`runs/cube_goal_layers_251bad3/`保留，本地副本在`runs/model_retests/`同名目录。前两组运行的158个中间断点完整归档于本地`runs/model_retests/cube_coverage_intermediate_checkpoints.tar.gz`，通过gzip CRC及成员大小校验后释放远端重复副本，给FLAN后续断点接收留出空间；压缩包保留原相对路径、权重、Adam与采样状态。原1000／2000步及采用权重未移动或覆盖。

反向BFS、层数据与诊断入口为[goal_layers.py](../src/goal_layers.py)，训练复用[coverage_train.py](../src/coverage_train.py)和原`fixed_batch`／Huber／soft-rank，最终选择及配对测试由[coverage_evaluate.py](../src/coverage_evaluate.py)执行。训练源码为`251bad3`，最终测试为`830ef1d`，完整路径指标采用排除终点padding后的`3b04e12`。小规模检查共13项通过。

本试验不支持按当前配方扩大数千万条监督；也没有证明目标距离层路线无效或当前L∞网络不可能表达。下一项必要证据是固定小集合中真正需要目标切换的距离与完整排序能否被充分拟合，并区分坐标激活／优化与模型参数化限制。仅增加边数、重复相同关系或依据独立测试继续调参，均不能填补这项证据。
