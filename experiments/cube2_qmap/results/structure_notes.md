# 魔方的动作结构与距离表示

研究目标是让同一个 Q(s) 通过关系监督形成可直接读出远近的空间。这里保留任务结构、数学依据与相关工作，不记录逐次实验过程。

## 动作、闭环与对称性

本实现记动作执行为 s→sa。同面动作满足 aa⁻¹=e、a⁴=e、a³=a⁻¹；不同面的动作通常不交换。这些等式描述最终状态，不代表不同动作序列具有同样的最短长度。

简单平移动作 Q(sa)=Q(s)+vₐ 无法非平凡地表达四转闭环：回到原态要求 4vₐ=0，因此实数向量 vₐ 只能为零。当前模型没有采用这种动作平移假设。

共同左乘 k 把动作边 s→sa 变成 ks→ksa，并满足 (ks)⁻¹(kg)=s⁻¹g，所以保持最短距离。对应的学习要求是 D(ks,kg)=D(s,g)，不是 Q(ks)=Q(s)；后者会使所有状态向量坍缩。共同右乘、任意颜色置换或整体空间旋转不能不经检查就当成同一种对称增强。

## 距离规则的表达边界

**L1：**同面四转构成图四环 A—B—C—D—A，边长为一、对角距离为二。若用任意维 L1 精确表示该环，则对任意目标 g 必须有 D(A,g)+D(C,g)=D(B,g)+D(D,g)。魔方存在到目标距离为 (12,11,12,11) 的实例，左右分别为 24 与 22，产生矛盾。整体缩放不能改变该限制。

**L2：**距离一加一等于二的等号，要求中间点位于两端中点。四环两条最短路径的中间点因此重合，与其相距二矛盾；同样无法精确表示该环。

**L∞：**有限状态集合可用到各状态的距离作坐标，再取最大绝对差，精确恢复集合内距离。但所需坐标数可以随集合扩大；有限构造不保证 128 维网络覆盖整个魔方。[已有数学见证](linf_dimension_witness.json)进一步证明，128 维 L∞ 不能同时精确拟合全部魔方距离，其全体距离的最坏绝对误差至少为 0.5。可复核检查见 [test_quarter_turn.py](../tests/test_quarter_turn.py)。

这些限制不证明正确动作排序不可学。当前目标是形成可用于行动的近似距离空间，而不是把零误差作为前提。

## 监督需要连接什么

所有动作边若在向量空间中都不超过一步，三角不等式就保证任意向量距离不超过真实最短距离。远距离监督再要求状态充分分开，才能排除“实际很远、向量却很近”的捷径。只在部分采样边上成立，不构成全图保证。

因此需要把局部动作边、多目标远近与跨集合关系联结到同一个编码器，并检查训练是否真的满足这些约束。曝光过标签不等于学会；平均误差较低也不保证正确动作始终更近。对固定目标，贪心策略一旦重复状态，就会重复动作形成循环，必须用完整到达检验。

## 相关工作可借鉴什么

| 来源 | 可借鉴之处与适用边界 |
|---|---|
| [Pan & Kondor：Fourier Bases for Solving Permutation Puzzles](https://proceedings.mlr.press/v130/pan21a.html) | 用群表示表达动作组合；其固定目标价值学习不能直接证明任意目标共享 Q 的固定范数可行 |
| [DeepCubeA 作者实现](https://github.com/forestagostinelli/DeepCubeA) | 启发函数与搜索配合；搜索成功不能替代纯贪心地图的验收 |
| [Self-Supervision is All You Need for Solving Rubik’s Cube](https://arxiv.org/abs/2106.03157) | 自生成动作数据与搜索；打乱长度不能充当精确最短路标签 |
| [DeepCubeAI 论文及作者实现](https://github.com/misaghsoltani/DeepCubeAI) | 将状态表示、动作转移、目标代价和搜索分开检查；它的目标条件读出不同于本项目固定距离目标 |

DeepCubeAI 源码核对基于 commit `c93511a74ba0a03ae53b950994be8b8c3b2683ff`，未复现其训练。它联合学习二值状态码、重建与动作条件转移，再用当前／目标状态码预测动作代价并搜索。可借用的是将“一步状态是否完全正确”“自身预测连续递推是否保持正确”“真实环境能否到达”分开验收；具体入口为 [train_env_disc.py](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/training/train_env_disc.py#L412-L491) 与 [test_model_disc.py](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/scripts/test_model_disc.py#L125-L157)。

不直接将当前 Q 二值化：不同二值向量的 L∞ 距离恒为一，会失去所需远近。离散状态身份与连续距离坐标承担不同职责。当前仍保留共享 Q 与固定距离，未引入 DeepCubeAI 的转移头、目标条件读出或搜索。
