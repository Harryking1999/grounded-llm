# 魔方地图的结构与可检验改进

调研日期：2026-10-16。范围：二阶魔方的状态表示、动作组合、距离与求解；通过原论文和作者代码核对。检索词包括 Rubik cube group representation neural heuristic、Fourier Bases for Solving Permutation Puzzles、DeepCubeA、DeepCubeAI。以下是定向研究记录，不是穷尽性的系统综述。运行结果仍归 [report.md](report.md)。

## 当前任务究竟缺什么

目标是一个跨目标共享的状态地图，同时能支持全局关系与动作转移。现有 Q(s) 通过 Huber 距离和完整候选软排序训练；后继由精确环境产生，没有学习转移函数。因此必须分别验收“知道朝哪个目标走”和“知道动作把状态变成什么”。距离拟合、动作排序、单步转移及多步闭环不能互相替代。

已经实现的结构包括：角块身份与朝向的联合独热；固定 DBL 的参考系；完整群相对状态的精确距离标签；共同左乘的在线变换；两步局部图及完整候选监督。不能把这些再命名为新改进。

## 结构约束如何处理

在本环境的右乘动作约定下，动作执行为 s→sa；共同左乘 k 保持边 ks→ksa。相对状态 (ks)⁻¹(kg)=s⁻¹g 不变。共同右乘通常会共轭动作，不保证仍是六个单步动作之一。整体空间旋转也要核对固定 DBL 参考系、重新规范化与动作重命名，不能直接把 24 个姿态混进当前六动作条件。

动作逆关系 aa⁻¹=e、同面四次 a⁴=e 必须成立；不同面的动作通常不交换。只用可加动作向量 Q(sa)=Q(s)+v_a 会有问题：四次同向动作回原态要求 4v_a=0，实数空间下导致 v_a=0。应考虑非平凡的可逆算子，而不是简单平移。若采用群表示 ρ，则组合满足 ρ(sa)=ρ(s)ρ(a)；截断或低维表示可能把不同状态映到一起，仍须检验可区分性。

最短距离是动作路径的长度，不由“具有群表示”自动给出。结构正确但只会判相邻、逆操作与闭环，依然可能不知道远目标方向。

## 按失败风险排序的实验建议

1. 先完成匹配的 L1/L∞、必要时 L2 对照。L∞ 的锚点构造证明有限度量可表示，但 128 个学习坐标不保证覆盖最短路的见证锚点。L2 对四环已有零误差障碍，仍可试近似排序。
2. 若 L∞ 仍失败，先用精确锚点距离做离线表示诊断：固定训练侧锚点，比较真实锚点坐标在中程的动作排序和长程到达。它读取 oracle，只能是表达能力上界，不能列作学习成功。若上界也弱，盲目监督网络拟合少量锚点缺乏依据。
3. 若证据指向状态编码与组合能力，再单独比较群结构表示，或一个共享动作条件转移函数 T(Q(s),a)。先检查一步后继、逆动作、四转闭环与非交换动作序列，再测试未训练组合的多步转移及地图排序。不能通过所有状态映到同一点来满足闭环；必须保持可区分性与目标距离。

后两项是有序候选，不是本次已完成结果，也不与当前只换度量的主对照合并。已有距离差、进展边距和错题重放负结果提示：局部修正可能破坏其他关系；必须保留固定监测集和完整 rollout，不因训练池被修好就宣称形成全局地图。

## DeepCubeAI 实现细读

核对作者仓库 commit `c93511a74ba0a03ae53b950994be8b8c3b2683ff`（2025-08-28）及 [RLC 2024 正文](https://rlj.cs.umass.edu/2024/papers/RLJ_RLC_2024_225.pdf)。以下是源码阅读与小型代数检查，没有复现其训练或精度。当前仓库经历过更新，不能把现在的默认值自动当成论文实验配方。临时检出位于 Git 外 `tmp/DeepCubeAI/`。

### 最关键的区别：状态身份、转移和目标关系分开

```text
图像 s → 编码器 → 二值状态 z(s) → 解码器 → 重建图像
                     │
                     ├─ 与动作 a 拼接 → 转移网络 → 连续预测 → 取整 → 下一二值状态
                     │
z(s)、z(g) ───────────┴─ 拼接 → 目标条件 DQN → 每个动作的剩余代价
                                              │
                                         Q* 搜索
```

[cube3.py](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/environments/cube3.py#L67-L204) 中，编码器输出 400 个 sigmoid 值，经阈值变成 400 bit；解码器重建两视角的 6×32×32 图像；转移网络输入二值码和动作独热，输出下一状态的 sigmoid 值。DQN 输入当前、目标两份状态码的拼接，输出各动作代价。

它的 Q(s,a,g) 是动作代价，不是我们的 Q(s) 状态向量。它不要求状态码的固定范数等于图距离。这避开了当前几何限制，却也改变了研究条件：学到目标条件读出，不等于证明目标无关向量本身具有可读的全局距离几何。

### 可借鉴一：让表示既保留状态，又便于预测动作后继

[train_env_disc.py 的 step_model](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/training/train_env_disc.py#L412-L491) 联合训练编码器、解码器和转移网络，而非先学一个任意自编码器后永久冻结。记二值后继编码为 z′，转移网络连续预测为 p，sg 表示停止该目标分支的梯度：

```text
重建损失：当前状态和真实后继各自的重建误差
转移损失：½ MSE(z′, sg(round(p))) + ½ MSE(sg(z′), p)
总损失：重建与转移的加权和
```

第一项调整后继的编码，使其向转移模型的二值预测靠拢；第二项让预测向后继编码靠拢，也可经当前状态输入影响当前编码器。停止梯度只用于各项目标分支，不是冻结整个编码器。二值阈值使用 [STEThresh](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/utils/pytorch_models.py#L13-L42)，前向离散，反向用近似梯度。

**对我们的判断：**现有距离目标允许丢掉对动作预测有用、却不易降低当前距离损失的信息。重建角块身份与朝向，以及动作条件后继预测，是比再次增加距离标签更直接的候选。但源码机制不能证明我们的 Q 确实丢失了这些信息，应该先用冻结编码的重建／转移 probe 定位；若 probe 失败，也要区分表示信息缺失与 probe 容量／优化不足。

只加潜变量转移一致性有全体状态塌缩到常量的平凡解；重建提供保留状态内容的约束，但有限样本上的重建成功仍不保证全空间无碰撞。

### 可借鉴二：每步回到离散状态，并检查整状态而非平均误差

预测结果每一步取整，下一步使用取整后的模型预测，避免较小连续误差直接累积。只有每一位都落在正确阈值一侧才有效；误差越过阈值或进入未见潜变量时，取整仍会产生错误状态，不能视为全局纠错保证。

[test_model_disc.py](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/scripts/test_model_disc.py#L125-L157) 分开报告逐 bit 一致率与整行全部一致率；[自由递推](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/scripts/test_model_disc.py#L280-L303) 使用自身预测作为下步输入，真实后继只用于评分。论文 §5.1 使用 10 条各 10,000 步的随机动作序列；当前复现脚本采用自己的测试配置，二者不能混写。

**对我们的判断：**适合借用其验证方式。对二阶魔方，应比较精确角块状态的一步与多步完全正确率、首错步数、逆动作和四转闭环、非法状态比例，并在非交换动作组合上检查。若之后采用离散表示，我们已经有结构化角块输入，可先考虑身份／朝向的分类码，无需先把状态渲染成图像再重学感知。类别输出独立 argmax 不保证角块排列与朝向总和合法，必须如实报告非法状态，不能用 oracle 自动修补后计作成功。

**不能直接二值化当前 Q 再用 max：**任意两个不同二值向量的 L∞ 距离都是 1；L1 变成 Hamming 距离，L2 是其平方根。离散身份码与距离坐标有不同职责。借鉴它的离散状态码，需要单独的关系读出，或与连续距离坐标区分；不能声称是原固定度量方案的直接修复。

### 可借鉴三：用动作后继关联目标代价，而非用打乱长度当标签

[update_utils.py](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/utils/update_utils.py#L89-L132) 使用学习模型产生后继，并构造 Bellman 目标 `1 + min_a′ Q_target(s′,a′,g)`，当前状态等于目标时为零。起点经模型随机行走，目标再从该起点随机行走生成（[代码](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/utils/update_utils.py#L239-L254)），实现可达目标的重标记思路。随机行走步数用于生成状态，不作为最短距离标签。

**对我们的判断：**当前二阶魔方有精确距离裁判，不需要马上用含模型误差的自举标签取代真标签，也没有必要原样复制大型 RL 流程。值得借用的是明确连接“执行动作—后继—目标”的一致性诊断。若真要比较 Bellman 训练，先保留同一数据／预算和完整候选，并独立列出，不与本轮只换范数混合。

### 搜索、对称性和复现边界

[Q*](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/search_methods/qstar_imag.py#L181-L202) 用离散状态 bytes 判重，并保留更低路径代价；[最终解](https://github.com/misaghsoltani/DeepCubeAI/blob/c93511a74ba0a03ae53b950994be8b8c3b2683ff/deepcubeai/search_methods/qstar_imag.py#L862-L870) 在真实环境重放验证，潜变量到达不自动算真实成功。判重可靠性仍依赖编码不发生有害碰撞。

**论文表 1 中，三阶魔方 RC 的作者贪心策略到达率为 0%，DeepCubeAI 加 Q* 后为 100%；反向起终点条件分别为 0% 与 99.9%。**这是不同任务与预算下的论文结果，不是我们的二阶魔方对照。它说明可靠转移模型与搜索可以有效配合，并未证明一个纯贪心全局距离地图已经学成。反向起终点也不是任意两个新目标组合的完整泛化证明。

在已检查的 Cube3 网络和训练路径中，没有发现专门强制群等变、逆动作或四转闭环的损失；转移用通用动作拼接 MLP。不能把它描述为已经用魔方群结构解决了环约束。当前二阶魔方的共同左乘和完整局部图仍有独立价值。

实现与文字也有差异：论文描述逐步提高转移项权重，当前 `train_env_disc.py` 的训练循环使用传入的固定 `env_coeff`；循环中 `num_steps=1`，虽然 CLI 暴露了更长预测参数，实际这条路径是一阶训练，再做自由多步评测。当前 `qlearning.py` 也使用了过估平方误差、低估 Huber 的非对称损失，而非照抄论文中的普通平方误差。借鉴时应根据实际执行路径设计，不直接继承参数名和默认值。

### 当时的候选建议（已被下节的用户范围约束收窄）

1. 完成本轮 L∞／L2 固定度量对照，保持原因可辨。
2. 在现有冻结 Q 上做小型状态重建与动作后继 probe，先判断它是否保留可读的状态和转移信息；这只能检查读出能力，不是自主学会转移的结论。
3. 若需要联合训练，单独比较“原关系损失 + 状态重建 + 动作转移”；是否离散化由多步漂移证据决定。保留原关系指标，防止转移变好却破坏远目标排序。
4. 若固定几何始终限制排序，再明确比较目标条件关系读出。它仍可共享状态地图，但研究主张须从“固定范数读出图距离”调整为“共享状态表示支持学习的目标关系”。搜索另列辅助条件。

以上为研究建议，尚未把 DeepCubeAI 架构接入当前正式训练。

## 保留 Qmap 内在距离：当前范围与下一步判断

用户明确要求保留目标无关 Q(s)，用固定距离规则直接得到远近；当前不采用目标条件关系网络替代该结构。上节涉及独立关系读出与转移头的建议不作为当前执行方向。下面仍是候选设计，没有启动新的正式训练。

### 距离规则

L∞ 仍是有直接表达依据的基线；L1、L2 的零误差障碍不能靠更多数据消除，但零误差障碍也不等同于排序不可学。128 维 L∞ 没有全状态精确保证，随机固定锚点的失败也不否定其他可学习坐标。

一个兼顾局部可加结构与多种全局分离方式的固定规则候选是**分组 L1 后取最大**。将 Q 分成固定的块：

```text
D(s,g) = max_b Σ_j |Q_bj(s) − Q_bj(g)|
```

它对称、非负，在向量空间满足三角不等式；不同状态若被编码成同一向量仍会距离为零，因此这些性质不保证状态可区分。组内可由多个坐标共同形成距离；外层 max 使不同状态对可由不同组决定远近。相较单坐标 max，通常可将同一次距离监督的梯度传给获胜组内多个非零差坐标。这是优化机制的假设，不是改善保证。

该规则保持同一个状态编码器和固定读出，没有增加目标条件网络。本地构造检查：把 128 维暂分为 16×8，将已知五点反例的五个真实锚点坐标各放到不同块的一个位置，其余为零，可以得到零误差的完整五点距离矩阵。它证明候选避开了这个特定反例；不证明全魔方可精确嵌入，也不证明一定优于 128 个独立 L∞ 坐标。分组减少独立 max 分支数量，是需要权衡的容量限制。

Pitis et al. (ICLR 2020), [An Inductive Bias for Distances](https://arxiv.org/abs/2002.05825)，讨论了保留三角不等式的非欧氏范数与图距离拟合。本文分组固定规则是本项目候选，不是已复现的论文方法，论文结果不能替它背书。

### 已有监督和数据，不应误判为缺失

已有精确长程距离、全部相对根类型、完整后继排序、两步局部图和共同左乘；四转面环也可出现在该局部图中。完整绝对距离、距离差、进展边距和错题重放均已有负结果。因此不能再次把“补距离标签”“加一个 margin”或“多见一些随机状态”当成未经检验的新解释。

一次固定训练批检查有 4,480 个呈现状态、1,024 个绝对距离对及 5,316 个候选到目标的排序关系；抽样局部距离对中距离 1/2/3/4 分别为 22/51/58/125。该单批仅用于理解采样，不是全训练曝光统计。它显示均衡根深度不等于均衡边、环与远目标的联合约束。

**待验证的缺口是组织和权重，而非逻辑上没有真标签：**同一批稳定状态向量同时面对多个目标、完整的环边和对角线、连续最短路径，以及在中程的真实竞争分支。现有参数共享已隐式联立这些关系；提高同批交叉约束密度可能改善优化，但没有额外创造未知信息。

### 应怎样监督内在距离

1. 保留绝对步数校准。仅要求相邻状态接近，会把不相邻状态也挤在一起；仅排序也不保证步数尺度。
2. 把中程同目标的完整候选和最短路径一起训练。QTM 非终点后继真距离为 d−1 或 d+1，排序间隔为 2；若每个候选距离绝对误差均小于 1，就足以保证这一组最短动作排序，但这是充分条件，不是必要条件，平均误差不能提供此保证。
3. 显式配对保持距离的变换：D(ks,kg)=D(s,g)。这约束的是关系，不是令 Q(ks)=Q(s)；后者在本任务的传递群作用下会使所有状态表示坍缩。

还有一条可解释的约束分工：若所有动作边的向量距离都不超过 1，则由三角不等式，任意状态对的向量距离不超过图最短距离；远距离标签再要求足够分离，就可排除虚假捷径。只在采样边上成立不能给出全图保证。这是对目标作用的分解，不能未经对照就断言比现有 Huber 更好，更不应把若干损失一次性叠加。

### 最便宜的区分实验

先固定一个包含环、中程路径及多个目标的小状态集合，完整计算相关距离矩阵与动作候选。对于状态数不超过维数的集合，原始 L∞ 的全锚点构造提供确切可行解；再要求共享 MLP 拟合同一多目标集合。它比已有单目标过拟合检查更直接检验关系同时成立的能力。小集合成功仅表明拟合可行，不能作为泛化。

若自由坐标存在可行解而 MLP 仍拟合失败，应查编码与优化；若小集合拟合好但新共同左乘呈现退化，应查对称一致性与组合泛化。对于没有构造或不可行证明的候选，优化失败不等于几何不可能。小型检查通过后，才分别比较分组距离、配对对称监督与多目标数据组织，避免再次用一个大混合改动掩盖失败原因。

### 正在运行的模型提供的中途线索

验证侧诊断（非最终结果，来源 `90f6733`）：L∞ 在第 65,000 步保存的当时最佳模型中，2,800 个状态对的最大坐标差只由 19/128 个坐标取得；共同左乘前后的预测距离差均值约 0.880、最大约 4.291。该现象不证明其余坐标在全部训练中没有用，但提示 max 的监督覆盖与对称一致性问题。相应 L1 当时最佳点为第 85,000 步，约 68.4% 的坐标输出接近 sigmoid 上下界；L∞ 并没有这个饱和现象，因此不能用同一个饱和解释两者。原始诊断保存在正式运行目录的 `interim_geometry.json`，不能代替最终性能。
