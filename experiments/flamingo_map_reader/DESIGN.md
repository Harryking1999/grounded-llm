# 完整轨迹 SFT：训练与评测方案

依据：[飞书 4.2](https://zcnhpsd26tyi.feishu.cn/wiki/ZNNSwpIo0iHwMgk7mk7coBA3nzb#BJmUde2p6oN7SxxELqkcIfUEnIe)（已核对修订 121）及本次讨论。

**本轮做两项完整轨迹训练：寻路只用一张图和它的 Q；积木用 1000 张初始棋盘。读取、比较、动作和终止在同一次 SFT 中学习，并在每一轮评测。**

用户已授权落地并启动四 GPU 队列。本轮优先长轨迹；正式参数以 [寻路配置](configs/path_single_long.json) 和 [积木配置](configs/blocks1000_long.json) 为准，实际覆盖与运行状态见项目状态页。

## 1. 两项任务分别训练什么

| | 寻路 | 积木 |
|---|---|---|
| 要回答的问题 | 对一张固定地图，LLM 能否读懂其 Q，并据此完成新任务？ | 从 1000 张棋盘的状态与完整轨迹中，LLM 能否学会读取共享地图并行动？ |
| 地图来源 | 固定现有 `graph_00` 及其原 Q/V，不按旧模型成绩挑图 | 原定 1000 张八块初始棋盘，使用共享冻结编码器 `tree_1000_132f5a1/best.pt` |
| 后继输入 | Q(current)+V(action) | Q(真实合法后继) |
| 监督距离 | 原 Q 空间欧氏距离 | 该编码器原有的 `directed_sum` 有向距离 |
| 本轮测试重点 | 同一地图的新起终点和目标，不同时混入跨地图学习问题 | 同一批初始棋盘的新任务，以及另外初始棋盘的任务 |
| 权重 | 从头训练一份寻路接口 | 从头训练另一份积木接口 |

积木的“1000 张图”指 **1000 张初始棋盘产生的不同状态和任务**，不是训练 1000 个独立 Q。寻路成功后是否扩展多图另作决定，本轮不把跨图泛化作为成功条件。

## 2. 数据：先有足够多的物理任务，再扩充编号版本

### 寻路

**确定要求：**固定同一张图，扩大起点、目标、路径长度及沿途状态覆盖。不能继续只用 16 道题，也不能只取十步题。

按正式配置划分目标并确定基础任务数；同一目标只属于训练、验证或测试的一组，起点可跨组。按目标轮流取题，各目标先取真实最短路最长的任务，不为了填短程档而额外采简单题。已核对这张图直径为 11 步，本轮候选从 8 步及以上取；实际动作轨迹可能更长。

测试目标没有作为训练 goal 出现，但节点仍可能作为训练 current 或 successor 出现，所以称“同图未训练目标”，不称“未见节点”。每个分区另含初始即目标；数量不足会使数据构造明确失败，不以编号副本充数。

### 积木

全部 1000 张初始棋盘用于训练，使用原冻结共享 Q。复用已认证的长任务起终点和轨迹种子，重新生成完整数值回答与编号版本，不复用旧 reader 权重或 swap 标签。已有物理任务主要为 7–8 步；每板的任务数、最短长度下限及留出规模由正式配置指定。

- 每板优先保留可用长轨迹，沿途自然包含接近目标的状态，最终终止段完整保留。长轨迹覆盖了短后缀，不等于已经证明短后缀学会；仍按剩余步数单独评测。
- 每板另取初始即目标样本。验证／测试同时包含训练初始棋盘上的新任务与另外初始棋盘的任务，新棋盘集合互斥。
- 不仅排除训练起终点，还排除训练轨迹中出现过的 `(current, goal)` 后缀任务。任务对全局去重，任何编号版本都不能跨分区。
- 新初始棋盘不等于所有状态都未见。逐题记录起点／目标是否曾作为训练 current、goal 或 successor 出现；Q 编码器自身的训练覆盖另列。
- 验证／测试只按真实可达性、长度与划分取样，不按地图贪心成功与否筛选。

### 两项共同的轨迹构造

1. 先划分物理任务，再生成完整轨迹，最后生成编号版本；任何编号增强都不能改变分区。
2. 用冻结地图的贪心动作生成成功示范；并列最优中选择一条真实动作，固定物理动作序列。记录候选任务中的贪心失败和筛除数量。
3. 每个决策段保留当时的**全部合法候选**，包括较差、远离目标或进入死路的动作。不因它不是示范动作而删除。合法性沿用任务规则：寻路不重复访问已走节点，积木遵守原八种形状的移除规则。
4. 一条成功轨迹为 T 个动作段和 1 个终止段。即使最后一步由环境确认已到达，也必须再让模型输出终止和总结。
5. 保存 trajectory_id、step_id、当轮地图、编号到真实动作的映射、真实历史、标签和结束标记。
6. 验证／测试任务只按环境可达性与分区选择，不按地图贪心是否成功筛选。逐轮参考历史使用同一地图贪心真实生成的轨迹，包括失败前缀；不能为补一个终止段伪造到达。闭环测试始终保留这些失败题，终止样本另列。

## 3. 随机编号：多套编号，每套反复学

**同一物理轨迹先固定，再为沿途每一步改变候选编号。**换编号时，真实动作、后继 Q、文字编号、距离列表、排序和动作标签一起更新；历史始终记真实动作。

每条非终止基础轨迹生成至多 **6 套不同的完整编号版本**，再将这批固定版本完整训练 **3 遍**。一条有 6 套版本的轨迹共出现 18 次，每套相同编号出现 3 次；不是每次临时抽一套以后就不再见。

具体覆盖方法：

- 寻路每轮最多三个候选：三个候选的 6 种排列全部覆盖；两个候选的 2 种排列平衡重复；一个候选只有一种。
- 积木候选多：每轮固定抽取至多 6 个互不相同的随机排列；不能宣称覆盖了所有排列或每个动作的全部可能编号。
- 不同轮次的排列组合成完整轨迹版本。去掉完全相同的完整版本；若本来就不足 6 套，保留实际数量并报告，不伪造多样性。
- 初始即目标没有动作编号，保留一个版本，每遍训练重复一次。
- 训练顺序打乱；编号版本本身保持固定，以便确实重复学习。应记录实际版本数与曝光次数。

数据摘要同时给出 **基础轨迹数、动作轮数、独立编号版本数、每版本重复次数**。例如 8000 条基础轨迹的 6 套编号仍是 8000 条物理任务，不是 48000 道独立新题。

测试在每道基础任务上固定抽取至多 6 套编号，分别报告各版本成绩和同一真实动作的一致性。寻路训练若已覆盖某轮所有排列，就不能把测试重排称为“未见排列”；它检验编号一致性。新任务上的正确才用于判断泛化。

## 4. 一次 SFT 同时学习读取与行动

### 文字、地图和回答

初始提示保留任务规则与真实状态信息：寻路给完整图、起点和目标，积木给形状、棋盘和目标。每轮环境更新只给实际状态、真实动作日志及当轮合法候选。模型通过 cross-attention 得到当轮 current、goal、successors 的 Q。

按这次重新确认的 4.2，**恢复回答中的距离数值**。距离是输出监督，不预先写进环境提示，也不作为额外标量塞入地图槽。

未完成时，模型按固定模板生成：

```text
当前状态尚未达到目标。
当前状态到目标的地图距离：{d_current}。
各候选到目标的地图距离：{1: d_1, …, k: d_k}。
候选比较：{包含 current 的排序、并列及更近／相同／更远判断}。
选择候选 {i}。
<action>{i}</action>
```

采用统一的数值精度；采用配置中的固定小数精度。排序、并列与动作真值按未舍入的原始地图数值生成。如果两个显示数值舍入后相同，不把它误标为距离真并列。

完成时，模型生成达成判断、真实动作序列与步数总结，最后输出 `<done/>`。初始即目标时动作序列为空、步数为零。到达定义由环境核验，不能仅凭地图距离为零判定。

### 参数与损失

- 基座仍为 Qwen2.5-1.5B-Instruct。冻结 LLM 原有全部参数和认知地图 Q/V。
- 新插入的读取接口一起训练：投影 P、角色／编号嵌入、cross-attention 和现有可训练门控。两任务各自初始化、各自保存，不从旧小样本或 swap 权重续训。
- 沿用已确认的地址 K／状态 V 分离：角色与编号负责寻址，完整 Q 经 P 提供状态。不新增关系模块，不根据旧 swap 结果选择结构或尺度。
- 采用现有未校准 K/V 基础设置；普通 assistant-token 交叉熵，不开排序加权分支。优化器及学习率沿用已有普通 SFT 基础设置。
- 每条完整轨迹作为一个样本，teacher forcing 训练全部动作段与终止段。训练遍数按第 3 节固定编号语料的 3 遍计，不与“物理轨迹被看 18 次”混淆。
- 距离、排序和动作都在本次 SFT 中检验；没有先通过独立距离读出才能继续的条件。

### 动作边界和上下文

`</action>` 的全部 token 都读取当前地图 M_t。完整标记生成后才执行动作、更新真实状态与地图；下一轮输出从 M_(t+1) 开始。终止段全部使用最终地图 M_T，完整生成 `<done/>` 后才结束。

原有“旧 token 读旧轮地图、新 token 读当轮地图”的绑定保留。距离输出和积木多候选会加长语料，需用真实完整样本测长度、显存与训练耗时；不能静默截断长排序、后几轮或终止段。现有长轨迹实际 batch=1 可作为起点，最终运行预算据测量写入正式配置。

## 5. 同一批权重，评测整条轨迹

评测与上述 SFT 是同一实验，不另训一个只答首轮或二选一的模型。验证集用于过程观察，测试集冻结到训练结束；不能按测试成绩选 checkpoint。

### 先区分两个问题

| 评测 | 给模型什么 | 回答什么 |
|---|---|---|
| 固定参考历史下的逐轮生成 | 到该轮为止的正确真实历史、当轮环境文字及地图；当前回答由模型自由生成 | 在相同状态下，距离、排序、动作和终止各自会不会？ |
| 完整闭环 | 从起点开始，模型每轮自由生成，环境执行其实际动作并更新地图 | 它实际能否到达、停止并总结？早期错误如何影响后续？ |

训练集固定抽取 256 条基础轨迹作全轮自由生成诊断，用于判断训练内是否学会；其余按完整验证／测试集合评测，不再使用 16／4 题。训练样本的编号副本与留出任务分别统计。

固定历史评测中，当前段的距离和排序必须由模型自己生成，不能先喂正确距离或排序再只测动作。参考历史中的距离、排序与实际动作保持一致，当前标签按当前真实状态重新计算；同距最优动作集合中任取一个均计正确。完整闭环另看模型自行偏离参考轨迹后的状态。

### 每轮和整题分别记什么

| 层面 | 指标 |
|---|---|
| 距离读取 | current 与候选距离的平均绝对误差，另报数值缺失／非法率；真值为该地图原始距离 |
| 比较 | 逐对关系、完整排序、最近候选集合、比 current 更近／相同／更远的判断 |
| 动作 | 合法动作率、是否属于地图最优集合、是否遵循自己生成的排序；环境最短动作另列 |
| 终止 | 未到达时提前停止、已到达仍行动、动作序列与步数总结是否符合真实历史 |
| 闭环任务 | 到达率、正确结束率、实际步数、相对最短路径长度、生成 token 和耗时 |

按具体轮次、剩余真实距离、候选数量分层，并给出整题平均与全部轮次汇总。单候选轮不能稀释多候选比较的错误；终止轮单独统计。比较置信区间以基础任务或初始棋盘为单位，不能把编号版本和同轨迹各轮当作独立新样本。

### 检验地图是否起作用

- **候选重排：**文字、真实动作和 Q 同步重排，比较物理动作及关系的一致性。
- **真实目标替换：**在测试任务中选相同起点、不同真实目标的任务对，两目标在同一测试分区，起点最优动作集合不重叠；同时更新文字目标、目标 Q 与标签，分别执行完整轨迹。从冻结测试题中提取同起点、不同目标的配对；目标数量见配置，不足部分如实报告，不另造冲突标签。
- **无地图对照：**同一训练后权重、相同文字与预算，关闭地图 cross-attention 残差，再测相同任务。它是依赖性消融，不冒充重新训练的纯文字 baseline；不另开一组大训练。
- **地图贪心控制器：**直接用同一 Q、同一合法动作约束跑相同完整测试题，报告到达率和长度，作为读图行动参照。

候选编号变化只改表示；目标变化要改变真实任务。两者均不得再次变成“文字不动、随意交换两个后继 Q”的矛盾训练。

## 6. 代码与执行顺序

数据选择、编号与模板、缓存 Dataset、训练、评测、指标和队列各自独立，模块对应关系及运行入口见 [README](README.md)。

队列先生成两项正式数据，再分别用实际最长训练样本做一次真实前向、反向和优化器更新，核对有限梯度与冻结参数，并丢弃 smoke 权重。通过后从新初始化启动正式 SFT，不截断轨迹来挤进显存。训练 checkpoint 保存完成才发布评测标记。

训练分别占 GPU 0、1；GPU 2、3 消费评测分片，训练卡完成后也转入评测。初始 checkpoint 仅做少量生成通路检查，不能用它估计能力；训练内诊断使用配置中的固定大样本集合，正式验证和最终测试全量执行。测试只评最终权重，不按测试成绩挑选。

所有运行产物位于 Git 外；配置与代码提交后才启动正式队列。旧 16／4 小样本、原四图和 swap 结果继续归档，不参与这轮结论。
