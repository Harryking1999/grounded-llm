已报告的主要候选边际分档（两候选到目标距离之差）的正确率为 0.506–0.518，包括距离差 0.49–1.38 的档位。该档下限已经超过小样本最大差距 0.384，上端约为其 3.6 倍。因此，仅用新增近似并列题无法解释失败；这没有排除所有分布变化。

**分档口径限制：**当前脚本用 `2048 // 5 = 409` 为块大小，实际会产生五个 409 样本块和一个 3 样本尾块，且可能切开 swap 对。本次未取得逐样本输出重新分档，不能把原摘要写成“严格五等分且全部分档均如此”。

`training_ce` 约 0.064 而 `decision_ce` 约 0.700，与“11 个回答 token 中主要只有一个二选一位置不会”相容：ln(2)/11≈0.063。对于相同文字、相反标签的配对题，纯文字预测的最优平均决策损失为 ln(2)。当前行为接近这个水平，但这些是训练题首次决策 token 的条件概率，不是留出自由生成或规划成绩；也没有通过地图消融证明所有已学行为都只来自文字。

## 3. 接口实际送达了什么（`diagnose_interface.py`）

对配对样本的前向做逐层挂钩。适配器返回 `hidden + tanh(gate) * read`，相减得到有限精度下实际落入隐藏态的增量，不等于未舍入的理论分支。注意力另行重算；分支重算相对误差曾达 0.54，不能据此声称重算已经精确验证。`rounding_loss_rate=0` 只表示没有一个被测位置的整个增量被完全舍去，不能排除部分维度受 BF16 舍入影响。

| 层（0/8/16/24/27） | 小样本 16 题 | 扩大 1024 题 |
|---|---|---|
| `tanh(gate)` | −0.0054 … 0.0104 | −0.0014 … 0.0131 |
| 读入项 / 隐藏态 | 0.0056 – 0.25 | 0.0087 – 0.09 |
| 每 head 两槽注意力差的绝对值，再取平均 | 0.48 – 0.67 | 0.39 – 0.69 |
| **左候选正确时的槽位差** | **0.5225**（第 12 层） | **−0.2732**（第 12 层） |
| **右候选正确时的槽位差** | **0.5221**（第 12 层） | **−0.2729**（第 12 层） |
| 交换后决策位层输出 hidden 的相对变化 | 0.098 – 0.42 | 0.018 – 0.026 |

解释边界：

1. 0.5225 与 0.5221 是接近，并非四位小数相同。按正确侧分组的槽位差均值没有明显翻转，但这不证明注意力在所有题目上固定，也不证明候选绑定失败：固定读取左／右槽，再在下游比较，是有效计算的一种可能。
2. `tanh(gate)` 的量级不能单独判定通路是否关闭，实际注入／hidden 范数比为小样本 0.56%–25%、扩大 0.87%–9%，不是统一的 1%，也不是信噪比。
3. 交换相对变化的分母是原始**整个条件化语言层输出**的 hidden 范数，并非地图分支范数；小样本为约 10%–42%，扩大为约 2%–3%。两模型各自在自己的训练题上测量，这一差异尚未隔离数据分布因素。

## 4. 这个标签到底需要什么计算（`diagnose_scoring.py`，1024 个训练对）

[`graph.py`](../../src/graph.py) 定义 `candidate_distances = ‖后继Q − 目标Q‖`。以下 c、g 指**原始后继 Q 与目标 Q**，不是经过投影 P 和 cross-attention 的 value。探针直接从 `map_batch.vectors` 取出它们。

| 打分函数 | 评估口径 | 正确率 |
|---|---|---:|
| 线性 `w·[c,g]` | 512 对拟合，512 对内部留出 | 0.551 |
| 二次 `[c,g,c⊙g,c²,g²]`（⊙ 为逐维乘积） | 同一划分，固定步数梯度拟合 | 0.803 |
| 直接代入 `−‖c−g‖²` | 全部 1024 对，不训练 | **1.000** |

因为 `−‖c−g‖² = −Σc² + 2Σc·g − Σg²`，已知公式在数学上与标签一致；代码为五个特征块赋的权重是 `[0,0,2,−1,−1]`。闭式满分是标注一致性校验，不是学习成绩。二次探针按固定步数拟合，现有输出不足以判定收敛，也不能将 0.803 当作能力上限。

更强的代数依据是：共享线性分数 `a·c+b·g+d` 在两候选相减后变为 `a·(cL−cR)`，目标项完全消失。因此它无法表达一般的目标相关排序。0.551 是当前划分的实测值，不是线性方法在任何分布上都恰好随机的定理。原始 Q 上的结论也不证明投影后的欧氏几何或冻结 LLM 已保留这些关系。

## 5. 机制

单层、单 head、给定 α 时，读入可写为 `r=Σ_i α_i Wv P(Q_i)`。接口送入的是状态混合，没有显式保证候选与目标分别出现在可寻址的位置；模型仍需保留身份并形成目标相关的非线性关系。这一学习负担与失败相容，但尚未由干预实验确认为根因。

- **16 题成功的局限：**交换能改变混合，32 个样本反复训练约 72 轮后，可能拟合具体混合模式与编号的对应。训练成对全对、同图新目标 55/768 对正确，与局部记忆解释相容，但不直接证明内部执行了查表。
- **1024 题的观测：**模型已接近纯文字限定候选的损失水平，尚未形成可靠比较。这不证明 1024 题在容量上不可记忆，也没有排除每题优化次数、优化路径或分布变化。

“必须先反解混合再相乘”也不是必要条件：多 head、多层与多文本位置可能提供足够的混合观测，后层 query 可受地图注入影响；非线性网络还可能直接在混合空间计算比较函数。现有监督没有直接教分解步骤，但存在最终标签监督，不能称为没有监督。需要保留的信息及关系是否容易学到，才是待检验问题。
