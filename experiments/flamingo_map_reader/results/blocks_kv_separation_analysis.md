# 积木读取接口分析：是否恢复 K/V 解耦

历史架构分析，2026-10-08。比较融合FFN小batch的3.5轮完整结果与更早分离K/V输出；后续完整结果见[FFN报告](report_ffn_failure.md)与[分离K/V报告](report.md)。

## 1. 需要解释的现象

现在有两个不同的问题：新断点首轮选择较弱，以及 reference 总体成绩远高于自主 rollout。首轮尚无模型自身的先前回答，后续两模式的差距则同时受到状态、历史和轮次构成影响。二者需要分别检验。

| 已有证据                 | 计数／结果                                           | 能支持的判断                                       |
| -------------------- | ----------------------------------------------- | -------------------------------------------- |
| 新模型首轮保持目标可达          | reference 245/510（48.0%）；rollout 256/510（50.2%） | 当前首轮动作弱 |
| 新模型首轮选择编号 1–3        | reference 400/510（78.4%）；rollout 399/510（78.2%） | 有很强的低编号选择偏向，且在自主历史形成前就存在                     |
| 新任务首轮候选数             | 最少 20，中位数 58.5，最多 102                           | 约 78% 不是仅由首轮候选很少造成；均匀随机选择 1–3 的逐题平均概率只有 5.4% |

这些是第二性原理层面的统计约束。它们足以确定优先调查的环节，尚未识别内部因果机制。

## 2. 代码里实际改变了什么

核对 [memory.py](../src/memory.py)、[fusion.py](../src/fusion.py) 和 [train.py](../src/train.py) 后，两种结构可以写成以下形式。令 `Q_i` 是一个地图槽位的状态向量，`r_i` 是角色，`c_i` 是本轮候选编号；`l` 表示读取层。

**旧结构：地址作 K 输入，状态作 V 输入。**

```text
a_i = concat(role_embedding(r_i), id_embedding(c_i))
u_i = P(Q_i)
K_l,i = W_K,l LayerNorm(a_i)
V_l,i = W_V,l u_i
```

角色和编号提供地址，地图向量提供内容。旧主运行没有值分支 FFN；现有 `AddressedMapMemoryEncoder` 另外支持可选的值分支残差 FFN。

**当前结构：先融合，再分别投影为 K 和 V。**

```text
z_i = FFN(concat(Q_i, role_embedding(r_i), id_embedding(c_i)))
K_l,i = W_K,l LayerNorm(z_i)
V_l,i = W_V,l z_i
```

共享 FFN 对各槽位使用相同权重，输出供所有读取层使用；各层仍有独立的 K、V 投影。这里的融合不是令实际 attention 的 K 与 V 相等，也不是取消 K/V 两个投影矩阵。真正取消的是输入的信息分工：状态现在能影响地址，编号现在也能影响内容。输入维度与参数化也随之变化，正式尺寸和训练参数以[当前合同](../configs/blocks_ffn_failure_batch4.json)为准。

两种结构都用语言隐状态生成 attention query，读取结果再经过输出投影和 `tanh(gate)` 残差加入冻结语言模型。因此，语言提示和地址分支仍包含编号。

评测新启用的地图 K/V **缓存**是计算复用，与此处讨论的地址／状态分工是两件事；已有配对短测的回答和评分一致。

## 3. 为什么解耦值得作为候选

**假设 A：稳定地址减轻读取难度。**

旧结构固定角色和编号后，K 不随该槽位的棋盘内容变化。当前结构的同一编号则可以随 `Q_i` 改变 K，模型必须在变化的特征中保持编号绑定。如果新模型不能稳定把语言中的“候选 j”对应到该地图槽位，几十个候选的首轮可能更容易出现关系错误。恢复地址分支可移除这条依赖。

这是假设，首轮排序差，也可能来自正确取到向量后不会比较 current、goal 和候选关系；本次没有测量各层是否取到了 intended slot，也没有通过固定状态干预区分检索与比较。

**假设 B：编号进入 V 后提供了更直接的输出捷径。**

当前 FFN 可把编号编码进值内容，读取后可能较容易驱动某些编号 token，而不必正确理解地图关系。旧结构对值分支规定只接收状态，因而限制了这条路径。首轮集中输出 1–3，与这个机制相容。

但旧 step 49,000 同样有 71% 的低编号选择，说明旧分工没有自动消除捷径。语言模型也可以靠文本、查询或地址偏向输出低编号。当前 78% 只是强输出偏向的证据。

**假设 C：共同特征承受不同学习目标的牵引。**

当前同一 FFN 同时为寻址和内容服务：其参数更新会同时改变 K、V。解耦使两类变化更容易分别调节，可能减轻学习难度。K/V 分支梯度方向、实际 optimizer 更新与受控训练对照待补充。

这三个假设提供了恢复解耦的理由。

## 4. 现有实现与训练差异

**状态参与 K 本身没有逻辑错误。**按内容决定注意力可以帮助找到与目标相关的候选，编号参与 V 也可能帮助把所读内容绑定回输出编号。融合形式在表达上允许保留身份和状态信息，把状态影响 K 称为“污染”会先假定一种寻址方式必然正确，超出现有证据。

**候选早已重编号。**`blocks_step` 在 rollout 使用随机排列；训练的 `numbering_plans` 为大候选集合抽取不同排列，`numbered_step` 同步移动动作、后继、向量与距离，保持编号和物理动作对应。普通非零步训练任务有多套固定编号。因此，预览中“候选按固定 placement 顺序导致低编号答案”的解释与现有实现不符。固定有限增强仍可能留下样本统计偏差，但需读取实际 gold 标签后验证。

**训练成熟度和监督分布仍是竞争解释。**旧低编号偏向从约 71% 降至约 23%，支持将后续断点变化纳入观察。当前逐轨迹平均损失同时监督排序、动作与终止；晚轮候选较少，低编号出现机会更高，也可能影响总体 token 学习，但本次尚未按训练轮次核对编号标签频率和各部分有效更新。

首轮 reference 为 48.0%，第 2 轮起显著升高；下一轮使用 gold 排序和动作历史，状态也沿参考轨迹。仅按 rollout 的轮次构成重新加权，reference 总体从 81.8% 降到 68.5%，仍高于 rollout 的 55.9%。这剩余差距并未控制状态和历史。

**门控注入幅度。**同一批成功训练输入上，接近更新数时旧／新的局部注入幅度约为 9.74%／11.28%；新架构并不更小。这里测量的是注入能量。

旧／新历史对照还混入不同留出任务、global batch、失败数据、训练预算和初始化。即使旧模型在当前题上更强，也首先说明旧训练得到的整体系统更有效；要识别 K/V 分工自身的收益，还需要其余条件匹配的训练比较。

## 5. 当前错误对架构讨论的约束

3.5 epoch 的 504 道失败中，420 道在前三轮首次失去可达性。239 次删掉目标占用格，265 次保留目标格却留下无法按合法形状移除的结构。原始格式大体可执行：首轮排序全部可解析，动作全部跟随自身排序第一名；整个 rollout 的 3,994 个可解析排序也都选择自己第一名。

首轮输出 top-10 与地图实际 top-10 的平均交集约 2.53 个，随机期望为 1.81 个，输出关系较弱。当前 reference／rollout 的首轮物理状态与合法动作集合相同，经 CPU 检查地图向量逐位一致；两种模式的编号则不同。现有问题优先定位为地图关系到排序、动作的转化。

耗尽动作后的 418 个失败末端中，224 个误报已经达标，192 个正确报无解；真正到目标的 6 个全部正确停止。终止分类是另一个问题，恢复 K/V 解耦未必解决它。当前失败监督只覆盖动作耗尽，不覆盖中途不可达判断。
