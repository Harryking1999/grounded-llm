## 与同期融合 FFN 的同题比较

2026-10-08 19:26（北京时间），只读取已保存回答，离线重算两种架构的同一指标。0.5 与 1 epoch 固定使用相同的 192 个普通任务，1.5 epoch reference 固定使用相同的 64 个任务，均为同棋盘新目标。逐题核对 ID、编号版本、起点、目标、采样种子、缓存文件及冻结地图一致；重建编号和地图距离，并验证已有排序得分可复现。未增加 GPU 推理或修改训练。完整分母、来源见结果摘要的 `matched_ffn_comparison`。

**当前差异主要在终止判断；地图排序和完整到达仍很接近，不能认定分离 K/V 已全面胜过 FFN。** 以下为 1 epoch 同题结果：R 为示范历史与状态下回答，F 为自身连续执行；F 的后续访问状态会随模型而不同。

| 选择地图最优候选 | 19.3% | 19.0% | 13.6% | 14.9% |
| 合法动作率（有候选轮次） | 99.29% | 99.94% | 99.37% | 99.56% |
| NDCG@10，排序位置倒数 | 0.552 | 0.560 | 0.497 | 0.497 |

rollout 首轮具有相同状态，地图最优选择为 FFN 10/192（5.2%）、K/V 9/192（4.7%），排序位置倒数 NDCG@10 为 0.238/0.246，也未显示明显差距。0.5 epoch 同题 reference 排序位置倒数 NDCG@10 为 FFN 0.520、K/V 0.526，rollout 为 0.531/0.523，到达且停止为 1/192 对 0/192。1.5 epoch 仅有 64 题匹配 reference，单步可达为 65.5%/68.1%，地图最优为 21.3%/19.9%，排序位置倒数 NDCG@10 为 0.574/0.568。局部动作与排序各有胜负，差距尚小，后者样本也少。

终止判断的差别更大。1 epoch 同题 reference 已达标正确停止为 FFN 72/126（57.1%）、K/V 120/126（95.2%）；0.5 epoch 为 36/126（28.6%）对 109/126（86.5%），1.5 epoch 为 41/45（91.1%）对 44/45（97.8%）。自身 rollout 耗尽后的无解报告则相反：1 epoch FFN 50/181（27.6%）、K/V 15/184（8.2%），0.5 epoch为 123/180（68.3%）对 20/178（11.2%）。这些是普通任务中的访问状态，尤其无解状态与历史不匹配；独立初始目标和固定失败测试尚无新 K/V 完整分片，不能替代其正式成绩。两者 1 epoch 都只成功 1/192，说明已达标状态的停止改进仍未解决到达目标的问题。

训练日志取每个断点前最后 500 次更新，重复恢复步按最后记录去重：

| epoch | FFN 平均 loss | K/V 平均 loss | FFN 裁剪前梯度范数均值 | K/V 裁剪前梯度范数均值 |
|---|---:|---:|---:|---:|
| 0.5 | 0.2501 | 0.2706 | 6.58 | 3.58 |
| 1 | 0.2427 | 0.2649 | 7.94 | 2.22 |
| 1.5 | 0.2393 | 0.2641 | 12.88 | 2.64 |

FFN 的训练 loss 低约 8–10%，但没有对应的大幅任务收益。两个结构的参数化不同，且梯度都按 1.0 裁剪，裁剪前范数不能作为实际更新幅度之比或训练优劣证据。1 epoch 前 500 步超过裁剪阈值的比例分别为 84.6%/75.6%。

因果解释仍受设置差异限制：两轮每 epoch 的普通训练轨迹同为 48,000，旧 FFN 却有 6,000 条无解轨迹，新 K/V 只有 1,000 条，初始目标均为 1,000 条。因此旧轮每 epoch 总更新多 10%，终止标签权重和 warmup 步数也不同。无解增强改变了终止标签在训练中的占比，可能同时影响训练均值及两种停止标签的倾向，这只是与结果相容的解释，尚未由控制实验验证；架构变化也同时改变了 K/V 的信息来源，不能单独归因于有无 FFN。建议先收齐既定三任务评测，再判断是否有必要控制这些差异。

## 历史快照：0.5 epoch 的 192 题随机比较

2026-10-08 17:06 离线计算，固定使用上述各 192 题的同一批完整分片，不纳入后来完成的分片。对每一轮，在其全部合法候选中均匀随机选动作或随机排列，再对相同轮次等权平均。地图最优随机率为最优候选数量/合法候选数量；单步可达随机率为可达候选数量/合法候选数量。随机 NDCG 的期望精确计算为 `mean(gain) * sum(discount) / IDCG`，无需抽样或模型推理。重建了原编号及冻结地图距离，并验证全部模型 NDCG 与已保存值一致。

| 指标 | reference 模型 | reference 随机 | rollout 模型 | rollout 随机 |
|---|---:|---:|---:|---:|
| 单步保持目标可达 | 58.9% | 50.8% | 48.0% | 48.0% |
| 选择地图最优候选 | 16.9% | 15.3% | 16.6% | 16.2% |
| NDCG@10，排序位置倒数 gain | 0.526 | 0.505 | 0.523 | 0.527 |
| NDCG@10，地图距离倒数 gain | 0.840 | 0.830 | 0.878 | 0.887 |
| NDCG@1，排序位置倒数 gain | 0.312 | 0.283 | 0.302 | 0.299 |
| NDCG@1，地图距离倒数 gain | 0.733 | 0.707 | 0.801 | 0.807 |

reference 的单步可达高于随机约 8.1 个百分点，地图最优高约 1.6 个百分点；rollout 单步可达与随机相同，地图最优仅高约 0.4 个百分点，两种 NDCG@10 略低于随机。此处只有描述性比较，未据此声明统计显著或架构因果收益。

首轮的随机地图最优率在两种模式下均为 1.80%；模型 reference 为 1.56%（3/192），rollout 为 3.13%（6/192）。首轮单步可达 reference 55.7%、rollout 49.5%，随机均为 50.7%；首轮排序位置倒数 NDCG@10 为 0.193/0.207，对随机 0.199。首轮结果仍未显示稳定的地图读取优势。

距离倒数指标的随机基线本身很高：rollout 随机 @1 已有 0.807，表示随机候选的平均 gain 与最优 gain 之比已达约八成。模型 0.878 的 @10 不能单独作为有效排序证据。基线是在模型或示范访问的状态上计算，并非随机策略自身的连续轨迹；尚未运行随机完整路径实验，因此不能将模型 0/192 的到达率与一个未测得的随机整局到达率比较。
