**主结果看动作与任务完成：寻路 final 在全部 532 个 validation 任务上的到达率为 79.5%，到达且最短路率为 13.2%。积木 epoch 3 在作答前可解的 validation 参考状态上动作可达率 84.9%、最短路动作率 77.2%，但同一 checkpoint 的闭环到达率只有 187/1,100（17.0%），去掉 100 个初始即目标任务后为 87/1,000（8.7%）；参考状态上的动作选择与自身状态下的长程执行之间的差距是本轮的主要结果。**

结果快照：2026-10-05 18:18（北京时间），运行 `long_f73b700_20261004`。积木 epoch 1–4 的 validation 已齐，第 5 个 epoch 与最终测试未完成；分片来源和 checkpoint 对应见[证据摘要](long_trajectory_summary.json)，设置见[设计页](../DESIGN.md)。

**本轮读取接口只有一种结构。**角色与编号作为 attention 的 K（寻址），Q 的投影作为 V（状态内容），门控随训练更新；状态值尺度 `value_scale` 与固定门控 `fixed_gate_tanh` 都取默认值，不生效。此前的混合 K/V、固定门控、关系 token 加权与状态值尺度校准都不参与下面任何读数，逐条对照见[失败变体清单](archive/abandoned_readout_variants.md)。

## 1. 四个主指标

| 模式 | 主指标 | 判定与分母 |
|---|---|---|
| rollout：执行模型动作，保留自己的历史 | 到达率 | 到达目标的案例数／全部案例数 |
| rollout | 到达且最短路率 | 到达目标且实际步数等于环境最短距离的案例数／全部案例数 |
| reference：每轮给示范历史，模型回答不执行 | 动作可达率 | 选中合法动作后目标仍可达的轮数／作答前可解的决策轮数 |
| reference | 最短路动作率 | 选中动作使剩余最短距离减少 1 的轮数／同一批作答前可解决策轮数 |

最短路可能有多条，积木也可能有多种同样短的移除序列；**选中任意最优动作或走出任意最短解都算正确，不要求匹配唯一示范**。reference 的最短路动作是可行动作的子集；非法动作或未给出动作仍计错。rollout 的两项主指标不额外要求正确输出停止，总结与停止另列辅助诊断。

初始即目标任务只进入 rollout 的零步任务统计与终止诊断，不进入 reference 决策轮分母。reference 排除作答前已有死局，并保留全部轮次的原始计数供核对。百分比保留一位小数，精确值见摘要。

## 4. 地图贪心参照：按相同任务范围比较

## 5. 地图使用证据：以动作与对照为主

动作落入地图最小候选集合，说明选择与地图几何一致；接受集合中的任意动作，不要求复现某一个并列示范。它是读图的动作诊断，不替代上面的任务主指标。

| 积木 epoch 4 | 45.7% | 43.4% |

上表沿用全部参考决策轮分母，因为已有死局仍可评价地图一致性。积木的地图一致率（epoch 3 validation 41.3%）远低于同期动作可达率（84.9%），两者不矛盾：可达动作通常远多于地图最优动作，因此该列不能当作“是否用图”的主指标，只能说明选择的分布偏向，配对消融仍缺。要进一步说明模型确实使用地图，应看同题同编号的 map／no_map 在四项主指标上的差值，并结合真实目标替换与重编号后动作选择；这些对照结果仍待补充。长排序是更强的辅助输出要求，不能以其成败代替“能否选择有效动作”的判断。

| 寻路 epoch 1 validation | 316/532（59.4%） | 50/532（9.4%） | 83.8% |
| 寻路 epoch 2 validation | 408/532（76.7%） | 69/532（13.0%） | 90.0% |
| 寻路 final validation | 417/532（78.4%） | 68/532（12.8%） | 91.7% |
| 积木 epoch 1 validation | 145/1,100（13.2%） | 100/1,100（9.1%） | 90.1% |
| 积木 epoch 2 validation | 173/1,100（15.7%） | 106/1,100（9.6%） | 93.2% |
| 积木 epoch 3 validation | 180/1,100（16.4%） | 103/1,100（9.4%） | 92.0% |
| 积木 epoch 4 validation | 187/1,100（17.0%） | 110/1,100（10.0%） | 95.9% |

寻路主表的 70/532 是“到达且最短”，此处 68/532 还要求正确停止，两者分开保留。积木“到达且正确停止”采用 success 字段，与主表只要求到达的口径不同（epoch 3 有 7 个到达案例停错）。含正确停止的最短成功率仍在 9–10%，多数到达案例的步数多于最短解。寻路闭环的可达性字段覆盖 10,073/10,182 个决策轮，其余 109 轮按缺失处理，不将缺失按失败发布；积木四个 epoch 的闭环可达性字段基本完整（epoch 1／2 缺失 0 轮，epoch 3 缺 6 轮、epoch 4 缺 3 轮）。

### 分母与原始指标核对

积木 epoch 3 validation：6,409 个可解状态中，5,439 次保住可达（84.9%），4,947 次为最短路动作（77.2%）。其余 970 次是合法但使目标不可达的选择，0 次无合法动作。若把作答前已不可达的 1,833 轮也放回分母，原始两率为 66.0%／60.0%；这两种口径不混用。

寻路 final 闭环：10,182 个决策轮中 10,073 轮带可达性字段，全部保住可达（100.0%），6,937 轮为最短路动作（68.9%）。寻路的状态分布里合法动作几乎总保持可达，所以该列在寻路上没有区分度，必须与最短路动作率、闭环到达一起读。

随机基线先算每轮可行候选比例，再对相同轮次平均：积木 epoch 3 的可解子集为 50.3%，全部决策轮为 39.1%；寻路的可解子集为 100.0%。汇总器的 `reachable_candidate_rate` 现与 `action_keeps_goal_reachable_rate` 同取该可解子集（积木 epoch 3 为 48.8%），按候选槽位加权，不是相同分母的逐轮随机得分。所有原始计数保留在摘要中。

## 8. 当前结论边界

本轮已提供训练内动作拟合、留出 reference 泛化、积木四个 epoch 的闭环和完整寻路闭环证据。三条结论：

1. **积木已学到参考状态上的动作选择**：epoch 4 validation 动作可达率 86.1%、最短路动作率 78.9%，逐轮随机可达基线为 50.3%；epoch 2–4 的提升有限。
2. **积木闭环仍弱，增加 epoch 仅带来缓慢改善**：到达率 epoch 1→4 为 13.7%→17.6%（非零步组 5.1%→9.4%），不能由这几个 checkpoint 判定训练已饱和。epoch 3 的 1,100 个 episode 里 781 个（71.0%）以模型宣称到达结束，而这些宣称发生时目标全部已不可达；非法动作占 9.9% 的决策轮、格式错误只占 0.3%。这些现象提示需要定位自身轨迹上的首次错误，尚不能排除终止判断也有问题；参考状态上的动作准确率不能直接外推到闭环。
3. **寻路同图新目标上的闭环表现明显改善**：epoch 1→3 到达率由 60.3% 升至 79.5%。reference 可达率与逐轮随机基线同为 100.0%，该列没有区分度；应结合最短路动作率（validation 74.4%）和闭环到达判断，尚不支持跨图泛化或训练已饱和。

排序与集合指标用于进一步诊断，不决定任务主结论。地图使用需结合动作一致性和匹配消融，不能仅由高到达率或低排序分数推断：积木 epoch 3 只有 41.3% 的决策轮选中地图最优动作，但这与 84.9% 的动作可达率并不冲突——可达动作远多于地图最优动作。这类“高可达率 + 低一致性”的组合本身说明两项指标在测不同东西。

本轮同时改变任务范围、轨迹长度、重复次数与监督格式，不能把变化单独归因于数据量。旧实验见[完整轨迹历史](archive/full_trajectory_history.md)与 [swap 归档](archive/swap_training.md)，不并入当前 run。
