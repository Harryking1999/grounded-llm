# 汉诺塔 Qmap

用同一个纯 Q 范式，分别训练各盘数的状态地图。本任务独立维护 [数据](src/data.py)、[训练](src/run.py)、[模型适配](src/model.py)与[评测](src/evaluate.py)，不再使用混合 puzzle 训练入口。与其他任务共享基础 MLP、距离和排序方法，见[统一方法](../../tasks/QMAP_METHOD.md)。当前用户已采用八盘全图阶段所选地图，正式范围为[任意合法起点到指定整塔终点](configs/hanoi8_tower_evaluation.json)；完整结果见[报告](results/report.md)，加载与权重见[任务入口](../../tasks/hanoi/Qmap/README.md)。三至六盘只作历史条件。

## 规则与状态

三根柱 A/B/C；n 个盘从小到大编号。状态记录每个盘在哪根柱，输入为 3n 维独热。每根柱上的盘按大小唯一排列，因此共有 3ⁿ 个合法状态。四、五、六盘分别为 81、243、729 个状态，图直径分别为 15、31、63。

动作是六种有序柱间移动；只能移动源柱顶盘，且不能放到更小的盘上。非法动作抛出异常，批量后继中非法槽记为 −1。每次合法移动计一步。环境完整枚举状态和边，用 BFS 标注任意两状态的精确最短距离；七、八盘用 SciPy 的无权图最短路实现同一裁判，避免逐元素 Python BFS 的开销；Q 选择器不读取该距离表。

## 数据与对称性

三根柱同时重命名保持距离和动作关系。将无序状态对及其六种柱置换视为一个关系轨道，完整轨道不能跨训练／验证／测试。

四至六盘把所有合法一步关系轨道放入训练，其他关系按轨道留出。训练混合完整遍历和真距离均衡。它检验的是**已知状态、已知一步拓扑下的长程关系补全**；后继到目标的其他关系可能见过。

状态图由三个少一盘子图构成，移动最大盘的边连接它们。过桥前要先把较小盘搬到第三柱，所以不能用逐盘是否在目标柱上的差异替代最短距离。

## 配置与使用

[三盘](configs/study.json)、[四盘](configs/hanoi4.json)、[五盘](configs/hanoi5.json)、[六盘](configs/hanoi6.json)各有独立配置。三盘是较早合同，不与后续盘数作匹配泛化比较。

```bash
python -m experiments.hanoi_qmap.src.run --config experiments/hanoi_qmap/configs/hanoi4.json --out runs/hanoi_qmap/RUN_ID --source-commit COMMIT --device cuda:0
python -m experiments.puzzle_qmap.src.solve --task hanoi4 --start 0 --goal 80 --checkpoint runs/hanoi_qmap/RUN_ID/best.pt
python -m unittest discover -s experiments/hanoi_qmap/tests -v
```

去掉 checkpoint 参数运行的是精确裁判解。历史运行产物已归档，命令中的 RUN_ID 指新的运行目录；本次清理未启动新训练。

## 八盘首轮

继续采用完整关系轨道划分与六种柱置换增强；全部状态已知，留出的是关系而不是状态。训练预算随完整关系数量增加，正式参数只在合同中维护。除随机题外，最终固定报告六个标准整塔方向的完整 rollout 和循环。依赖项目环境中的 SciPy。

## 整塔求解结构的数据覆盖

首轮三个整塔终点对称地各只有 1,604/6,560 个非终止父状态获得完整候选训练，距离关系各覆盖 4,579 个状态。随机留出关系把连续求解链拆开；这说明数据中存在缺口。

[完整整塔关系合同](configs/hanoi8_tower_coverage.json)保持原全部训练关系，只将涉及任一整塔终点的**完整柱置换轨道**补入训练，从验证和测试移除这些轨道，不把已训练关系移到留出集合。于是每个整塔终点覆盖全部父状态、全部合法分叉及其所有后续，三个方向的标签曝光保持对称。其余原中间状态关系保留。通过混合采样增加整塔关系曝光，直接使用原训练器的 Huber＋原权重 soft-rank；不新增损失或监督类型。

从首轮权重与 Adam 状态续训。在新的剩余留出集合上先评估原权重，随后使用同一集合比较，选模检查全部状态到三个整塔终点的真实贪心到达，同时约束中间关系距离退化；最终仍单列六个整塔方向、随机中间关系和循环。全状态整塔检查属于训练分布内执行。

按用户进一步明确的“全状态＋绝大多数起终点对与分支转移关系”要求，[全图联合合同](configs/hanoi8_full_coverage.json)把训练关系轨道覆盖扩大到99%。保留原来已经训练的全部轨道，并将大多数原留出轨道补入同一训练池，仅保留很小的原留出子集作诊断；不会把旧已训练标签挪到验证。完整精确距离表仍为6,561×6,561。全部整塔求解分支保持闭合，其他父目标的完整合法候选也随关系覆盖大幅增加；具体覆盖比例由生成数据报告。六种共同柱置换继续对完整关系组一致作用。两个任务分别单组联合训练，损失与监督配方相同。
