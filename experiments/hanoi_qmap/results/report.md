# 四至六盘汉诺塔纯 Q 结果

四、五盘表现较好，六盘总体到达率仍高但存在明确失败；不能用总体相关性掩盖经典任务的循环。

## 固定实现与任务结构

每个盘数独立训练同一共享编码器范式，输入为每盘柱位独热，输出维数、固定对称距离和两项损失保持不变。没有把三盘模型直接用于新盘数，也没有加入新学习模块。环境完整枚举状态、合法动作及精确 BFS；最大盘位置固定时形成少一盘子图，过桥前必须先处理较小盘。

所有合法一步关系及其柱置换轨道进入训练；其他无序关系按完整轨道划分。训练混合全量遍历与距离均衡；验证和测试按真实距离分层。它检验已知状态和一步拓扑下的长程关系补全，不是未见状态、未知规则或跨盘数泛化。候选到目标的其他关系可能见过。

## 六盘的具体失败

经典全部盘 A→C 的精确解长 63 步。Q 前 60 步都沿最短路线；第 61 步在还剩三步时选择了另一个同层状态，随后在 `722 → 725 → 722` 循环，未到达目标。原始可重放轨迹位于 `D:/Grounded_llm/runs/hanoi_qmap/hanoi6/canonical_solution.json`。这是距离相关性接近一仍不能保证每个关键局部排序正确的实例，不能称六盘已可靠解决。

六盘 1,024 条分层 rollout 中，790 条全程最短；234 条有过非最短决策，首次错误中 221 条停留同层、13 条远离目标。部分能够恢复，39 条最终失败。仅三盘中可验证的 L1 精确拟合冲突不能解释这些具体误差，表示、优化和决策几何仍需分开研究。
