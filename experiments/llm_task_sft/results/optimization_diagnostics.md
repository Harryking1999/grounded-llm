# SFT 的 loss 为何初期下降快？

**前期下降快，后期仍在改善；当前不能据此断定整题解题已经收敛，也不能认定优于地图线。**
SFT 三轮训练已完成，同地图线的 510 道 test 题正在逐轮补齐。

## 1. 实际 loss 与下降速度

下表为各自保存的训练 step loss 的窗口均值。SFT 每 10 步记录，地图线每步记录；
两个目标文本和样本权重不同，绝对值不能用来排列方法优劣。

| 更新区间 | SFT loss | 地图接口 loss |
|---|---:|---:|
| 1–250 步 | 0.18105 | 0.81887 |
| 501–1,000 步 | 0.07325 | 0.75898 |
| epoch 1 最后 1,000 步 | 0.04839 | 0.26408 |
| epoch 2 最后 1,000 步 | 0.04242 | 0.25926 |
| epoch 3 最后 1,000 步 | 0.03755 | 0.24446 |

以两个早期窗口比较，SFT 下降 59.5%，地图线下降 7.3%。SFT 到 1,000 步约用 33 分钟；
前 1,000 步只占一轮的 8%。之后第二、第三轮的末尾窗口分别再下降 12.3%、11.5%，
不是完全平坦的平台。SFT 各轮完整日志均值为 0.05821、0.04531、0.03921。
三轮共 37,500 步、训练约 20.1 小时，所有已记录 loss 与梯度范数均有限。

地图最终 20 轮末尾窗口仍为 0.13576。没有采用 HF 最后一次输出的 `train_loss`：
该运行多次恢复，Trainer 会重置累计 loss 再除以全局 step，这个汇总数不代表全程均值。
这里直接从两段完整 step 日志重算，并按 step 去重。

## 2. 已核实的条件差异

| 条件 | 无地图 SFT | 地图接口 |
|---|---|---|
| 参数更新 | 1,543,714,304 个主干参数 | 冻结主干和地图；24,457,884 个接口参数 |
| 普通轨迹标签 | 精确求解器认证的最短动作 | 当前地图 Top-10＋current 排序及地图最小距离动作 |
| 普通数据扩充 | 多条不同物理路线 | 同一物理路线的编号排列增强 |
| 候选编号 | 按形状／行／列固定顺序 | 候选顺序随机化及编号增强 |
| 输出 | 固定短依据＋一个动作标记 | 排序、动作依据；终止时另输出执行总结 |
| 格式提示 | 首次输入明示完整的两行句式 | 既有构建器输入任务规则，排序格式来自示范目标 |
| 优化路径 | 直接修改已有语言网络 | 经从零初始化的门控读取地图向量，再影响冻结网络 |

**主干更新范围相差约 63 倍，是强基线的重要条件。** 地图信息没有直接变成推荐动作；
接口仍须学会把向量关系变成语言中的排序和编号选择。增加信息和采用更易优化的训练路径是两回事。

另一个已确认的早期差异是 warmup：SFT 为 1,875 步，地图线为 6,250 步；
1,000 步时两者学习率分别约 1.07e-5 和 3.20e-6。
地图门控从零开始，初始时读取分支的参数梯度被零门控压住；第二轮断点的门控绝对值均值约 0.0103。
这些条件能提供优化速度差异的机制解释，但没有通过消融分离各自贡献。

## 3. 低 loss 不等于规划收敛

实际监督 token 中，数值 token 占 13.4%；按本次物理任务平衡的 loss 位置权重，占约 11.9%。
其余主要是固定句式、标点和控制标记。这是 **token／位置权重比例，不是实测 loss 贡献比例**。

训练使用正确的历史 token：预测动作 ID 前，模型已经在训练输入中看到正确的移除格说明。
因此，动作 ID 的条件预测部分依赖前面的正确答案文本；自由生成时，这段说明也必须由模型自己生成。
平均语言建模 loss 很快下降，与模型在自身历史下稳定做对每一步不是同一个要求。

这一差别已体现在行为结果中：第一轮控制格式错误为零、独立初始已达标题停止 100/100，
但普通 validation 只完成 32/1,000；第二轮为 116/1,000，仍有 794 题最终无合法动作。
当前没有单独测验证集 NLL 或可变决策位置 loss，不凭训练 loss 宣称泛化收敛。
同一初始输入还可能对应多条同样正确的最短路线，不以训练 loss 是否趋零定义任务收敛。

## 4. 简单规则也会产生看似较高的单步分数

新增无学习对照：保护目标格，优先移除当前最大的合法形状，同大小均匀随机。
它不使用可达性标签、最短距离或地图，允许走入死局。

| 题集 | 参考单步可达率 | 整题到达期望 |
|---|---:|---:|
| validation 1,000 题：规则随机 | 64.78% | 3.505% |
| validation 1,000 题：SFT epoch 2 | 72.26% | 11.60% |
| 同题 test 510 题：规则随机 | 65.39% | 5.114% |

这说明单步分数的参照起点本来较高。SFT 第二轮超过这些简单对照，但不能由此区分
内部搜索、局部几何偏好、训练模式复用等不同解释。全部随机结果见[合法候选分析](legal_candidate_baselines.md)。

## 5. 对“基线应低于地图”的判断

地图有用是要检验的假设。当前两条线同时改变了主干是否更新、监督目标、物理路线覆盖、编号与优化路径，
并不是仅打开或关闭地图的对照。因此，地图线不会因为多了一份信息，就自动在训练早期胜出。

此前用 SFT 的 1,000 道 validation 与地图的 510 道 test 直观比较是不合适的，现已改为每轮补同一 510 题；
题目 ID、初始棋盘和目标棋盘逐项一致。单步 reference 的路线与编号仍有方法条件差异，
不把旧报告的单步均值当作完全相同状态上的因果差值。最终先对照同题整题曲线，再判断系统表现。

以上解释中，参数、标签、编号、门控和日志是已核实的事实；
它们对优势各贡献多少仍是代理判断，不能用这些相关性替代因果证据。
精确数据与来源见[优化诊断摘要](optimization_diagnostics.json)。
