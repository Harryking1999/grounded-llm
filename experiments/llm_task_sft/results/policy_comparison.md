# 同题 510：SFT 与地图策略诊断

**总分接近，成功题与实际动作明显不同；地图内容干预也改变了实际动作。大多数首次失败是合法移除造成的不可逆死局。**
本次比较地图 19.5、20 epoch 与 SFT 4、4.5、5 epoch 的保存回答，全部为同一 510 个起终棋盘。
正式合同的主比较是地图 19.5 / SFT 4.5；最新 SFT 5 作为补充，以下分步表用它与地图 19.5 比较。
物理动作回放、ID／起终状态核对及首次失败的精确裁判核验均通过。没有重新生成完整轨迹。

## 1. 总分接近，不代表相同的行为策略

| 地图 / SFT epoch | 共同到达 | 仅地图 | 仅 SFT | 均未到达 | 首个物理动作相同 |
|---|---|---|---|---|---|
| 19.5 / 4.5 | 82 | 93 | 79 | 256 | 15/507 |
| 19.5 / 5 | 85 | 90 | 86 | 249 | 13/508 |
| 20 / 5 | 91 | 81 | 80 | 258 | 16/509 |

地图 19.5 到达 175/510，SFT 5 到达 171/510，但只有 85 题共同到达；成功集合的交并比为 32.6%。
两者至少一个成功的并集为 261/510（51.2%），这是事后统计，不能当作可执行集成策略的成绩。
共同成功的 85 题中，忽略移除顺序后，只有 7 题采用同一套积木移除；差异不只是动作交换顺序。
候选局部编号已转为形状与坐标后比较；首动作分母只含两者都实际执行了合法首动作的题。
多解、编号、提示与监督差异仍可能造成不同选择，因此这些结果不能单独识别内部机制。

## 2. 失败原因：区分首次走死与末尾表现

| 首次失败原因 | 地图 19.5 | 地图 20 | SFT 4.5 | SFT 5 |
|---|---|---|---|---|
| 误删目标格 | 156 | 132 | 142 | 147 |
| 保住目标，但残余无解 | 175 | 203 | 205 | 191 |
| 仍可解时提前停止 | 3 | 3 | 2 | 1 |
| 仍可解时控制格式错误 | 1 | 0 | 0 | 0 |
| 仍可解时非法动作 | 0 | 0 | 0 | 0 |
| 首次失败合计 | 335 | 338 | 349 | 339 |
| 到达后停止错误（另计） | 3 | 25 | 0 | 0 |

SFT 5 的末尾标签是 258 题无合法动作、78 题提前停止、3 题非法动作；但只有 1 题在仍可解时提前停止，
其余提前停止和非法动作均发生于更早已走死的历史。直接把末尾标签当成致败原因会误判。
地图 19.5 同样只有 3 次提前停止和 1 次格式错误直接导致未到达，另外 331 次都是合法致命动作。

进一步检查“残余无解”：SFT 5 的 191 次中，167 次留下至少一个不再属于任何可移除形状的残余格，24 次所有格局部可覆盖却不能整体拼除；
地图 19.5 分别为 168/175 与 7/175。加上误删目标格，简单目标保护／局部支持检查能拒绝 SFT 的 314/338（92.9%）、地图的 324/331（97.9%）次合法致命动作。
这是对已有错误动作的识别覆盖率，不是加筛选器后的成功率。这些检查只用于离线诊断，不是模型已具备的能力，也没有作为新工具筛选器混入原成绩。
错误后果可如此定位，但还不能区分模型没有正确解析棋盘、没有预测移除后果，或没有利用已有判断。

第 3 轮后地图仍有 324 题可解，SFT 有 247 题，领先 77 题；到最后只多到达 4 题。
SFT 后期高单步分数来自已经留下的较小题群，不能据此认为所有题都获得稳定的后期规划。

## 4. 为什么单步均值更高，整题差距却小

- 两条 reference 轨迹不同：地图的可解状态为 3,148，SFT 的求解器最短轨迹为 3,690；88% 与 83% 不是同状态配对差值。
- 自主单步按回合加权。地图有 2,574 个可解回合、335 次首次失败；SFT 5 有 2,110 个可解回合、339 次首次失败。对应单步可达率为 87.0% 与 83.9%，但失败题数几乎相同。
- 在双方共同成功的同一 85 题上，最短长度均值为 7.29 步；地图实际 8.24 步，SFT 7.46 步。走最短解的题数为 23/85 与 72/85。

地图能保住更多早期可解题，但其成功路线也更长；较多安全回合不等于较多整题成功。
共同成功的长度对照属于条件统计，确认路线效率差异，不能单独证明额外动作造成了未到达。

## 5. 当前地图内容干预：实际动作与排序分开

地图内容反序后，19.5/20 epoch 的配对可达率分别从 81.7% 降至 48.3%／45.0%，实际动作改变 75.0%／76.7%。
每个权重的两种条件均各有 59/60 次选择自己排序中的首候选，与“地图影响排序，再跟随首项行动”的解释相容，尚未独立分离排序中介。
完整状态分层、控制条件与原始产物位置见地图实验的[内容干预结果](../../flamingo_map_reader/results/current_map_content_probe.md)。

## 6. 训练示范：地图成功路线有多少不是最短解

2026-10-13 14:41（北京时间）在平台 44491 核查当前 K/V 运行实际使用的训练 manifest。
**8,000 条普通成功示范中，4,462 条（55.78%）不是最短解。** 这些路线都能到达目标，差别是完成效率，不是动作标签不可达。

| 比真实最短解多走 | 原始轨迹数 | 占普通训练轨迹 |
|---|---:|---:|
| 0 步 | 3,538 | 44.23% |
| 1 步 | 3,644 | 45.55% |
| 2 步 | 771 | 9.64% |
| 3 步 | 47 | 0.59% |

平均示范长度为 **8.019 步**，真实最短长度为 **7.354 步**；平均多 **0.666 步**，只看非最短路线则平均多 **1.194 步**。
全部示范共 64,155 个动作，同题最短解合计 58,828 个动作，多 5,327 个（相对最短解多 **9.06%**）。
各行比例独立四舍五入，合计可能略偏离 100%。

这里一条原始路线对应一个起终状态任务，六份编号变体不算六条物理路线。
普通训练实际占 48,000 条编号样本；另有 1,000 条初始即目标和 1,000 条仅监督末尾的失败历史，共 50,000 条。
后两类不进入上述最短性分母。编号重复不改变普通路线的长短比例。

**这使监督路线效率成为值得检验的原因，但还没有确定它造成了多少整题差距。**
最短示范可能减少执行时的决策次数；是否真的提高到达率，仍需固定架构、训练范围、监督格式和预算做对照。
用户提出的数据增强方向是补充“地图贪心也能走出的最短成功路线”，保留原排序与动作标签的一致性，不以人工距离容差代替这一条件。
现成满足条件的有 3,538 条、覆盖 978/1,000 张训练棋盘；仅筛旧数据会少掉 4,462 个任务和 22 张棋盘，不能视为增加了路线覆盖。
本段审计当时只检查旧数据。后续增强数据已验收并用于新多基线，当前结论和产量见 [新实验报告](../../map_sft_baselines/results/report.md)。

核验范围：全量检查 8,000 条 manifest 的三个动作计数字段，并逐题核对其起终状态、最短长度与 SFT 独立求解后保存的认证一致。
按多走 0/1/2/3 步各抽 16 条，共 64 条缓存示范、573 个动作；合法回放、目标保留、最终到达、选择地图最优候选及六份编号缓存均通过，64 题重新精确求解也一致。
全量计数来自 manifest，原始缓存回放与重新求解是抽查，不声称对全部缓存重新审计。
紧凑计数见 [policy_comparison.json](policy_comparison.json) 的 `training_route_audit`；原始摘要和检查脚本保存在平台当前地图运行的 `diagnostics/training_route_lengths/{summary.json,audit.py}`。

## 7. 数据覆盖：编号重复与不同物理轨迹

全量读取旧地图 8,000 条普通示范缓存，并回放现有 SFT 的 49,000 条普通路线；以下不计终止样本，也不把历史文本或编号变化算成新物理状态。

| 覆盖指标 | 旧地图 | 当前 SFT |
|---|---:|---:|
| 不同形状＋坐标动作 | 664/664 | 664/664 |
| 不同当前状态—目标 | 62,230 | 292,758 |
| 不同当前状态—目标—监督动作 | 62,230 | 337,299 |
| 状态—目标有多个监督动作的数量 | 0 | 16,932 |

SFT 的不同状态—目标覆盖为旧地图的 4.70 倍。这不是完整状态空间覆盖率，也不说明旧地图没看过其他候选：它的输入包含全部合法候选，并监督候选排序。
旧地图六份编号重复后有 384,930 次普通动作监督，SFT 有 360,336 次；前者并不少，关键差别在重复程度和标签策略。

旧任务来源为每张官方棋盘的一条参考清空路线＋32 条随机合法路线，从其中前后状态组合成任务；筛最短距离至少 6 步，再从长到短保留地图贪心成功的八题。
每张来源棋盘确实都是八题，但 8,000 题只使用 2,400 个不同起点，208 张棋盘的八题共用一个起点；题长 7–8 步占 97.35%，目标剩 0–4 格占 91.55%。
原始候选有 3,282 次地图贪心失败被拒收；因此等额取棋盘不能保证难度和状态分布均衡。短状态仍在长路线后半段出现，不将起点长度分布等同于所有监督状态分布。

随机抽取同一批 128 个任务，在起点重新精确求解所有合法动作，得到 3,216 个最短解动作。旧地图动作标签覆盖 117 个（3.64%），SFT 覆盖 693 个（21.55%）；这些数只衡量样本中正确分支被选为动作标签的比例，不是单步准确率或整体覆盖率。固定策略并不必须覆盖每个正确分支。
SFT 的 7,764/8,000 题包含多套不同的积木移除组合，平均每题 4.85 套；因此新增路线大部分不只是同一套动作交换顺序。二格块在旧地图/SFT 动作中分别占 63.22%/41.76%，同时受教师与最短性影响，不能据此强行均衡所有形状。

**旧地图 64,155 个决策的地图最优候选全部唯一。** 在这些起终任务上换随机种子不会增加严格贪心路线；增加地图最优示范需要更多起终任务，不能承诺同题六条。
旧数据审计不代表新版 Q 的覆盖统计；新版数据的产量和验收范围见 [新实验报告](../../map_sft_baselines/results/report.md)。用户已决定按 SFT 覆盖目标加强数据，保留全部 1,000 张来源棋盘；优先选长轨迹，同长度下先增加状态覆盖，覆盖相同时兼顾起点与目标大小多样性，不设强制分层配额。所有新组统一使用更好的 Q，有地图输出 R＋排序＋A、无地图输出 R＋A。主实验为 B0–B4，覆盖对照 B5–B7 仅作补充；设计见[多基线方案](../../map_sft_baselines/DESIGN.md)。

精确统计见 JSON 的 `training_coverage_audit`。原始摘要、128 题逐题覆盖及检查脚本在平台当前地图运行 `diagnostics/training_coverage/{summary.json,root_sample.json,audit.py}`；本次只作 CPU 诊断，未制作新训练集或训练模型。
