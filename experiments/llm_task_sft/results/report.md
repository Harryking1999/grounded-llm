# 无地图任务 SFT：已验收结果与诊断

本报告保留旧独立 SFT 的事实记录。其多路线数据、物理任务权重与当前统一 token CE 的新实验不同，不能把两者当作同一运行。新实验见 [map_sft_baselines](../../map_sft_baselines/README.md)。旧运行每半轮监测固定 510 题；历史 1,000 题仅用于早期诊断。

## 1. 结果与 loss

|---|---:|---:|
| 1 | 18/510（3.53%） | 0.04839 |
| 2 | 60/510（11.76%） | 0.04242 |

这是截至既有验收记录的完整结果，不冒充最新运行状态。当前运行状态仅维护在 [项目状态页](../../../docs/PROJECT_STATUS_AND_TODO.md)，原始动态曲线保留远端 `continuation/curve.json`。

## 2. 验收结论

- 固定 50,000 条样本与 9,000 个物理任务配额通过；每个完整评测点、每模式均为同一 510 个 ID，无漏题或重复。
- 原训练与续训 14 项检查通过；累计六个评测点 252 分片、384 个裁判回合抽查通过，动作回放、停止、到达与汇总一致。
- 保存完整模型、Adam、scheduler 与四卡 RNG；日志 loss、梯度、学习率有限。具体边界和计数保留在 [acceptance.json](acceptance.json)。

## 3. 为什么 loss 快降，任务表现却会平台

- 第一轮早期 loss 从 0.18105 降至 0.07325；3.5–4.5 末尾 loss 又下降 7.49%，但到达率在约 32% 波动。
- 大量监督 token 是固定依据、标点和控制格式。训练预测动作前还能看到正确的移除格说明，自由生成时这些也须自行生成。
- SFT 更新约 15.4 亿主干参数；旧地图只更新约 2,446 万接口参数。动作教师、warmup、编号和监督目标也不同，不能从绝对 loss 判断谁更会规划。
- 旧 SFT 采用物理任务加权的轨迹 token 均值；新多基线统一采用全体有效 assistant token 的标准 CE，两类 loss 不直接拼接。

窗口、参数及分布原始计数见 [optimization_diagnostics.json](optimization_diagnostics.json)。

## 4. 合法候选与简单策略的参照

在同一 510 题上，保护目标格并优先移除最大合法块、同大小均匀随机的策略：参考单步保持可达约 65.39%，整题到达期望 5.114%。它不用求解器选动作或地图，仍可能走死。

历史 1,000 题的合法随机整题期望为 0.371%，保护目标后随机为 2.369%，保护目标＋大块优先为 3.505%；这些属于不同题集，不作为当前 510 题成绩。分子、分母和精确随机期望保留在 [legal_candidate_baselines.json](legal_candidate_baselines.json)，计算入口见 [README](../README.md)。
