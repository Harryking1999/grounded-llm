# 过桥Qmap：带权完整目标

五人多目标地图在首批开发题上表现可用，但全员左岸起点仍有验证缺口，尚未登记采用权重。完整人员分布和手电位置作为目标，环境提供真实后继；排序分数为即时过桥耗时加预测剩余时间，没有搜索或候选过滤。

| 条件 | 完成 | 最优成本完成 | 成功题平均超额时间 |
|---|---:|---:|---:|
| 熟悉耗时场景的留出关系 | 127/128 | 121/128 | 0.14 |
| 熟悉场景的留出完整目标 | 128/128 | 128/128 | 0 |
| 未训练耗时组合 | 125/128 | 119/128 | 0.16 |
| 未训练耗时组合，全员左岸起点 | 119/128 | 91/128 | 0.60 |

对应全员左岸起点的验证组仅99/128完成，低于80%基本要求；其他较高分组不能替代这一缺口。每组精确最优策略均100%最优完成。中间目标可直接停止已由裁判检查，但这不是LLM已学会停止的证据。

数据、预算和选择规则见[配置](../../configs/bridge/bridge_multigoal_fit.json)，距离、可达性、循环与教师路径诊断见[结果](multigoal_fit.json)。这是小规模开发结果；题目已用于观察，不作为后续独立最终验收。不同耗时比例、新人数和LLM读取尚未形成验收结论。

下一步保留原耗时场景、目标和起点题，追加训练场景以检查覆盖不足。扩展[配置](../../configs/bridge/bridge_multigoal_coverage.json)在原train/validation/test全部生成之后才追加训练场景，原有验证和测试场景不移入训练。
