# 过桥Qmap：带权完整目标

五人多目标地图在开发条件下取得进展，各组完成超过80%，尚未进行独立最终验收或登记采用权重。完整人员分布和手电位置作为目标，环境提供真实后继；排序分数为即时过桥耗时加预测剩余时间，没有搜索或候选过滤。

| 条件 | 完成 | 最优成本完成 | 成功题平均超额时间 |
|---|---:|---:|---:|
| 熟悉耗时场景的留出关系 | 127/128 | 121/128 | 0.14 |
| 熟悉场景的留出完整目标 | 128/128 | 128/128 | 0 |
| 未训练耗时组合 | 125/128 | 119/128 | 0.16 |
| 未训练耗时组合，全员左岸起点 | 119/128 | 91/128 | 0.60 |

首批对应全员左岸起点的验证组仅99/128完成。随后追加训练场景，保留原验证与测试场景、目标和起点题，并从首批所选权重开始新的优化阶段。同一原始题集重评中，该验证组提高到114/128；测试原始起点由119/128变为120/128，最优完成由91/128提高到106/128；新耗时组合由125/128变为126/128，最优完成由119/128提高到125/128。验证改善较明确，测试完整完成只多1题，不能把两者混为同一收益。

每组精确最优策略均100%最优完成。中间目标可直接停止已由裁判检查，但这不是LLM已学会停止的证据。

数据、预算和选择规则见[首批配置](../../configs/bridge/bridge_multigoal_fit.json)和[覆盖配置](../../configs/bridge/bridge_multigoal_coverage.json)，结果见[首批](multigoal_fit.json)和[固定题重评](multigoal_coverage.json)。这是小规模开发结果；题目已用于观察，不作为后续独立最终验收。不同耗时比例、新人数和LLM读取尚未形成验收结论。

下一步独立训练[六人地图](../../configs/bridge/bridge6_multigoal_fit.json)，并检查五人地图的耗时比例、全员右岸与中间目标分项。人数变化需要新的地图，不能视为五人地图直接泛化。
