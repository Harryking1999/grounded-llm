# 过桥Qmap：带权完整目标

五人多目标地图已通过限定范围的独立验收并登记采用；六人地图的成本最优性仍未通过门槛。完整人员分布和手电位置作为目标，环境提供真实后继；排序分数为即时过桥耗时加预测剩余时间，没有搜索或候选过滤。

| 条件 | 完成 | 最优成本完成 | 成功题平均超额时间 |
|---|---:|---:|---:|
| 熟悉耗时场景的留出关系 | 127/128 | 121/128 | 0.14 |
| 熟悉场景的留出完整目标 | 128/128 | 128/128 | 0 |
| 未训练耗时组合 | 125/128 | 119/128 | 0.16 |
| 未训练耗时组合，全员左岸起点 | 119/128 | 91/128 | 0.60 |

首批对应全员左岸起点的验证组仅99/128完成。随后追加训练场景，保留原验证与测试场景、目标和起点题，并从首批所选权重开始新的优化阶段。同一原始题集重评中，该验证组提高到114/128；测试原始起点由119/128变为120/128，最优完成由91/128提高到106/128；新耗时组合由125/128变为126/128，最优完成由119/128提高到125/128。验证改善较明确，测试完整完成只多1题，不能把两者混为同一收益。

每组精确最优策略均100%最优完成。中间目标可直接停止已由裁判检查，但这不是LLM已学会停止的证据。

数据、预算和选择规则见[首批配置](../../configs/bridge/bridge_multigoal_fit.json)和[覆盖配置](../../configs/bridge/bridge_multigoal_coverage.json)，结果见[首批](multigoal_fit.json)和[固定题重评](multigoal_coverage.json)。这是小规模开发结果；题目已用于观察，不作为后续独立最终验收。不同耗时比例、新人数和LLM读取尚未形成验收结论。

独立训练的[六人地图](../../configs/bridge/bridge6_multigoal_fit.json)在新耗时组合完成123/128，最优完成115/128；原始起点完成120/128，最优完成93/128。人数变化使用新地图，不能视为五人地图直接泛化，见[结果](bridge6_multigoal_fit.json)。

按目标类型枚举全部原始起点题，五人全员右岸测试8/8完成、7/8最优；六人7/8完成、6/8最优。其余完整中间目标分别141/152和142/152完成。按最快／最慢耗时比例分层，测试中较高比例组的五人完成62/64、六人75/80，距离MAE除以最慢耗时约0.093和0.076。分项来自冻结模型，未重新选权重；场景数仍小，不解释为范围外尺度泛化，见[目标与耗时分项](goal_and_time_profiles.json)。

## 冻结后的独立验收

在模型冻结后，按已提交的[验收配置](../../configs/bridge/bridge_frozen_acceptance.json)为每张地图另取128个耗时场景，排除该地图原训练、验证和开发测试的全部208个组合。各必需组要求完整完成率与最优成本完成率均至少80%；完成目标为90%。没有用此题集重新选权重。

| 地图与目标 | 完成 | 最优成本完成 |
|---|---:|---:|
| 五人，全员过桥 | 119/128 | 103/128 |
| 五人，原起点到完整中间目标 | 125/128 | 114/128 |
| 五人，中间起点到完整目标 | 126/128 | 118/128 |
| 六人，全员过桥 | 120/128 | 86/128 |
| 六人，原起点到完整中间目标 | 115/128 | 92/128 |
| 六人，中间起点到完整目标 | 114/128 | 103/128 |

每组精确最优策略均100%最优完成。五人通过三组门槛，最优成本最弱组仅103/128，结论限于已测分布；六人两组成本最优率未通过，不登记采用。结果见[独立验收](frozen_acceptance.json)，采用权重及输入、人数范围只维护在[selection](../../../../tasks/bridge/Qmap/selection.json)。LLM读取与学会停止尚未评测。

六人的后续拟合比较扩大常规耗时组合覆盖，并检验成本随全部耗时同比缩放的结构。[原始编码控制](../../configs/bridge/bridge6_scale_control.json)与[耗时齐次编码](../../configs/bridge/bridge6_scale_homogeneous.json)共用无偏置ReLU及线性输出模型；后者将人员岸位置乘以各自耗时、手电岸乘以最大耗时，因此仍完整编码原始状态，且所有耗时乘以正数k时地图坐标和读出成本也乘以k。该性质只约束尺度，不保证最短路正确。两组从头匹配训练；与旧带偏置sigmoid地图的差别另列，不把其历史成绩当作该编码的因果控制。已用精确图、模型和实际MapReader检查缩放及旧权重兼容，采用权重保持原范围。

该比较的[新独立验收](../../configs/bridge/bridge6_scale_frozen_acceptance.json)在两组既定预算完成后，仅按既定验证分数冻结一个候选；新题排除训练、开发和历史六人冻结题的全部耗时组合。验收输入沿用被冻结权重的编码，完成率和成本门槛不变。失败不触发在同一独立题集上换另一张地图重新选择。
