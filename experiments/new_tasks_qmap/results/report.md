# 新任务 Qmap 首轮可行性

三个任务已建立独立环境、数据、裁判、任务文字与配置。当前没有正式采用权重，也没有LLM接入结果。

## 规则与表示的结论

- 手电过桥是带权可逆状态图，成本须包含本次过桥耗时。经典四人例的精确最优值为17；不能用最少动作次数替代最短时间。
- 推箱子的合法动作可能不可逆、可能进入死锁。目标是全部箱子到位的状态集合，玩家位置不限。首轮使用小棋盘完整枚举与多源最短路，不把它报告成标准Boxoban成绩。
- 24点采用XoT题目与两数合并规则，用精确分数修正浮点判等。每个可解状态的最短距离都等于剩余数个数减1；固定目标距离主要检验可解性，而非丰富的状态间几何。

## 证据范围

规则测试覆盖加权最优解、转移可逆性、合法推箱死路、重复数字、除零、分数解及24点距离退化；三个任务均完成小型端到端训练检查。完整配置的数据另以精确oracle验证所有评测起点。

训练结果待运行后填入。参数只维护在[配置](../configs/)，模型是否采用只维护在各任务selection。有限的不可达代理标签不等于精确无穷距离；本轮只监督既定目标，不足以证明任意状态关系或跨任务迁移。
