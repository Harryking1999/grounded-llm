# 推箱子 Qmap：覆盖、执行与泛化

**当前尚无通过验收的地图。主条件改为每套固定墙体分别训练Qmap。** 同墙体内保留不同箱子、玩家、终局与普通完整中间目标，验收留出关系、目标及原题起点；不要求这张地图泛化到另一墙体。先使用[902](../../configs/sokoban/sokoban_fixed_wall_902.json)与[327](../../configs/sokoban/sokoban_fixed_wall_327.json)两套独立地图，采用[固定墙体验收](../../configs/sokoban/sokoban_fixed_wall_acceptance.json)，首批完成结果仍未通过，见下文固定墙体拟合。以下原共享地图结果保留：扩大布局覆盖改善短题，长题和训练图自主执行仍弱，完整图训练未充分拟合。

范围为Boxoban hard、10×10四箱，每题指定箱子与玩家的完整目标，环境提供全部合法后继，地图按预测距离逐步贪心。规则与划分见[任务数据](../../../../tasks/sokoban/data/README.md)，验收见[配置](../../configs/exact_pair_acceptance.json)，采用状态见[selection](../../../../tasks/sokoban/Qmap/selection.json)。本页按研究问题组织已有结果；参数、逐题轨迹和逐节点统计由链接来源维护。

在小规模精确物理图中加入普通箱子布局和玩家位置目标，逐目标重算有向距离。保持模型、损失、初始化、完整候选和更新预算，比较原关系采样与25%距离监督替换为真实动作边。熟悉关系完成从7/62变为11/62；留出普通目标均9/128，新布局均7/128，原始起点均0/47。小图多目标执行仍弱，动作边没有带来目标或布局泛化收益，不能据此扩棋盘。

配置见[原关系](../../configs/sokoban/sokoban_multigoal_control.json)与[动作边](../../configs/sokoban/sokoban_multigoal_edges.json)，教师路径、循环和首次不可达位置保存在原始运行，紧凑结果见[比较](sokoban_multigoal_pairs.json)。

复用现有有限距离／死锁边界采样器，保证换目标后仍有明确可达关系配额后，无动作边／动作边分别完成熟悉关系7/62与14/62、留出目标10/128与14/128、新布局11/128与9/128，原始起点仍均0/47。可达配额和动作边仍未形成可靠执行，见[配置](../../configs/sokoban/sokoban_multigoal_finite_control.json)、[动作边配置](../../configs/sokoban/sokoban_multigoal_finite_edges.json)及[结果](sokoban_multigoal_finite_pairs.json)。下一步检查小图内真正曝光的目标关系和首次循环；暂不混入更大棋盘。

## 布局覆盖与连续路径采样

64张与1,000张训练棋盘采用相同模型和更新预算，使用同一批100张未见测试棋盘的1,024题。以下为单个种子。

| 真实最短距离 | 64张组完成 | 1,000张组完成 |
|---|---:|---:|
| 1–5步 | 301/437 | 360/437 |
| 6–20步 | 5/275 | 28/275 |
| 21步及以上 | 0/312 | 0/312 |
| 全部 | 306/1024（29.88%） | 388/1024（37.89%） |

扩大覆盖的收益主要来自短题。1,000张组在4,096个训练布局诊断题中也只完成1,359题，其余全部出现两步往返；失败不仅发生于新布局。排序关系实际曝光比例约从81%降至21%，证据：[覆盖对照](sokoban_coverage_comparison.json)、[训练执行诊断](sokoban_training_failures.json)。

后续对照共用固定验证题，每组1,024题。各对照内部匹配起始权重、模型、损失和预算。

| 对照 | 熟悉布局新关系 | 未见目标 | 未见布局 |
|---|---:|---:|---:|
| 相邻独立采样 → 同批成组 | 23.93%→26.66% | 14.16%→15.43% | 36.13%→35.35% |
| 完整路径：原采样 | 24.02% | 14.75% | 36.52% |

21步以上均未成功。相邻对照还改变了近目标与可达点监督占比；完整路径后两组匹配关系与次数，只改变同批组织。成组未显示未见布局收益。见[相邻验证](sokoban_neighborhood_validation.json)、[路径验证](sokoban_local_path_validation.json)、[路径数据](sokoban_local_paths_data.json)。

关系覆盖与多轮训练在30万步停止，保留完整断点，未达到原预算或降学习率阶段。20万步同题未见布局完成32.71%，低于起始36.52%；训练区间loss下降，固定训练关系误差和泛化没有共同改善。配置及运行来源见[实验入口](../../README.md#推箱子覆盖量对照)。

旧原生评测偏向短题，与这里固定距离区间不同；历史[64张](sokoban_coverage64_native.json)与[1,000张](sokoban_coverage1000_native.json)记录保留。

## 固定混合分布的收敛检查

20%混合组两种子从完整优化、随机与采样状态接续，在固定分布下完成既定96k节点；不与重建优化器的早期阶段混称同一次恢复。条件见[配置](../../configs/sokoban/sokoban_mixture_convergence.json)。

| 指标（种子1；2） | 6k | 96k |
|---|---:|---:|
| 验证中间目标全跨度排序 | 70.36%；69.41% | 68.53%；68.13% |
| 验证相差一步排序 | 54.89%；54.79% | 54.10%；54.13% |
| 验证中间目标完成 /512 | 73；70 | 71；68 |
| 验证原终局完成 /512 | 128；117 | 103；105 |
| 训练图内1–32步起点完成 /489,392 | 8,007；7,912 | 13,013；10,615 |

训练内有进展，但96k完整执行仍仅2.66%、2.17%。验证全跨度和一步排序的布局配对平均差分别为−1.70、−0.79个百分点，95%区间分别为[−2.67, −0.73]、[−1.30, −0.29]；中间目标完成差区间跨零。原128布局动作正确率为73.54%、73.56%，未出现纯小图训练的明显整体遗忘。

保存的验证最佳权重也已补评。中间目标峰值79/512、74/512，整体排序、教师路径与连续执行未共同改善；较早最佳权重在训练图上也只完成约2%。这些是反复查看的开发验证峰值。

主要执行问题是错误的局部远近关系和不稳定的完整动作链。96k有限图循环均为两步往返，绝大多数并非浮点打平；约9.9万个起点没有预测更低的合法后继。当前第一步最优的起点约36.2万，但所有真实最优分支后续都持续正确的仅11,644、9,678个。训练减少了死锁，却常把失败转成行走循环。

图点关系实际见过约97.7%，排序决策约60.5%，最低曝光仍为零；48k至96k还有拟合变化。原始结果、节点、布局区间、保护边界和轨迹见[收敛结果](sokoban_mixture_convergence.json)；延长配置仍是未运行候选。

失败回放仅使用允许的训练关系，保留全部合法动作，保护留出关系及候选闭包。多次查看的验证／测试题用于开发与回归，最终泛化需独立留出验收。数据准备、实现检查与环境真值不记作地图能力提升。所有结构化结果、配置和恢复产物沿用原位置；研究优先级只维护在[项目状态](../../../../docs/PROJECT_STATUS_AND_TODO.md)。

## 固定墙体内的训练拟合

两张独立地图的首批预算已完成。902图所选节点在2,048个允许训练关系中完成1,011题、循环1,037题；327图完成1,025题、循环1,023题。留出关系分别4/16、3/16完成，留出目标9/94、4/96；原题起点到训练目标均未完成。各组合法候选和精确标签均保留，原始起点可解查询没有被无解题稀释。所选训练点源已遍历仍不等于被重采后的全部关系持续正确。

这些结果说明固定墙体尚未解决神经地图的局部关系与连续执行，不能把失败全部归因于跨墙泛化。327图留出目标MAE约47.6步，而熟悉关系约1.6步；其留出普通箱子排列未作为训练查询目标，目标变化与训练内拟合分别存在缺口。完整分项、距离层、首次循环／不可达诊断和目标箱子曝光见[固定墙体基线](sokoban_fixed_wall_baseline.json)。

后续在同一902图使用较宽MLP，从头匹配比较[有向最大差](../../configs/sokoban/sokoban_fixed_wall_902_max_fit.json)与[有向正差求和](../../configs/sokoban/sokoban_fixed_wall_902_sum_fit.json)。两者都保留方向性，只改变已有固定距离读出及其梯度分配，不添加教师坐标或过滤动作。该对照检查拟合／优化条件，不把读出改变直接解释为表达能力，也不因单步正确率高就宣称连续求解通过。

## 原始棋盘编码、局部边与空间对照

固定墙体902和327的精确物理图分别包含91,000／123,760条自由走动边、13,650／17,920条推箱边。自由走动边全部一步可逆，推箱边均不能直接用一步反向动作撤销，但可能经其他路线返回，不能把“没有一步逆边”等同永久不可逆。图分别有4,159／5,629个强连通分量，原起点所在分量仅2／3个状态；推箱在小片可逆走动区域之间形成有向连接，箱子和玩家位置必须共同编码。精确最短逐格距离还包含绕到推箱位置的行走成本，不能仅按箱子排列合并玩家位置。

训练失败诊断中，首次错误分别972/1,066与984/1,070发生在走路上，闭合循环的动作全部为走路；因此失败并不只在推箱是否合法。902原题最优46步，模型先正确推进，随后在真实剩余39步时选择40步后继而非38步后继：预测值分别约41.000与41.057，微小排序反转即触发往返。327原题最优32步，第一次正确推箱后就把应剩30步的后继排在32步后继之后。完整状态、候选与误差见[编码对照和结构诊断](sokoban_fixed_wall_encoder_comparison.json)。

同一预算、数据、目标保护和有向最大差下，[原四通道CNN](../../configs/sokoban/sokoban_fixed_wall_902_cnn_fit.json)参数量与宽MLP相差约0.44%。训练批次MAE由MLP约1.441步降至CNN约0.836步，最优动作率由94.84%升至97.22%；但留出目标两者均只完成7/94，原起点到训练目标分别1/17、0/17。CNN改善局部拟合，未解决多目标完整执行，不采用，也不能将当前失败全部归于MLP空间偏置。

教师参照用训练目标的精确距离作坐标，两张图训练查询均2,048/2,048最优完成，留出目标却仅1/94、0/96；加入全部查询目标坐标则全部最优完成。这只证明小目标域的可表示性和训练目标距离坐标的泛化缺口，不提供神经地图能力或任意目标已学会的证据。当前目标仍是独立状态表示支持广泛状态对的自然转移与距离；原棋盘输入不添加预计算可达区域或推箱位置。

## 扩大同墙体内的查询目标覆盖

在原墙体、四通道原始输入和有向距离下，训练目标从20个扩为532个，覆盖487种箱子排列。原始物理图、全部原留出目标、验证／测试的父状态、候选、标签和最优动作数组保持逐元素一致；新增目标不采用留出目标的箱子排列。新增的是目标条件下的精确关系监督，不是编码器输入特征。准备统计见[目标覆盖](sokoban_goal_coverage_structure.json)。

[MLP](../../configs/sokoban/sokoban_fixed_wall_902_goal_coverage_mlp.json)与[CNN](../../configs/sokoban/sokoban_fixed_wall_902_goal_coverage_cnn.json)在新域从头匹配训练。广域点池按物理源状态遍历，并在线重新抽目标，完整有限排序关系仍保留；覆盖计数不再重复计算同一源因不同目标产生的准备行，也不声称全部状态对已曝光。两组仍使用原始输入、损失和固定距离读出，不加入可达区域、推箱位置或目标距离坐标。新域与较早小目标条件还改变训练分布及预算，不能将其差异直接归于单一因素。

两组均完成8,000次更新。相同94道留出目标中，MLP完成20道、CNN完成17道；原17道起点到训练目标查询两组均0/17。固定旧2,048道允许训练查询分别完成782和815道；新增目标后的原题查询池分别8/198、5/198完成，不能将198题与原17题混为同一组。MLP／CNN实际训练批次MAE约1.373／1.495步，21步以上约3.228／3.563步，最优动作率90.72%／89.61%。全体42,840个状态作为损失输入出现过，仍不等于所有状态对已经学会。分项和原题重放见[目标覆盖对照](sokoban_goal_coverage_comparison.json)。

本次匹配试验未显示CNN的整体执行收益，推箱子保留MLP作为主编码器，CNN权重及负结果保留，不追加预算。两组均未通过验收；MLP从6,000到8,000步的训练MAE和验证目标仍在下降，不能宣称优化已收敛。[MLP续训](../../configs/sokoban/sokoban_fixed_wall_902_goal_coverage_mlp_continue.json)保持输入、模型、采样和损失，恢复完整状态继续检查拟合及长程执行；后续成绩与本节8,000步编码对照分开报告。

完整实际采样记录核查显示，MLP的747,780个允许排序关系均出现，最少3次；原起点到198个可解训练目标也全部出现，最少11次。点查询关系覆盖约88.83%，全部允许直接走动边90,974条和推箱边13,649条均出现。该证据排除了“这些允许排序关系从未采到”的解释，仍不等于已经拟合。原固定2,048道查询按真实距离1–5／6–20／21以上分别完成391/409、367/819、24/820，失败集中在长程，MLP的1,266个循环均为两步返回。

按当前箱子与查询目标箱子位置的重合数分层，同一固定训练查询在0/4、1/4、2/4、3/4、4/4时分别完成5/301、83/665、227/523、349/441、118/118；这些阶段与距离相关，不能把边际差异解释成单一原因。箱子布局到达数与完整玩家／箱子目标到达数在这组轨迹相同，失败并非主要来自最后玩家站位。原棋盘目标格上的训练目标阶段分布为159、253、100、8、12个，3/4目标稀少；原起点到原终局目标仍0/12。精确最优分支中存在先减少已匹配箱子数的动作，阶段用于采样与诊断，不强制单调增加，也不作为编码器附加输入。

[控制](../../configs/sokoban/sokoban_fixed_wall_902_control_transition_fit.json)、[阶段分层](../../configs/sokoban/sokoban_fixed_wall_902_stages_transition_fit.json)与[转移差值](../../configs/sokoban/sokoban_fixed_wall_902_transitions_transition_fit.json)保持532个目标和原始MLP。后两者交叉平衡目标本身阶段、当前相对目标匹配数及距离；转移条件另监督同目标下父／后继的有限剩余成本差，合法绕路可以使距离增大。该项增加关系损失，须单列与原两损失比较，不能以实现接通宣称长程循环已解决。原无分层预算续训保留为候选，未同时启动。
