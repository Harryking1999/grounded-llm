# 推箱子 Qmap：循环、不可逆推动与目标迁移

**无采用地图，正在针对训练区循环与死锁继续优化。** 接续固定墙体宽MLP的完整断点，保留原关系和目标覆盖；箱子布局、玩家位置与完整查询目标仍变化。早期多墙体共享地图的结果单独列于历史对照。

## 结果应怎样判断

每走一格或推一格计一步。完整目标要求四个无编号箱子和玩家都到指定位置，既包含原终局，也包含箱子未全就位的中间状态。原目标格标记只是棋盘输入，查询目标由另一完整状态给出。

| 固定墙体902，较宽MLP的检查 | 完成 | 结论 |
|---|---:|---|
| 全部允许训练决策出发的连续执行 | 238,976/747,780（31.96%） | 训练区本身未学好 |
| 其中21步以上 | 49,679/328,054（15.14%） | 长程明显不足 |
| 原题起点→训练目标 | 44/198（22.22%） | 原起点执行仍弱 |
| 留出完整中间目标 | 22/94（23.40%） | 目标泛化未通过 |

以上各行对应独立检查集合，完成率均低于基本要求。

## 数据、输入与求解结构

输入是4张10×10二值图：墙、原棋盘目标格、箱子、玩家，共400维；没有加入玩家可达区域、可推位置或死锁答案。环境提供全部合法走／推后继，模型学习有向剩余距离和候选排序。

精确物理图对不同完整目标重新计算有向距离及不可达关系。数据包含动作边、完整候选、教师路径、训练循环／死锁分支，并按箱子0/4至4/4在原目标格就位分层检查。该“就位数”不是必须单调增加的价值函数，先移开箱子也可能必要；合法动作还可能使目标永久不可达。

原宽MLP在全部747,780道允许训练决策中完成238,976道；431,276道陷入仍可解的循环，77,528道进入不可达区域。47,883个两步循环分叉均为玩家走动，39,033个分叉的全部最优出口为走动，7,252个分叉的全部最优出口为推箱。沿精确最优边检查，玩家走动的预测剩余成本下降误差均值为0.58步，推动为1.15步；两类动作都存在方向或幅度拟合不足。

针对性补训池保留57,708个循环／死锁分叉及8,806个正确后续分叉，每个分叉包含父状态与全部合法候选。2000批真实池采样核对中，每个关键分叉最少抽到3次、后续分叉最少7次。补训使用可完整恢复的独立采样流，同时保留原广域、关系遍历和阶段分层。正式参数见[接续配置](../../configs/sokoban/sokoban_fixed_wall_902_width_wide4.json)，完整计数见转移拟合结果的`current_policy_structure`。

## 改变判断的关键比较

- 固定墙体、扩大目标覆盖的相同94道留出目标题：MLP完成20题，CNN完成17题；CNN未显示优势，因此保留MLP。
- 只用训练目标的精确距离作坐标，两图训练查询可100%最优完成，但留出中间目标仅1/94、0/96。该项使用教师距离坐标作诊断。
- 动作边、完整分支、转移差值和关系遍历改善过部分训练拟合，拓宽后仍只有上述31.96%训练完成。
- 早期1000墙体共享条件在未见布局完成388/1024（37.89%），21步以上0/312；增加布局没有解决长程。它不属于当前固定墙体地图的采用结果。

规则、精确教师图、数据与失败样本保留；模型采用与LLM读取验收继续按对应题集检查。
