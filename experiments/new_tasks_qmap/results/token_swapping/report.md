# 棋子交换 Qmap：近距离改善与长程循环

原固定10顶点树的L1地图已通过完整完成率验收并采用；最优交换率和残余循环继续单列。历史方案仍对应原固定10顶点树，全部3,628,800种排列可计算精确距离；另一棵同规模树的独立L1地图也已通过完整完成率验收，早期弱地图结果保留。规则与数据见[任务数据](../../../../tasks/token_swapping/data/README.md)，验收见[总报告](../report.md)。

**棋子交换：近距离能力提高了，但长轨迹仍会循环。** 从原基线约27%–30%提高到约68%–69%，说明采样和动作排序有用。单独继续加大排序权重反而变差。上一方案在随机1–5步题上已约96%完成，但长题执行中仍会遇到反复往返的位置；最新方案三个主要测试组仍分别有330、325、319题循环；两端未见组只有20.90%的题达到最少交换次数。证据：[原基线](token_pairs_baseline.json)、[排序权重对照](token_pairs_local_rank8.json)、[近距离评测](token_pairs_near_validation.json)、[执行轨迹检查](token_pairs_policy_boundaries.json)。

较好方案在三个各1,024题的测试组中，分别完成694题（67.77%）、未见起点699题（68.26%）、两端未见705题（68.85%）；已知困难题2/5。详细结果见[当前较好方案](token_pairs_local_walk8_rank4.json)。

地图还没有可靠地产生一条通向目标的下降路径。后续判断应继续以整题完成为准，同时看循环、死锁和路径是否最优。精确拟合所有距离与可靠求解分别检验；[表示能力检查](token_pairs_linf_witness.json)保留具体构造。

上述历史方案各主要组未达到至少80%的要求；当前采用身份见[selection](../../../../tasks/token_swapping/Qmap/selection.json)。

## 精确距离层、两步环与另一棵树

目标可通过精确距离表中的相对排列直接分层生成，再用排列重标记得到同一起点的不同目标；这些变换只用于教师采样，不进入模型输入。实测约18–19更新/秒，随机游走拒绝采样约2.2–2.3更新/秒。吞吐改善不等于地图质量改善。

从原较好权重开始、完整覆盖原状态对采样源、保留诊断关系排除的长程检查中，同一128题开发组的完整完成下降：熟悉关系88→71，未见起点83→74，两端未见96→69；已知题2/5→1/5。该阶段使用精确距离层和训练两步环回放，不能把变化归因于其中单一因素，也没有依据替换原较好地图。距离／排序验证选出的权重并不保证自主完成保持。

另一棵10顶点树独立训练的开发图完成熟悉关系56/128、未见起点56/128、两端未见52/128，仍有大量循环；所选节点未完整曝光所有准备点关系，不能作为验收通过或接入LLM。弱初始化的原树条件也未通过。随机游走对照按原固定预算继续，运行状态见runtime。

配置见[原图较好权重长程检查](../../configs/token_swapping/token_swapping_best_long_coverage.json)与[新树精确层条件](../../configs/token_swapping/token_swapping_alternate_tree_exact_layers.json)，完整结果及同题初始参照见[开发比较](token_multigoal_long_development.json)。下一步定位已曝光关系中的首次两步环和选模指标与完整执行的分歧，先解决原树，再考虑LLM读取新图。

循环分支数据复用同一精确教师与完整候选评测。冻结较好地图，在训练允许的长程起终点中挖掘实际循环，保留循环两端及相同起点下最优交换集合不同的目标。匹配比较使用相同根关系：控制组回放根关系，分支组补全部合法后继、两层邻域及每条初始分支的精确下降后续。回边仍按真实最短距离标注，不能一律视为错误。

原端点和关系留出继续生效；遇到保护边界就停止该后续的监督扩展，记录中断，保留已接受父节点的全部合法候选。数据不宣称形成全图闭包。原广域距离样本保持不变，两组另加相同数量的局部距离样本；实际回放关系曝光单独计数。数据准备见[配置](../../configs/token_swapping/token_cycle_branches_data.json)，匹配[根关系控制](../../configs/token_swapping/token_cycle_seed_control.json)和[完整分支条件](../../configs/token_swapping/token_cycle_branch_training.json)先检查训练区误差、分支排序与连续完成，未通过不能称为收敛或直接扩大训练。

该端点条件实际挖掘到1,460个两步循环题；2,920个循环端关系与460个改变最优动作集合的换目标关系，经保护边界筛选后留下1,006个根关系，扩展为8,064个分支关系。9,054条教师后续中只有20条走到目标，9,034条因原端点／关系留出中断。该结果说明随机端点划分严重切碎了可监督路径，不能把分支数量当作完整路径覆盖。

因此另设[查询目标留出拟合条件](../../configs/token_swapping/token_query_reference.json)：物理状态输入可全部曝光，训练只查询固定完整目标池，验证／测试另外保留完整查询目标和关系闭包。固定目标池优先检验连续分支能否拟合；它不能支持任意目标能力或未见状态能力结论。匹配[根关系控制](../../configs/token_swapping/token_query_seed_training.json)与[完整分支训练](../../configs/token_swapping/token_query_branches_training.json)独立记录训练区距离、最优动作、完成、循环及教师后续是否到达。原端点留出结果继续保留，不能混用两种成绩。

匹配对照已完成；下表是各条件按验证距离／排序选模后的开发测试，每格128题，与历史1,024题验收不混用。完整误差、最优率和循环数见[结果](token_cycle_branches_comparison.json)。

八目标分支模型的留出关系MAE为0.654步，最少交换完成117/128；未见目标MAE为4.568步，循环91/128。控制组在已训练目标上也全完成，不能把此改善归因于扩分支。训练目标池过窄与原端点条件是不同问题，大batch也未使该条件通过全部拟合门槛。

八目标条件还暴露出第二个路径覆盖问题：19,264条教师后续全部被留出关系截断。把临近目标的验证关系及其全部候选闭包留出，会保护目标到自身的零距离关系，从而阻断最后一步的完整候选训练。[128目标条件](../../configs/token_swapping/token_query128_reference.json)保留远距离关系作熟悉目标验证，且所有评测闭包避开训练目标一步邻域的完整候选关系；未见完整目标仍单列。修正后38,546条教师后续有38,507条到达目标（99.90%），另39条碰到留出边界；保留366,224个完整分支决策和1,858,279条局部距离关系，没有裁剪物理候选。

128目标分支模型的熟悉目标测试完成84/128、MAE1.402步，新目标完成88/128、MAE1.299步。所选3,000步节点已曝光全部分支决策与局部距离关系，分别平均回放8.39和6.61次；运行至6,000步，训练区误差和循环仍未通过拟合门槛。八目标与128目标还改变了关系留出距离和终点邻域约束，不能只按目标数量解释两者百分比差异。数据后续被截断已大幅减少，但反复曝光仍不保证神经地图学会，不能继续只以增加数据量解释失败。

[根关系拟合控制](../../configs/token_swapping/token_query128_seed_focused.json)与[完整分支拟合](../../configs/token_swapping/token_query128_branches_focused.json)从同一个已完成的分支阶段末权重重新初始化优化器和采样，保留全部广域点样本，提高局部点与分支排序占比，检查训练池本身能否拟合。两组只改变回放池种类；这一短阶段是训练区诊断，不代表原优化器连续恢复或独立验收。

同一4,096个训练长题在原参考权重下有1,359题循环，在分支拟合阶段末权重下有1,783题循环。后者的2,838个不同循环决策关系中，2,600个不在原局部分支池，238个在池内。这是有向的完整状态—目标关系覆盖统计，不是单状态输入是否见过，也不意味着这些关系从未被广域随机采样。静态旧策略分支池无法代表新策略访问分布，局部重复曝光与整题改善需分别检查。

[固定池控制](../../configs/token_swapping/token_query128_fixed_training.json)与[当前策略反馈聚合](../../configs/token_swapping/token_query128_feedback_training.json)从相同末权重开始，只比较回放池是否加入新策略的失败分支；聚合保留原来的全部根关系，并重新计算完整候选及教师后续。两组使用同一个原分支池作共同拟合诊断，独立验证集继续负责选模，不使用测试失败构造回放。

聚合池包含9,393个根关系和777,720个完整分支决策。共同原分支池的训练诊断在阶段末完成100/128，固定池控制为91/128；聚合模型MAE仍为1.162步、最优动作率90.63%，未通过拟合门槛。这是训练池结果，不能当作独立测试改善。

隐藏宽度[四倍](../../configs/token_swapping/token_query128_feedback_wide4.json)与[八倍](../../configs/token_swapping/token_query128_feedback_wide8.json)复用同一反馈池、初始窄网络权重和采样预算。复制隐藏单元、拆分出边权重，并用出边组内和为零的扰动打破复制单元的训练对称性；加载后核对初始地图坐标偏差。输入及128维地图读出保持一致。该对照同时改变网络容量与优化条件，不能把潜在收益仅归因于表示容量，也不能由拓宽本身宣称收敛。

两种宽度均完成既定更新。验证所选节点在熟悉目标测试完成88/128和85/128，未见目标均99/128；阶段末共同分支训练池分别完成107/128和100/128，MAE约1.149和1.131步，最优动作率约89.84%和90.04%。加宽没有通过训练池拟合门槛，见[同题结果](token_cycle_branches_comparison.json)。

[坐标监督对照](../../configs/token_swapping/token_query128_anchor_supervised.json)进一步检验距离标签虽已充分曝光、但只有最大差值坐标接收距离梯度时的拟合问题。每个坐标用到一个固定训练目标的精确距离作辅助Huber监督，与[零权重控制](../../configs/token_swapping/token_query128_anchor_control.json)匹配初始化、输入、完整分支回放和更新预算。保护关系的两个方向、全部评测候选闭包以及留出输入行均屏蔽辅助梯度。该条件增加了密集教师监督，不能归入原两损失方案或声称监督预算相同；读图仍仅独立编码原始排列，推理不加载距离表。先看训练池拟合，再分别检验新查询目标和原端点条件。

精确坐标诊断表明，即使这128个坐标完全等于教师距离，熟悉目标128/128最优完成，新查询目标也只完成33/128，MAE3.539步、循环95题。该诊断使用精确标签而非神经编码器，不能记为地图能力；它说明固定128个参照目标的距离坐标不足以保证新目标执行，不能把坐标监督当作任意目标的已证解决方案，见[诊断](token_cycle_branches_comparison.json)。

从头训练的匹配比较已完成：零权重控制与坐标监督在熟悉目标测试分别完成119/128、123/128，新查询目标66/128、70/128；新目标MAE仍为3.782和3.696步。阶段末共同分支训练池分别完成123/128、125/128，MAE0.441和0.557步，仍各有5题、3题循环，均未通过全部拟合门槛。全部点源已曝光，不等于全部候选关系已曝光或任意目标已学会。新初始化和固定目标条件的训练拟合明显优于旧权重接续阶段，但辅助坐标标签没有解决目标泛化，不能采用该图。

[原端点条件的Linf控制](../../configs/token_swapping/token_endpoint_linf_fit.json)与[L1读出](../../configs/token_swapping/token_endpoint_l1_fit.json)使用相同原始输入和从头初始化的较宽MLP，完整保留原端点／关系保护及循环分支。该比较检查固定读出及其梯度分配，而不引入教师坐标；任意允许训练目标继续采样，原未见起点和两端未见组分别评测。读出改变也会改变梯度和数值条件，不把收益直接等同于表示容量。

## 另一棵树的独立地图

新树使用相同排列编码和精确教师接口，重新计算该树的距离与合法交换，独立挖掘自身训练策略的循环分支；没有搬用原树距离标签或分支池。所选节点通过全部准备点源覆盖，末次共同分支拟合达到种子127/128、分支128/128完成，MAE约0.415、0.384步。该训练池诊断不替代独立验收。

[新树冻结验收](../../configs/token_swapping/token_alternate_frozen_acceptance.json)保持原端点保护、三个1024题组及长题子集门槛。按验证分数冻结后，原保护关系回归、新查询未见起点、新查询两端未见均完成1,011/1,024，各循环13题；最优完成分别690、739、732题。两个新查询组21步以上均完成199/204。所有留出输入曝光为零，精确参照100%最优完成。

另把原五对已知起终点排列作为新树诊断，按新树重算距离与动作，完成5/5、最优4/5；这组仅为已知排列迁移的诊断，不声称独立端点留出。实际MapReader对三个组各前128题和全部五题复核，共389题、5,444个物理动作与评测器一致，禁止调用搜索且动作全部重放。证据见[新树结果](token_alternate_acceptance.json)，采用身份及绑定边集仅见[selection](../../../../tasks/token_swapping/Qmap/selection.json)。新树通过完整完成率要求，但最优完成约67%–72%，残余循环仍在；尚未验证原LLM读取这张新地图。

## 最优交换效率

完成率通过不代表交换次数最优。保留两张采用地图，分别开展[原树](../../configs/token_swapping/token_endpoint_efficiency_acceptance.json)和[新树](../../configs/token_swapping/token_alternate_efficiency_acceptance.json)的效率对照：从各自采用节点的相同权重开始，匹配比较软距离排序与仅精确最优后继的排序目标，保留原排列输入、L1距离、完整训练分支及端点保护。新的冻结查询排除旧准备和旧验收状态对，每组完成、最优完成、成功题成本比及21步以上子集分别检查；成功题平均效率不能掩盖循环与未完成。该阶段尚不修改采用记录，原LLM读取新树地图仍未评测。
