# 寻路：统一的状态 Q 网络

目标是沿用积木、汉诺塔和魔方的训练范式，让状态向量通过距离和动作关系自行形成地图。

本目录就是当前采用的统一方法寻路 Q 实现，不回退旧 Q/V。文字、数据和选定权重入口见[任务工作区](../../tasks/path/README.md)。

四个任务共用 `StateEncoder`：两层隐藏 MLP、ReLU、固定维 Q 输出及 sigmoid 范围约束；只训练 Q。寻路输入为节点编号的 one-hot，输入层适配节点数，隐藏层与输出宽度保持一致。这里是同一结构的任务模型，不是四个任务共享一套已训练权重。

监督统一为平均 Huber 距离损失加软距离目标的候选排序交叉熵，排序函数共用同一实现。输入编码、采样和固定距离规则由任务配置明确指定；积木的有向距离、汉诺塔的对称 L1 和魔方的 L∞ 并未被宣称为相同几何。寻路首个对照使用积木的有向求和规则，并对两个方向都监督；不会假定任意图都能被它精确表示。

离线 BFS 提供标签，冻结求解只比较合法后继 Q 与目标 Q 的距离。主评测保留全部合法邻居，允许返回并检测循环。验证／测试题的起点与全部候选到目标的关系均从两项监督排除；节点仍在训练中出现。检查距离误差、最短动作率和完整到达率，不据此声称可泛化到新图。

- 正式参数：[path256.json](configs/path256.json)。图来源为配置指定的既有冻结 suite；不改写历史寻路产物。
- 训练：`python -m experiments.path_qmap.src.run --config experiments/path_qmap/configs/path256.json --out runs/path_qmap/<run> --source-commit <commit>`。
- 冻结接口：`FrozenPathMap.load(checkpoint)`；`path_q_step` 返回现有 `GraphStep/MapBatch`。
- 积木、寻路、汉诺塔、魔方统一提供 `[batch, 当前／目标／合法后继槽位, Q维数]`，经相同的投影和 cross-attention 读取。汉诺塔／魔方使用 `puzzle_q_batch`。同维数不等于不同模型的坐标语义已对齐；读取能力仍需训练验收。

新方法训练已完成：留出测试完整到达 251/256（98.05%），最佳权重按验证目标选择，见[结果报告](results/report.md)。原始日志、数据与完整权重仍在 Git 外；全图到达率不作为独立测试。
