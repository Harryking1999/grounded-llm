# 数字华容道 Qmap

假设：与目标无关的状态向量 Q，经过完整复原距离与多目标关系监督，可以支持以复原为最终目标的贪心动作选择，并补全未监督的中间目标关系。距离拟合好并不保证完整复原；完整 rollout 和循环率是主要检查。

按既有 Qmap 模板使用共享两层 MLP、对称距离、距离 Huber 和全部合法候选的软排序，只训练 Q。任务独立维护环境、数据、模型适配、训练和评测，不使用汉诺塔或魔方的训练器或权重。正式参数只在 [配置](configs/puzzle8.json) 中维护。

## 完整覆盖与中间状态关系

当前按用户明确要求升级为全状态、绝大多数起终点对及分叉转移关系的**单组联合训练**，不再占用另一张GPU做覆盖对照。早期少量固定中间目标的条件保留用于解释历史结果。

枚举从标准复原状态可达的整个状态图。每个状态到复原终点的精确距离全部进入训练；还对训练合同指定的中间目标构造全状态精确 BFS 距离与候选排序。这覆盖全部状态，但不等于构造所有状态对的距离表。输入是棋盘每个位置的数字独热，目标不进入编码器；关系由两个 Q 向量的固定距离表达。

验证和测试各自留出中间目标。训练仍见过这些状态及其到其他目标的关系，因此评测的是已知状态上的目标关系补全，不是未见状态泛化。对称距离会把 (s,g) 与 (g,s) 视作同一关系：留出评测移除训练目标端点及其邻接状态，确保评测的父节点和候选到目标关系均未在训练中以反向对出现。精确表仅供标签与裁判，Q 选择动作不访问距离表。

## 检查、选择与使用

主要指标是标准复原 rollout 的完整到达率、循环率、解长额外步数；复原目标覆盖全状态，所以这是训练分布内的执行检查。另报留出中间目标的距离 MAE、最优后继率、排序和 rollout。基线是同候选集上的 Hamming 距离和精确裁判；Hamming 是弱基线，不能替代后续 LLM 对照。合法动作由环境枚举，零非法率不是模型学会规则的证据。

完整遍历与真距离均衡混合采样；至少完整覆盖一次训练距离和决策后，按验证距离 Huber 加排序交叉熵选择权重。测试仅在训练完成后评估，不参与选择。保存完整训练数据、精确目标距离表、最佳与最终断点，以及紧凑汇总；产物进入 Git 忽略路径。

```bash
python -m experiments.puzzle8_qmap.src.run --config experiments/puzzle8_qmap/configs/puzzle8.json --out runs/puzzle8_qmap/RUN_ID --source-commit COMMIT --device cuda:0
python -m unittest discover -s experiments/puzzle8_qmap/tests -v
```

启动与结果记录见 [本轮记录](results/report.md)。尚无已验证和采用的本任务权重。

## 数据层面的地图修复

所有任务继续使用统一的距离 Huber＋候选软排序损失；本任务数据实验直接调用原 `run.py` 的同一损失计算，不新增 margin、progress、辅助头或标签。此前 `96c41a3` 曾改变损失，用户已否决该方向；其源码在 Git 历史、运行与产物在远端保留，仅作偏离方法约束的记录，不作为候选模型或数据方案证据。

原数据含全部状态到复原与多个固定中间目标的距离，但全图 241,920 条无向一步边中，仅 61 条直接进入原距离样本（0.025%）。标准终点占原始关系数量的 4%。这些是数据分布事实，不单独证明失败原因。

参考积木的路径／分支关系包、魔方的实际循环与出口数据，本轮补入训练许可的一步、两步邻域距离和朝两步中间目标的完整候选排序。所有局部标签可由真实图精确判定；原验证／测试目标及反向等价标签被保护。另以原标签增加复原全状态、当前循环与正确出口及邻居的抽样。候选动作仍全部由原环境给出，Q 推理仍为原贪心。

[数据实验](configs/local_graph_data.json)与[原数据续训对照](configs/continuation_control.json)从同一原基线断点出发，匹配模型、Adam、学习率、损失及其权重、更新数、batch 和模型选择；唯一差异是抽取哪些真实关系样本。两者复用原划分。实际抽样计数和完整策略图在日志记录，保留原断点作为选择候选。

验收要求见正式合同：报告全状态复原、所有循环、旧成功丢失、原同题结果及留出中间目标；达到训练分布内高可靠复原，且关系质量保持，才讨论采用。部分改善必须继续称为部分改善，不能把训练侧完整枚举称为独立泛化。

## 分叉与后续关系覆盖

短程局部数据试验提高了复原，但明显损害中间目标距离。用户随后明确要求加强起终点组合、求解结构和转移覆盖，因此下一组数据采用 [branch_data.py](src/branch_data.py)：从真实复原分叉的后续轨迹选取新中间终点，构造全状态到这些终点的精确距离。关系池以索引隐式存储，不复制巨量父节点和四候选数组；可用关系数与实际抽样遍数分别报告。

对每个目标，选取不同真距离层的父状态，包含所有合法第一步分支，再沿**所有最优后继**递归补到终点。在这些后续父状态仍保留全部合法候选及其精确距离，包含回头与绕路。兄弟分支到同一中间终点的关系也由精确图标注；本任务可逆，不照搬积木的不可达标签。另补全训练许可的一步边距离，保留原中间目标与全状态复原数据。

[扩展覆盖对照](configs/branch_coverage_control.json)和[分叉后续重放](configs/branch_routes.json)使用相同新目标、关系池、原始断点、模型与优化设置；后者只调整抽样，将部分新增关系曝光分给完整分叉及后续关系。根据当前复原策略的真实错误补入完整分叉和最优后续，原多目标结构包持续保留。验证和测试目标的正反关系均排除；少量因此中断的训练闭合会明确计数。全部训练仍直接使用原 `run.py` 的 Huber＋原权重 soft-rank，不增加监督类型或损失。

## 全起终点对与全分叉联合训练

[完整数据合同](configs/full_pair_data.json)用真实状态图精确构造 181,440×181,440 的距离矩阵，共32,920,473,600个有序起终点对，int8存储约32.9GB。每个父状态对任意目标的全部合法后继标签都从同一矩阵取得；不再限于几十个训练终点。数据仅供监督与裁判，冻结Q推理不读取该矩阵。

[联合训练合同](configs/full_graph_joint.json)合并原关系、全图起终点对、全部一步边、完整分叉、不同尺度后续关系、跨分支终点和当前复原错误。对**所有父状态**展开每个合法第一步，沿真实复原路径选取多尺度后续状态，标注分支之间的精确远近，再对这些决策递归补齐所有最优后继直到终点。每个决策均保留全部合法候选，不把可逆分支误标为不可达。原8个留出目标的相关新关系被保护，除这极小边界外可训练几乎全部起终点组合。

巨量关系用可遍历的整数置换流抽样，无需在内存中复制数百亿索引或候选数组。记录可用关系总数、实际曝光、不同起终点数和结构包遍数；完整真距离表不等于网络已拟合全部距离，是否可用仍以完整求解、中间目标和残留循环验收。监督仍为原 Huber＋原权重 soft-rank，没有新增损失或动作标签。
