# 数字华容道 Qmap

假设：与目标无关的状态向量 Q，经过完整复原距离与多目标关系监督，可以支持以复原为最终目标的贪心动作选择，并补全未监督的中间目标关系。距离拟合好并不保证完整复原；完整 rollout 和循环率是主要检查。

按既有 Qmap 模板使用共享两层 MLP、对称距离、距离 Huber 和全部合法候选的软排序，只训练 Q。任务独立维护环境、数据、模型适配、训练和评测，不使用汉诺塔或魔方的训练器或权重。正式参数只在 [配置](configs/puzzle8.json) 中维护。

## 完整覆盖与中间状态关系

枚举从标准复原状态可达的整个状态图。每个状态到复原终点的精确距离全部进入训练；还对训练合同指定的中间目标构造全状态精确 BFS 距离与候选排序。这覆盖全部状态，但不等于构造所有状态对的距离表。输入是棋盘每个位置的数字独热，目标不进入编码器；关系由两个 Q 向量的固定距离表达。

验证和测试各自留出中间目标。训练仍见过这些状态及其到其他目标的关系，因此评测的是已知状态上的目标关系补全，不是未见状态泛化。对称距离会把 (s,g) 与 (g,s) 视作同一关系：留出评测移除训练目标端点及其邻接状态，确保评测的父节点和候选到目标关系均未在训练中以反向对出现。精确表仅供标签与裁判，Q 选择动作不访问距离表。

## 检查、选择与使用

主要指标是标准复原 rollout 的完整到达率、循环率、解长额外步数；复原目标覆盖全状态，所以这是训练分布内的执行检查。另报留出中间目标的距离 MAE、最优后继率、排序和 rollout。基线是同候选集上的 Hamming 距离和精确裁判；Hamming 是弱基线，不能替代后续 LLM 对照。合法动作由环境枚举，零非法率不是模型学会规则的证据。

完整遍历与真距离均衡混合采样；至少完整覆盖一次训练距离和决策后，按验证距离 Huber 加排序交叉熵选择权重。测试仅在训练完成后评估，不参与选择。保存完整训练数据、精确目标距离表、最佳与最终断点，以及紧凑汇总；产物进入 Git 忽略路径。

## 针对循环的首轮续训

用户要求参考积木和魔方经验针对性解决循环。完整策略审计发现原图有 7,525 个两状态循环，所有周期节点均属于这种循环；全状态在原预算内复原 49,403/181,439，原 1024 题仍为 305 成功。循环存在可由真实规则给出的最短出口，当前 Q 将错误邻居排在出口前。

修复沿用原 Q、距离几何和 Adam 状态，见 [cycle_repair.py](src/cycle_repair.py) 与正式[合同](configs/cycle_repair.json)。借鉴积木的明确目标监督和魔方的独立归一化：复原与中间关系各自计算损失，避免唯一复原目标被大量中间目标稀释。保留原中间关系数据及验证／测试划分；根据当前复原策略的错误和实际循环挖掘父节点，加入真实最短出口后续，并回放起始正确决策。新增出口排序间隔与父节点到出口的下降间隔，训练对象仍是原 Q，无新策略头。

推理保持原贪心，不加入禁回头、访问记忆或精确裁判。审计在训练侧缓存全状态 Q，解析整个确定性策略图，区分真正循环与预算耗尽。它检查全部已训练复原状态，不是独立泛化证据。模型选择计入此前成功状态的丢失，并限制中间目标验证 MAE 恶化；这是有限实测选择条件，不是全局不退化保证。测试目标只在最终评测使用，不据其调参。保留零步原模型作为候选；首轮是有界修复，不自动追加网格或后续轮次。
