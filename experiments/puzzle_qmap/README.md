# 汉诺塔与魔方 Qmap：先读这一页

我们要训练一个**与目标无关的状态编码器**，把状态变成向量 Q(s)。求解时，用向量距离比较所有合法后继与目标，选择最近的后继。

**目前的结论：汉诺塔四、五盘表现较好，六盘仍有循环；魔方还没有学成可靠的长程地图。**补全绝对距离与错题重放未改善留出求解，已归档。当前只保留纯 Q 基线、必要结果和可复核的结构反例。

## Q 究竟是什么

这里的 Q 是状态向量，不是通常强化学习中的动作价值表 Q(s,a)。

```text
状态 ──独热编码──共享 MLP── Q(s)，128 维
                              │
合法后继 Q(s₁)…Q(sₖ) ──与 Q(目标) 比距离── 选择距离最小的动作
```

同一个网络编码当前状态、目标和候选。目标不进入编码器；环境负责执行动作和枚举合法后继。

| 部分 | 现在的实现 | 与积木的关系 |
|---|---|---|
| 编码器 | 两层 ReLU MLP，输出 cap × sigmoid；cap 为任务图直径 | 直接复用 BoardEncoder，只适配输入维数 |
| 距离 | D(s,g) = Σᵢ\|Qᵢ(s)−Qᵢ(g)\| / (2√128) | 对积木的有向距离取双向平均，适应可逆动作 |
| 距离监督 | D(s,g) 拟合精确最短步数，使用 Huber | 沿用积木的距离拟合 |
| 排序监督 | 对全部合法后继，比较 softmax(−真实距离/T) 与 softmax(−预测距离/T) | 沿用完整软目标；候选来自任务环境 |
| 求解 | 每轮选择预测距离最小的合法后继；重复状态判循环 | 只读取冻结 Q |

当前总损失只有“距离 Huber + 排序交叉熵”，权重与温度见各任务配置。没有学习到的转移头或策略头。精确距离表只用于训练标签和评测裁判，纯 Q 求解不读取它。

## 数据怎么来

- **汉诺塔：**完整枚举状态和合法动作，用 BFS 求任意两状态最短距离。同时重命名三根柱子是正确对称变换；关系及其对称副本必须在同一划分。四至六盘把全部一步关系放入训练，其他关系留出。因此检验的是已知状态与一步规则下的关系补全。
- **魔方：**当前使用三个面的顺、逆 90°，共六个动作。完整 BFS 标注真实步数；每个训练单元包含两步内的 34 个不同状态，对起点及其六个后继分别监督完整六候选。根任务按真距离分层、层内无放回遍历，每次为整组状态和目标重新共同左乘，增加不同绝对布局。
- **留出边界：**魔方训练的全部输入避开保护的评测父状态和目标；测试候选和 rollout 中间状态不保证全部未见。相对任务类型已被训练覆盖，不能声称未知任务类型泛化。

## 为什么会循环，现有证据说明了什么

对固定目标，正确地图应让至少一个真实最优后继更近，并让它领先错误后继。对称距离本身不保证这个条件。预测距离会形成错误的局部低谷；求解器离开低谷后，下一步又被吸引回来，于是往返。

魔方训练的总 loss 下降主要来自绝对距离拟合，候选排序没有相应学好。替换为动作距离差监督、再尝试增加进展边距，都没有解决全局循环。单目标小样本可以拟合成功，但它同时减少了目标数和样本量，**还不能据此确定是多目标干扰、网络容量还是优化问题**。具体证据集中在[魔方结果](../cube2_qmap/results/report.md)。

“分开训练再合并”保留为待验证想法，尚未启动。即使各模型局部成功，它们的向量坐标也不一定对齐，直接平均参数没有正确性保证。在决定合并前，需要用固定数据量、改变目标数的小实验区分这些影响。

任务有递归结构不代表 MLP 已学会分解与组合。汉诺塔的小盘子图及过桥条件是真实递归结构；魔方的两步动作组合只约束局部拓扑，不能直接给出面向远目标的方向。“局部好”目前主要指剩一、两步的魔方任务；中程一步排序仍差。最新数据修复改善了一部分困难训练题，却损伤其他关系，详见[报告](../cube2_qmap/results/report.md)。

另已验证：魔方的一个四点转面环加远目标，违反 L1 必须满足的五点不等式。因此当前度量无法在任何维数中精确拟合全部距离；这不等于正确动作排序不可能。一个值得单独检验的最小修改是 L1 求和改为 L∞ 最大绝对差，编码器及两项损失保持不变。五点构造证明该距离可容纳此反例，128 维网络的全空间表现仍未知，尚未实现或训练该条件。
