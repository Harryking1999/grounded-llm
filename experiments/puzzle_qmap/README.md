# 可逆任务的共享 Qmap 核心

本目录只共享汉诺塔与 2×2×2 魔方已经需要的数据、编码、训练和评测流程。任务规则与精确求解留在 [hanoi_qmap](../hanoi_qmap/README.md)、[cube2_qmap](../cube2_qmap/README.md)，不复制积木实验的专属数据结构或启动系统。

## 因果假设与模型

假设：离线精确距离加同一目标下的候选排序，能让目标无关状态编码器 `Q(s)` 的固定距离反映最短动作远近，进而改善一步选择和连续到达。状态输入是符号真值，合法后继由环境提供；这一实验不检验视觉解析、状态估计或 LLM。

沿用积木的 `状态 → 共享 MLP → Q` 与精确状态对监督。两个新环境均可逆，因此取 `D(s,g)=mean(abs(Q(s)-Q(g)))`，它对称、非负且满足三角不等式；不沿用积木因单向移除而需要的有向距离。它是**学习到的动作距离近似**，不是物理位置距离，也不能保证任意图在固定维度中无误差表示。

总损失由三项组成：状态对距离 Huber；合法后继的多正确答案排序损失（把全部最短后继的概率相加）；独立动作条件头 `T(Q(s),a)` 对真实后继 Q 的预测误差。后继目标停止梯度，转移误差按直径平方归一化。没有 V、策略头、目标条件编码器或学习距离头。动作头只用于转移诊断，Q 贪心直接读取真实候选 Q；不能把这两项能力混称为自主转移或规划。

## 模块接口

| 模块 | 职责 |
|---|---|
| `src/tasks.py` | 延迟加载任务；不依赖 torch |
| 每个任务的 `src/environment.py` | 状态编号／验证、文字说明、动作执行、合法后继、特征、Hamming 基线、精确距离和最短解 |
| `src/data.py` | 固定划分、精确标注、候选排序与转移样本；不导入 torch |
| `src/model.py` | `QMap.encode`、固定距离、独立转移头；`MapReader` 冻结读取接口 |
| `src/run.py` | 构建数据、训练、验证选模型、冻结评测与向量导出 |
| `src/evaluate.py` | 距离、候选、转移、连续到达；oracle 仅为标签或独立基线 |
| `src/solve.py` | 输出可重放动作与状态序列，支持精确解或纯 Q 贪心 |

向量接口读取 checkpoint 中的完整配置并核对任务／动作约定：

```python
from experiments.hanoi_qmap.src.environment import Hanoi
from experiments.puzzle_qmap.src.model import MapReader
reader = MapReader(Hanoi(), "runs/hanoi_qmap/RUN_ID/best.pt")
q = reader.encode([0, 26])       # [2, state_dim]，目标不进入编码器
action, successor = reader.choose(0, 26)
```

## 比较与证据边界

同题比较随机初始化 Q、训练后 Q、原始状态 Hamming、精确最短距离。距离报告 MAE、Spearman 与按真实步数分桶的预测均值。一步选择报告固定动作顺序打破平局的最短动作率、均匀打破平局的期望正确率与严格候选排序准确率。转移报告后继 Q 误差、合法候选内后继检索率及“不预测动作、保持当前 Q”的参照；它不是所有状态中检索的准确率。

连续到达使用同一批任务、相同且不依赖 oracle 的固定最大步数；重复状态判为确定性贪心循环并停机。报告成功率、循环率、超预算数、成功题额外步数和按初始真距离分层的成功率。合法候选由环境枚举，非法动作率结构性为零，不能解释为模型学会了合法性。oracle 的 100% 到达是环境／标签检查，不是学习结果。全部状态在各自环境中互相可达，因此不伪造“不可达状态对”负标签；非法状态和非法动作单独测试。

汉诺塔按无序状态对留出，双向距离不跨划分；排序与转移训练也只读取训练状态对。其留出父状态—目标任务的候选—目标关系可能见过，这只是关系补全。魔方按完整状态空间的稳定哈希分出训练／验证／测试，训练距离、排序候选和转移两端全部排除留出状态；测试父状态和目标均未参与训练损失。魔方距离均衡采样不代表均匀随机打乱分布，两个任务的指标不可混算。

## 产物与执行

从仓库根目录运行各任务 README 的命令。运行目录必须不存在；所有生成物写入 Git 外的 `runs/`。每次保存实际 `config.json`、`data.npz`、划分摘要、验证曲线、最佳 checkpoint、初始与最终评测 `summary.json`、示例 `q_vectors.npz`；魔方还保存完整精确距离表。模型只按验证距离误差和一步选择的固定组合选取，测试不参与选择。单 seed 首轮只证明流程与该训练条件的表现，不宣称最优超参或统计稳健性。

依赖：环境与数据只需 NumPy；学习和冻结 Q 推理另需 PyTorch。不修改仓库通用依赖或公共环境。
