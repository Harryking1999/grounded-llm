# 纯文字基线：模型、设置与预算对照

当前结果入口。所有 ACC 均为**整题真实执行到达目标的成功率**，不是单步正确率或最优解率。

新增 [DeepSeek 积木／魔方各 100 道新题的 64k 复测](../configs/deepseek_blocks_cube100_64k.json)尚不完整，部分结果单列于第 3 节，不并入已完成组。魔方深度权重有变化，不作旧题配对比较。

- **8k／16k**：思考与最终答案合计不超过 8,000／16,000 输出 token；超限计错。
- **原执行**：保存答卷的实际动作判分，不追加预算扣分；不表示无限生成预算。
- 所有下表条件均一次输出完整计划，无工具、无中途反馈。“逐步状态”是在同一份答案中附上每步棋盘。
- 第 1、2 节各组已完成，服务失败均已补齐；正常错误、截断和超限未重抽。第 3 节另列未完成的 64k 新题组。

## 4. 目前能说明什么

**DeepSeek 初始五任务同题评测（2026-10-18）：**[正式合同](../configs/deepseek_flash_same40_16k.json)逐字复制初始 200 题与参考解，积木为原八形状、12 次构造、仅动作输出。官方文档将 Flash 标为 V4.1-Flash-1017，在线 `/models` 确认为 V4.1 Flash；旧 V4 Flash 已转接，R1 未列为可用模型。本轮请求 `deepseek-flash` high，全部最终响应回显该别名与 high；回显本身没有独立提供日期版本号，因此版本日期来自官方文档，不冒充原 V4 或 R1 的实测。

200 题均完成，16k 整题到达与严格合同通过数相同，为 **101/200（50.5%）**；53 次服务失败已补齐，正常错误与截断未重抽。99 题失败中，97 题耗尽预算截断（积木 8、汉诺塔 23、魔方 35、华容道 31），另有积木、寻路各 1 题非法动作。不能将大量未生成完整答案的预算失败直接解释为某项内部状态能力缺失。

本轮从生成时请求思考＋答案共 16,000 token，全部最终响应有用量，最高恰为 16,000，无超发；8k 仅为附加重算。各任务平均输出 token 为积木 12,002、寻路 3,702、汉诺塔 13,652、魔方 14,066、华容道 13,617。200 份最终答卷已独立重放，执行与预算判分一致。答卷、进度和复核摘要保留在 Git 外 `runs/deepseek_flash_same40_16k/`。对照组部分使用更高请求上限后重算为 16k，故本表不构成完全匹配的生成预算或计算量比较。

- 原八形状上，5.6 加逐步状态后，16k ACC 从 92.5% 到 90.0%，8k ACC 从 92.5% 到 67.5%。合法前缀棋盘正确率为 446/469（95.1%）。
- 5.6 的 S/Z 组原执行为 90.0%，16k 下为 75.0%，8k 下为 15.0%。31/40 份输出超过 8k，7/40 超过 16k；预算内完整棋盘正确 360/360，全部答卷的合法前缀为 432/444（97.3%）。严格合同在 16k 下通过 30/40。
- 5.6 的 S/Z 组有 3 题对可解棋盘返回空计划并误报 `no_solution`；另 1 题未清空却报完成，该题同时超出 16k。40 份最终答卷已重放，判分一致。
- 6.1 的同题 S/Z 组原执行、16k 内到达与严格合同均为 40/40；8k 下为 37/40，另 3 题实际解出但超过 8k（06、12、34）。逐步状态正确 481/481（100%），无超 16k 或用量缺失；两次服务失败已补齐，40 份最终答卷重放一致。

## 5. 比较边界与来源

8k／16k 是对保存答卷的评分重算，不等于在对应请求上限下重新生成。初始 6.1、32B 原请求为 32k；5.6 五任务混用 32k／16k；S/Z 四组及原八形状逐步状态组均请求 16k。第三方接口仍可能超发，已按实际回传用量扣分。GPT 的 high 为请求档位，多数答卷未回显强度；S/Z 四组各 40 份均未回显模型名或档位，不能独立验证后台身份与强度；Qwen thinking 也不等同于 high。

同题的原八形状“有／无状态”对照仍有请求上限差异；原八形状与 S/Z 的形状对照同时改变目录与棋盘分布，6.1／5.6 的 S/Z 模型对照则完全同题；历史 medium 与新 high 还改变了强度和提示词。以上差值均不能单独证明某一种失败机制，也不与训练后的地图／7B SFT 成绩混算。

正式合同与原始答卷目录见[实验入口](../README.md)。此目录只保留本表；逐题答卷、自动汇总和已停止的加难记录位于 Git 忽略的 `runs/`，可用现有报告工具重建。历史 medium 的来源见[原实验报告](../../sol_dag_blocks/results/report.md)。
