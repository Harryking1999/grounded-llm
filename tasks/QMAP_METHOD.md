# Qmap：共享方法与任务外壳

目标是让独立于查询目标的状态编码Q(s)，通过距离和完整候选排序形成可读取的状态关系。**任务、小类与当前可用性只在[任务总览](README.md)汇总；模型身份、参数及范围由各任务selection链接正式配置。** 本页说明方法与实现，不维护实验时间线。

## 共享接口与职责

| 层次 | 共享部分 | 任务负责的部分 |
|---|---|---|
| 环境 | 返回真实状态、合法动作及真实后继 | 规则、状态验证、动作成本与终止条件 |
| Q编码器 | [StateEncoder](../grounded_llm/core/qmap/model.py)及基础MLP | 原始状态特征、输入宽度与配置指定的结构 |
| 关系学习 | 固定距离读出、距离Huber及候选排序基础组件 | 精确标签、可达性、采样、留出及监督变体 |
| 地图槽位 | [state_q](../grounded_llm/core/reader/state_q.py)、[MapBatch](../grounded_llm/core/reader/memory.py) | 当前、完整目标、全部合法后继的对应关系 |
| LLM读取 | 共用投影与cross-attention | 任务文字、动作解析和停止答案 |

源、目标和后继分别编码，Q(s)本身不读取查询目标。布局、人员耗时等决定物理规则的上下文属于状态输入；目标通过独立目标槽位给出。环境提供后继的条件下，地图贪心成绩是距离读取和动作选择证据，不证明网络会自行生成动作条件转移。

各任务独立编排训练和评测，公共实现不导入任务或实验。参数及采用身份不在本页复制；编码器结构、距离几何、监督变体与数据范围不能笼统描述为所有任务完全一样。

## Qmap要表达的关系

| 关系 | 数据构造 | 验证 |
|---|---|---|
| 自身与一步邻接 | 自身对、真实动作边与精确成本 | 零距离、一步成本误差 |
| 近中远层次 | 多源多目标、按精确距离分层 | 分桶误差、距离顺序 |
| 目标切换 | 同一起点配最优动作会变化的完整目标 | 首步是否按目标改变、两题能否完整完成 |
| 分支与连续执行 | 每个父状态的全部合法后继、替代最优分支、回退及绕路 | 完成、最优成本、首次错误、循环、死锁 |
| 可达与不可达 | 精确可达对、死锁、不同连通分量、同层异状态 | 可达召回及两类误判 |
| 范围扩展 | 新关系、新目标、新布局、新图新地图 | 分开验收，不把一种留出当作另一种泛化 |

记预测剩余成本F(s,g)=D(Q(s),Q(g))。真实最短路满足

`d(s,g) = min_a [c(s,a) + d(T(s,a),g)]`。

正成本、可达且非目标的状态应有某个最优后继降低剩余成本，不能要求所有合法动作都下降。自身为零、固定距离的三角关系或平均MAE低，都不自动保证F沿物理动作满足这一条件；必须检查完整执行。

连通底图上的棋子排列互达；8-Puzzle按奇偶分量生成关系；推箱子和21／24点有方向性与不可恢复分支。21／24点每步元素数减1，可达时距离固定为元素数差，重点是保留解分支。过桥使用真实耗时，不以动作数替代成本。

## 数据与监督

物理图复用任务环境，单位成本标签由BFS得到，过桥用Dijkstra；教师表只用于准备、监督和裁判。选目标后计算源状态距离，同时保留全部物理候选。训练中的不可达真值保持无穷，配置指定有限代理标签；代理值不是精确无穷。

基础距离项拟合源—目标成本，排序项比较同目标下全部后继的“即时成本＋剩余成本”。单位成本任务即时成本相同；过桥须显式加入耗时。并列最优保留，不把回边或暂时远离目标位置的动作一律标错。仅最优动作目标、转移差值、辅助坐标等变体按配置和匹配比较单列，不能视为基线实现修复。

数据按需要混合广域状态对、真实动作边、多目标完整候选、连续路径与训练失败分支。训练池、开发集、结构留出和独立验收各有职责；测试失败不用于同一验收条件的训练或重新选模。

覆盖分别统计场景、物理状态、动作边、源—目标关系、完整候选、目标和实际损失曝光。物理状态全枚举不表示所有状态对都训练过，反复曝光也不表示已拟合。保护查询需包含其父状态及全部候选到目标的关系；若保护边界截断教师路径，应记录而非裁剪合法候选。目标到自身等末端关系的保护也可能切断监督链。

## 任务扩展与训练安排

当前八类范围及小OOD详见[任务总览](README.md#多任务扩展准备情况)。新任务优化已暂停；推箱子搁置。下列是地图组织原则，**不是自动继续训练的队列**。

- 寻路每张固定图、棋子交换每棵底图分别提供独立Qmap；新图地图本身通过与原LLM会读取分开验收。
- 推箱子当前按固定墙体对应地图，同墙体内改变箱子、玩家及完整目标；原跨墙共享条件仅保留为历史证据。
- 移车使用一张占格MLP覆盖训练车辆配置，限定采用已测熟悉布局范围；长程与整布局留出不宣称已解决。
- 过桥五人和六人分别训练，人数内覆盖配置耗时组合与完整人员／手电目标；范围外变化另验收。
- 21／24点限定1–10任取四数，四槽地图处理配置内后缀和中间目标；扩大来源域、独立初题或槽位上限另准备并验收。

正式地图验收分开报告完成率、最优成本、循环／死锁、可达误判和目标切换，不用预算结束代替收敛。当前采用权重不应被失败续训覆盖；没有核实通过的条件保留空缺或明确限定范围。

## 接入LLM的条件

Qmap、任务文字、正式SFT数据和LLM结果是不同阶段。联合训练按任务和小类组织，记录实际地图版本及曝光条件；新目标、同图新关系、新图新地图、未训练类别的比较分别定义。

每个读取样本提供当前、一个完整目标及全部合法后继，保持动作编号与环境一致；地图标签与精确教师距离不写入推理文字。达到目标和正确停止分别评价。五类新任务尚无新增LLM读取验收，现有四任务SFT结果见[对应报告](../experiments/map_sft_baselines/results/report.md)。

当前研究安排只维护在[项目状态页](../docs/PROJECT_STATUS_AND_TODO.md)。新任务结果与配置从[实验入口](../experiments/new_tasks_qmap/README.md)进入；历史设计同步页保留为[来源材料](https://zcnhpsd26tyi.feishu.cn/wiki/LStDwGVEQiageEkHL7Ncl95QnDi)，不替代当前采用记录。
