# 24点 Qmap

采用地图是四个排序槽位，各含存在位、符号位、16位绝对分子和16位分母，共136维；共享MLP与directed_max。旧数值编码每槽为存在掩码、带符号log(1+|分子|)、log(1+分母)、有界数值，保留兼容。Q只读当前值，不读解或精确可解标签。到[24]的可解状态距离恒为剩余数字个数减1，因此这轮主要检验可解性和动作选择。

训练复用 [StateEncoder、distance、soft_rank_loss](../../../grounded_llm/core/qmap/model.py)，保持距离Huber＋原权重软排序；按任务独立运行[首轮实验](../../../experiments/new_tasks_qmap/README.md)。不加入任务专属学习损失。不可达以配置中有限代理值训练与排序；它不是精确无穷距离。评测始终保留合法死路，并报告成本、动作顺序和完整求解。

仅采用有限域21／24及其2／3数后缀，任意中间目标规划尚未采用。权重、配置和适用条件以[selection](selection.json)为准。四数到21完成185/185、到24完成197/197，47组强制换目标均完成；但留出两数目标的两步4→2测试仅209/420。实际MapReader复核4,670个不同数值查询，禁止调用精确图并物理重放，复现全部分项。完整证据见[报告](../../../experiments/new_tasks_qmap/results/game24/report.md)，不宣称未见起题泛化或训练已收敛。
