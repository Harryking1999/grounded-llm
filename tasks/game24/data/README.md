# 21／24点数据

当前来源域是1–10中任取四个互不重复数字，共210组无序起题，全部属于地图训练域。每题展开全部合法运算DAG，保留分数、负数和无解分支；逐题共203,913个状态出现，按约分有理数多重集合并后28,118个不同数值状态。

目标包含[21]、[24]与配置内两数／三数完整中间多重集。每个源可配置多个目标，完整保留操作数选择及运算产生的合法后继。可达时最少步数等于元素个数差；不可达真值保持无穷，训练代理标签不覆盖真值。

训练和诊断按源元素数、目标类型、可达性及完整候选分层。留出目标按题内查询关系保护，同一精确中间状态或目标可能出现在其他起题；跨题曝光按精确数值合并，不能声称全局未见数值泛化。完整起题覆盖不等于所有源—目标关系都被监督。

当前准备、训练与验收配置由[selection](../Qmap/selection.json)链接；[报告](../../../experiments/new_tasks_qmap/results/game24/report.md)给出分层成绩与限制。生成实现见[relation_data.py](../../../grounded_llm/tasks/game24/relation_data.py)，原始精确图、采样曝光和完整断点在忽略的运行目录。

原XoT CSV划分及更大1–20域属于历史对照；[example.json](example.json)只用于字段说明。2／3数后缀来自四数域，不代替任意独立3数初题的验收。
