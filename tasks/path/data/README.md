# 寻路数据

准备入口：`experiments/path_qmap/src/data.py` 的 `prepare`；模型训练为同目录 `run.py`，冻结加载为 `reader.py`。

固定图邻接矩阵和节点编号；离线 BFS 标签、状态对、决策父节点、全部邻居及其到目标距离。验证／测试父节点与全部候选到目标的关系从两项损失留出；已见节点，不声称未见图泛化。

`example.json` 是小型结构说明，不是正式训练数据。模型可见输入与监督答案分开；精确标签用于训练和裁判，不作为地图组推理文字。候选编号与真实动作必须逐轮一致。大数据、oracle 表和缓存放在 Git 外，正式划分与参数只放对应实验的 `configs/`。
