# 8-Puzzle 数据

[example.json](example.json) 是一题可达的一步说明例，不是正式训练集；当前没有数据准备脚本或已生成的训练数据。

- 状态：3×3 整数矩阵，0 是空格，1–8 是数字块；展平时按行读取。
- 决策：当前／目标棋盘、全部合法方向、本轮候选 ID 与对应真实后继。
- 监督：真实最短距离、候选到目标的距离与最优动作。Q 距离排序在选定模型后生成，当前例中留空，不用真值冒充 Q 输出。
- 模型文字只显示当前状态、实际历史与候选方向；真实后继由环境供地图编码，不将精确距离作为推理文字。

后续实现先验证空格交换、边界、目标匹配与可达性。固定目标可用反向 BFS 生成精确标签；训练样本数、距离分层、关系留出与任意目标条件在正式合同中确定。随机打乱步数不当作最短距离。原始数据和 oracle 表放 Git 外。
