# 移车出库 Qmap

**采用原占格MLP，限定用于熟悉布局的已测关系与完整目标。** 该限定选用不表示训练域所有长题或新布局通过；权重、配置与排除范围见[selection](selection.json)，结果见[移车报告](../../../experiments/new_tasks_qmap/results/rush_hour/report.md)。优化已暂停。

| 内容 | 当前条件 |
|---|---|
| 状态输入 | 无墙6×6，每车一个占格通道，共26×36二值向量；场景内保持几何身份映射与A标记一致 |
| 目标 | 同一场景所有车辆的完整位置，普通中间目标允许A未到出口 |
| 一步与候选 | 一辆车沿自身轴线滑动任意合法距离计一步，保留全部合法后继 |
| 地图 | MLP分别编码当前、目标和后继；L1读出剩余最少滑动次数；不输入教师标签 |
| 加载 | [MapReader](../../../grounded_llm/tasks/rush_hour/qmap.py)，实际物理状态输入，不查询精确图 |

熟悉布局留出关系1024/1024，留出完整目标1024/1024；两组分别只有1–7步、1–3步。4096题分层训练原起点样本为3709/4096，但全量原起点×训练目标仅60,688/96,502。新布局随机中间起点591/1024，原题60/1024，均不属于可靠采用范围。

训练数据覆盖1000个独立车辆配置组。车辆属性编码的匹配对照比占格差，保留占格输入；追加2000组与L∞对照未形成新采用结果。完整统计、误差、循环和负结果见报告。
