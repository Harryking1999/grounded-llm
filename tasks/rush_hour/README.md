# Rush Hour（移车出库）

在拥挤的停车场里移动车辆，让它们到达指定位置。当前使用 **无墙6×6棋盘**，每辆车长两格或三格。

## 怎么玩

- 横车只能左右滑动，竖车只能上下滑动，不能转弯或穿过其他车。
- 一次只移动一辆车，沿自身方向滑动任意合法距离都算一步。
- 每题给出一张完整目标棋盘：**所有车辆的位置都必须匹配；中间目标允许A尚未到出口**。A到出口但其他车没到指定位置，仍未完成。
- 车辆始终留在棋盘内，目标是用尽量少的滑动次数完成。

车辆移动可以撤销，但为一辆车让路，常常需要先移动多辆其他车。

## 在项目中怎么用

编码器读取完整棋盘，区分每辆车。同一个Qmap覆盖多种车辆布局，学习到指定目标的最少滑动次数；测试单独检查训练时没见过的布局。

**原占格MLP按熟悉布局的已测关系与完整目标范围限定选用。** 两组短程测试均1024/1024，但全量训练原起点查询仅60,688/96,502，新布局原题60/1024。未达到全题库可靠长程或跨布局要求，优化已暂停，LLM读取未验收。完整比较见[移车报告](../../experiments/new_tasks_qmap/results/rush_hour/report.md)，范围见[selection](Qmap/selection.json)。
