# 推箱子 Qmap

**未通过，无采用权重；优化搁置。** 当前主条件为每套固定墙体独立训练Qmap，同墙体内改变箱子、玩家及完整目标；换墙体另训地图。保留MLP，CNN对照未显示优势。状态见[selection](selection.json)，结果见[报告](../../../experiments/new_tasks_qmap/results/sokoban/report.md)。

| 内容 | 定义 |
|---|---|
| 输入 | 4张10×10二值图：墙、原目标格、四个无编号箱子、玩家，共400维 |
| 查询目标 | 同墙体的完整箱子和玩家状态，允许箱子尚未全部到原目标格 |
| 一步 | 玩家走一格或推箱一格，各计一步；环境给全部合法后继 |
| 学习关系 | 有向最少走／推步数，保留不可达与死锁分支；源和目标独立编码 |
| 检查 | 训练拟合、留出关系、留出完整目标、原题起点，另记循环和首次死锁 |
