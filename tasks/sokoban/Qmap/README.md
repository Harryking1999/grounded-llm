# 推箱子 Qmap

## 已确认范围与实施状态

保留Boxoban hard的10×10、四箱四目标及逐格走／推动作。同一个Qmap覆盖多张hard棋盘，编码器输入完整棋盘，单独检验未见布局。**每题指定一张完整成功目标棋盘，箱子与玩家位置都要匹配**；不同题可以有不同目标。训练与评测均采用指定目标，不再安排原完成规则的对照。不是只为失败原题362训练。

该条件尚未准备正式训练数据、启动训练或采用权重。[selection](selection.json)中的历史六乘六两箱诊断身份保持原样，不能用于新的hard条件。历史试验与结果见[首轮入口](../../../experiments/new_tasks_qmap/README.md)。

## 规则、状态与输入

墙是不能进入的格子，目标格是箱子的指定停放位置。玩家每次上、下、左、右移动一格；若前方是箱子，且箱子前方为空，便同时把箱子向前推一格。不能拉箱子、穿墙或同时推动两箱。走动和推动每次均成本1。原规则以全部四箱到位为完成；首版指定的成功目标还要求玩家到给定格。箱子没有身份，不必指定哪只箱子去哪个目标。

棋盘符号为`#`墙、空格地面、`.`目标格、`$`箱子、`@`玩家、`*`目标上的箱子、`+`目标上的玩家。目标格不会因箱子或玩家盖住而消失。

| 输入部分 | 含义 |
|---|---|
| 墙通道，10×10 | 哪些格子不能进入，沿用公开原题边界 |
| 目标通道，10×10 | 四个箱子应停放的位置，包括被占据的目标格 |
| 箱子通道，10×10 | 当前四个箱子的位置，不按箱子身份编号 |
| 玩家通道，10×10 | 当前玩家位置，不能用箱子图代替 |

沿用已有四通道编码，展开为400维后输入共享两层隐藏MLP，输出128维Q。不同棋盘的墙和目标也随输入变化，不把场景编号当作替代输入。静态布局只是在一题内不变，并不表示整个训练集使用同一棋盘。分别编码当前和每个合法真实后继；每个状态最多四个候选。玩家在同一可行走区域的不同位置仍是不同状态，因为逐格走动计入成本。

## 完整目标与精确标签

目标g是一张真实合法棋盘：墙和目标格与起点相同，四箱均已到目标格，玩家在明确的非箱格。Q(s)、Q(g)、Q(s')使用同一四通道编码；不使用玩家全零的目标条件参照，也不拼接多个终局。Q(s)不拼入查询g；计算`distance(Q(s), Q(g))`拟合指定状态对的最小成本。字段`goal_board`明确给出目标；文本与裁判已支持箱子集合、玩家位置同时匹配。

复用[统一Q方法](../../QMAP_METHOD.md)的MLP、距离Huber和原权重soft-rank；沿用适合不可逆推动关系的`directed_max`。在每个布局内枚举完整物理状态及合法后继，针对选定完整目标分别反向单源最短路标注。采样可解起终点，并保留合法候选中到该目标不可达的后继；箱子推到死角等合法死路不能删除后宣称地图避开死锁。真实不可达距离为无穷，有限代理标签及输出尺度在精确距离范围明确后写入正式配置，不照搬旧两箱试验的代理值。

同一场景应覆盖多个完整成功目标及相应起点关系，不能只给每个布局绑定一个永远不变的目标后声称目标泛化。当前目标域仍限于箱子已到位的成功终局，不扩称任意合法中间棋盘目标。玩家位置不同的成功目标可能处于不同可达区域，不能随便选一个玩家格并假定从起点可达。精确最优成本针对给定目标独立计算。

## 多布局数据与泛化

按墙体布局分组留出训练、验证、测试；相同墙体下改变目标、箱子或玩家不能跨组。对墙体的旋转和镜像取同构分组，避免把变换副本称作未见布局。目标格仍作为完整输入，报告目标配置与墙体是否已见。原题ID、布局、筛选原因及可解状态范围随数据保留。

先核对各hard布局的完整物理图规模，再确定可精确标注的场景池与采样预算；有限资源筛选造成的分布偏移须报告。不能假定整个hard子集都可枚举。原题362作为已曝光失败诊断保留，不用作完全独立的最终测试。具体场景数、样本数、成本分桶与训练预算尚待精确图规模检查后确定，尚无正式配置。

## 验收与接入

分别报告已见布局的新起终点关系、目标留出与未见布局结果，包括有限距离误差、到指定目标的不可达判断、最优动作率、完整成功、最优完整计划、超额走／推步数及实际推动数。先验收冻结Q贪心，保留循环、死锁和超预算失败；搜索或重试另列条件。原题362的52步见证只给原规则的上界，不能当作指定目标或走动精确最优值。

任务reader按公共MapBatch放入当前、一个完整目标、全部合法真实后继，不改多目标接口；现有旧诊断不等于hard条件reader已完成。环境提供真实后继，不能声称编码器学会了转移。与无地图LLM比较时匹配起点、完整目标、规则、逐轮反馈、题集和预算；旧Flash筛查只对应原规则。hard条件训练与LLM接入尚待实现，权重通过验收后才登记采用。

历史六乘六两箱的目标条件参照及Flash原规则结果只作既有证据，不用于指定目标条件记分。
