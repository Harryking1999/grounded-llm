# 推箱子

玩家在仓库里推动箱子，走到题目指定的目标棋盘。当前使用 **Boxoban hard的10×10棋盘，四个箱子、四个目标格**。

## 怎么玩

- 墙是不能进入的格子，目标格是箱子应停放的位置。
- 每次向上、下、左、右走一格；前方有箱子且箱子后方为空时，可以把它推一格。
- 不能拉箱子、穿墙或一次推动两个箱子。走一格和推一格都算一步。
- 每题给出一张完整目标棋盘：**箱子全部到指定位置，玩家也要到指定位置**。箱子彼此没有编号。

目标棋盘与起点使用相同的墙和目标格。把箱子推入角落可能再也无法完成，因此合法动作不一定是好动作。

## 在项目中怎么用

编码器读取整张棋盘，包括墙、目标格、箱子和玩家。同一个Qmap覆盖多张布局，学习从当前棋盘到指定目标还要走多少步；测试会留出训练时没见过的布局。

**已完成数据准备和多组地图训练，尚未达标。** 扩到1,000张训练棋盘后，在100张未见棋盘测试中完成37.89%，21步及以上仍为0/312，尚未达到至少80%的要求；尚无采用权重或本任务LLM训练。完整比较见[三任务报告](../../experiments/new_tasks_qmap/results/report.md)。
