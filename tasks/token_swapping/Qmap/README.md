# Token Swapping Qmap

## 已确认范围与实施状态

第一版固定一棵10顶点树，学习并验证完整状态对距离；先验收，再考虑12–15顶点。沿用Flash已测的公开`Medium random tree 1`，边表与编号唯一维护在[tree10.json](../data/tree10.json)。不是跨树泛化实验。精确oracle生成、状态对训练、冻结评测与任务reader入口已实现，见[正式实验](../../../experiments/new_tasks_qmap/README.md)；尚无通过验收的权重；[selection](selection.json)保持空值。

[完整预算基线](../../../experiments/new_tasks_qmap/results/token_pairs_baseline.json)的留出关系／未见起点／两端未见到达率为35.55%／27.73%／27.25%，[补近阶段](../../../experiments/new_tasks_qmap/results/token_pairs_local_goals.json)为57.52%／47.85%／44.63%，均未达到最低验收线。局部最优动作率较高仍会在整题执行中循环，不能宣称已正确学到全域状态对地图。

## 状态、动作与目标

| 项目 | 构建约定 |
|---|---|
| 静态环境 | 固定树、节点0至9、棋子编号0至9；配置与权重必须绑定同一边表及编号 |
| 物理状态 | 长度10的完整排列，位置v存放当前在顶点v的棋子编号 |
| 动作 | 交换一条树边的两端，每次成本1；不是并行交换或多边跳转 |
| 查询目标 | 另一个完整排列g；到达判据是s与g逐项相等，不限定归位目标 |
| 真值 | 最少边交换数d_G(s,g)，对称、有限；所有10!个排列互达 |

不同底图上相同排列的合法后继及距离可能不同，但同规模连通图的完整排列状态集合相同。第一版把底图固定在环境与权重中，Q输入只需排列；以后若一张地图覆盖多树，必须引入图条件，不能仅混合排列训练或拿现有权重跨树使用。

## 编码与精确标签

用10×10的“顶点×棋子”one-hot展开为100维，每个顶点和每个棋子各有一个1。分别计算Q(s)、Q(g)、Q(s')；不把目标g拼入Q(s)。复用[统一Q方法](../../QMAP_METHOD.md)的MLP、距离Huber与原权重soft-rank。第一版采用适合可逆状态图的对称距离；具体距离、尺度、采样数与训练预算见[正式配置](../../../experiments/new_tasks_qmap/configs/token_swapping_pairs.json)，README不另维护参数副本。

[离线精确见证](../../../experiments/new_tasks_qmap/results/token_pairs_linf_witness.json)证明，128维L∞无法把固定树上见证端点的全部距离都拟合为精确值；它不证明近似地图不能达到80%贪心。由此单独考察core已有的分组L1读出，仍保持128维独立状态向量、原始排列输入及固定底图，不引入相对排列编码或推理搜索。模型是否可用仍依完整规划验收。

精确真值可利用棋子重标号：令`inverse_goal[token]`是该棋子在g中的位置，`relative[v] = inverse_goal[s[v]]`，则`d_G(s,g) = d_G(relative, identity)`。可先从归位排列反向BFS计算3,628,800项距离表，再查询状态对，不建立约13万亿项的全状态对矩阵。此等价关系已在三种小图共1728个状态对上逐项核对，完整10顶点表已生成并逐状态核验Bellman关系、边距离一致性及交换逆操作，图直径为25。上游参考序列、随机打乱长度或近似算法都不能替代最优标签；重标号只用于真值查询，不改变编码器的信息条件。

12顶点共有479,001,600个排列，15顶点有1,307,674,368,000个。扩展时仍可使用相对排列等价关系，但不能假定整张归位表可枚举；需另外确认采样与精确求解范围，不把10顶点结果直接记为更大规模能力。

## 采样、留出与验收

实际训练从全状态真值表抽取状态对和决策样本，逐源遍历并在线更换完整目标，而非仅监督所有状态到归位的距离。每个决策样本包含当前s、目标g、9个边交换后继以及各后继到g的精确距离。关系验证／测试留出同时屏蔽反向关系，并从距离损失与决策排序损失中排除对应父节点及候选关系，沿用寻路任务对关系曝光的约束。

状态已见、关系未见与目标未见分别报告；全状态可查询不等于所有状态或所有关系都已训练。独立核对实际点曝光与关系曝光，不能把固定归位表现称为任意目标泛化。

验收同时看距离误差、候选最优动作率、完整到达、最优完整计划及超额交换数。先用冻结Q贪心检验地图本身，保留失败与循环；搜索、重试或采样若另行启用需单列。公共输入槽位为当前、目标、合法真实后继；LLM仍由环境更新真实状态，地图不冒充学到的转移模型。

训练与冻结reader按任务独立编排，复用core编码、距离、排序、采样、指标与MapBatch，已验证单目标与全合法候选兼容。是否可用须由独立冻结评测判定，不能把接口通过当成地图通过。采用范围由selection维护；本任务不改动既有任务权重。

正式验收遵循[统一合同](../../../experiments/new_tasks_qmap/configs/exact_pair_acceptance.json)：各必需组地图贪心至少80%，目标90%以上；未见端点／布局分开报告，不以易题合并分数替代。
