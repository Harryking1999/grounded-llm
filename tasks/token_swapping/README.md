# Token Swapping（图上交换棋子）

图的每个顶点放一枚不同的棋子，通过相邻交换，把棋子移到指定位置。当前使用 **两棵10顶点树，各自对应独立Qmap**。

## 怎么玩

- 每个顶点始终恰好有一枚棋子。
- 每次选一条边，交换它两端的棋子，计一步。
- 不能跨越多条边直接交换，也不能同时执行多次交换。
- 每题给出完整起始排列和目标排列，所有顶点都匹配才算完成；交换次数越少越好。

在这棵连通树上，任意两个排列都能互相到达。难点是找到短解，所以同时评估完成率、最优率和多走了多少步。

## 在项目中怎么用

Qmap分别读取当前排列和目标排列，学习它们之间的最少交换次数。底图目前固定；换一棵树会改变合法动作和距离。

**原固定树L1地图已通过完整完成率验收并采用。** 三个1024题组完成998、1006、998题，最优完成723、772、766题；仍有残余循环。另一棵同规模树的独立地图也通过完成率验收；本任务LLM读取未验证。12–15顶点的扩展尚未开展。优化已暂停。完整比较见[棋子交换报告](../../experiments/new_tasks_qmap/results/token_swapping/report.md)。
